## Summary

B2C Commerce API Release Notes > 10/07/2026 > SCAPI Release

## Compressed

### SCAPI Release

Updated APIs:

- [Assignments] 1.0.39
  - `Schedule` no longer requires `startDate`, `endDate`, or `recurrence`. Omitting a bound leaves that side of the validity window open.
  - `timeFrom` and `timeTo` accept `HH:mm` or `HH:mm:ss`. Seconds are ignored and set to 0.

- [Campaigns] 1.1.1
  - Promotion campaign assignment `rank` must be null or a multiple of 10 from 0 to 100.
  - `Schedule` no longer requires `startDate` or `endDate`. Omitting a bound leaves that side of the validity window open.
  - `timeFrom` and `timeTo` accept `HH:mm` or `HH:mm:ss`. Seconds are ignored and set to 0.

- [Environments] 1.0.5
  - `updateEnvironment` (`PATCH /organizations/{organizationId}/storefronts/{storefrontId}/environments/{environmentId}`) now updates server-side rendering configuration in addition to `displayName`. The request is a partial update: only the supplied fields change, and at least one field is required. `displayName` is no longer required.
  - The environment resource and the update request now include `ssrRegion`, `ssrArchitecture` (`x86` or `arm64`), `ssrExternalHostname`, `ssrExternalDomain`, `ssrWhitelistedIps`, `ssrProxyConfigs` (up to 8 proxies; `path`, `host`, and `https` only), `isProduction`, `allowCookies`, `preserveProxyUserAgent`, `enableSourceMaps`, `logLevel` (`trace`, `debug`, `info`, `warn`, `error`, `fatal`), `distributedTracing`, `distributedTracingSamplingRate`, and `certificateId`.
  - For an environment served through eCDN, update `ssrExternalHostname`, `ssrExternalDomain`, and `ssrWhitelistedIps` in Business Manager. The API rejects those changes.
  - `allowCookies` can't be changed on a Storefront Next environment. Cookies stay enabled.
  - Selecting `x86` for `ssrArchitecture` is rejected when the organization isn't permitted to configure SSR architecture, and after x86 end of life. Use `arm64`.
  - `certificateId` is rejected when the certificate is missing, not validated, doesn't match the hostname domain, or the environment uses the default Managed Runtime domain.

- [Preferences] 1.2.3
  - Site `cartridges` is now read-only. It returns the effective cartridge path, including system cartridges and the site's custom cartridges.
  - Added `customCartridges`, the configurable custom cartridge path. It does not include system cartridges.

- [Schemas] 1.0.3
  - Schema search accepts `cartridgeName` to filter Custom API schemas. The schema listing includes `cartridgeName` for Custom APIs.

- [Shopper Agents] 1.1.5
  - Guest shopper calls can use `ShopperClientContextToken` with the `sfdc_usid` header. Registered shoppers continue to use `ShopperToken`.

- [Shopper Context] 1.1.4
  - Guest shopper calls can use `ShopperClientContextToken` with the `sfdc_usid` header. Registered shoppers continue to use `ShopperToken`.
  - Error responses for these operations use `application/problem+json`.

- [Storefronts] 1.0.4
  - `ssrRegion` values use underscores instead of hyphens. For example, `us-east-2` is now `us_east_2`.
  - `DELETE /organizations/{organizationId}/storefronts/{storefrontId}` returns 409 (`StorefrontBusyErrorResponse`) when a deletion of that storefront is already in progress.

- Updated list of cached API responses: `/shopper-experience` and `/custom` are temporarily not cached in SCAPI CDN cache for its specific handling of authentication.

- Infrastructure change for API validation on Staging and Production instances only. No customer impact is anticipated.

- Bug fixes and internal improvements.
