## Compressed

### Managed Runtime - Default Domain Change for New Environments

Newly created environments now use the `*.exp-delivery.com` domain instead of `*.mobify-storefront.com` as the default domain. This change affects all newly created environments.

**Important Notes:**

- Existing environments using `*.mobify-storefront.com` will continue to function normally and aren't affected by this change.
- Only new environments created after this date will use the new `*.exp-delivery.com` domain by default.
- Update public SLAS clients so that `redirectUri` includes the new default domain. See [Authorization for Shopper APIs]
