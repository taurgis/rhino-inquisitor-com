## Summary

B2C Commerce API Release Notes > 09/25/2025 > SCAPI Release

## Compressed

### SCAPI Release

- The SCAPI geolocation service does not support Anycast-related IP addresses. Anycast allows the same IP in multiple locations, and, therefore, can't resolve to one single location. For geolocation details, see [Shopper Geolocation] and [Geolocation Lookup for IP Addresses in B2C Commerce].

## Detailed

### SCAPI Release

- The SCAPI geolocation service does not support Anycast-related IP addresses. Anycast allows the same IP in multiple locations, and, therefore, can't resolve to one single location. For geolocation details, see [Shopper Geolocation](https://developer.salesforce.com/docs/commerce/commerce-api/guide/shopper-context-geolocation.md) and [Geolocation Lookup for IP Addresses in B2C Commerce](https://help.salesforce.com/s/articleView?id=cc.b2c_geolocation_lookup_for_ip_addresses.htm\&type=5).
