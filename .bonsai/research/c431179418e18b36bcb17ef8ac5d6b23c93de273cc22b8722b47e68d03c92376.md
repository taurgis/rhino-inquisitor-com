### 2.1 Attack Setup and Paraphrasing Methods

For evasion attacks, we consider a scenario where an adversary takes an AI response generated by a target model and then modifies the AI response in an automated and scalable fashion to evade detection. In this work, we propose the adversary modify the AI text from model ℒ\\mathcal{L} using an AI paraphraser 𝒫\\mathcal{P} to evade detection.

Figure 2: Recursive paraphrasing

Note that the adversary might be incentivized to use a detectable model ℒ\\mathcal{L} (say, watermarked) if ℒ\\mathcal{L} is powerful or might have been fine-tuned for specific applications. In these cases where ℒ\\mathcal{L} could answer a user prompt better, an adversary would still prefer to use the watermarked ℒ\\mathcal{L} to generate a response and then use a less detectable AI model 𝒫\\mathcal{P} for paraphrasing to evade detection. As shown in §[2.2], our evasion attacks only lead to a slight degradation in text quality while successfully evading detectors most of the time.

### 2.1 Attack Setup and Paraphrasing Methods

For evasion attacks, we consider a scenario where an adversary takes an AI response generated by a target model and then modifies the AI response in an automated and scalable fashion to evade detection. In this work, we propose the adversary modify the AI text from model ℒ\\mathcal{L} using an AI paraphraser 𝒫\\mathcal{P} to evade detection.

Note that the adversary might be incentivized to use a detectable model ℒ\\mathcal{L} (say, watermarked) if ℒ\\mathcal{L} is powerful or might have been fine-tuned for specific applications. In these cases where ℒ\\mathcal{L} could answer a user prompt better, an adversary would still prefer to use the watermarked ℒ\\mathcal{L} to generate a response and then use a less detectable AI model 𝒫\\mathcal{P} for paraphrasing to evade detection. We quantify the text quality using automated metrics such as perplexity and human studies. As shown in §[2.2](https://arxiv.org/html/2303.11156v4#S2.SS2 "2.2 Quality of the Paraphrases ‣ 2 Evading AI-Detectors using Paraphrasing Attacks ‣ Can AI-Generated Text be Reliably Detected?"), our evasion attacks only lead to a slight degradation in text quality while successfully evading detectors most of the time. Note that the amount of degradation that can be tolerated is application-specific. For example, an adversary could tolerate more quality degradation when generating a social media post than when generating a news article.

We use the “document” features of the XSum dataset ([Narayan et al., 2018](https://arxiv.org/html/2303.11156v4#bib.bib36)) containing 1000 long news articles (∼\\sim300 tokens in length) for our experiments. In Appendix [A](https://arxiv.org/html/2303.11156v4#A1 "Appendix A Experiments with More Datasets and Models ‣ Can AI-Generated Text be Reliably Detected?"), we perform experiments with additional datasets – a medical text dataset PubMedQA ([Jin et al., 2019](https://arxiv.org/html/2303.11156v4#bib.bib22)) and a dataset with articles from 10 different domains Kafkai ([Kafkai, 2020](https://arxiv.org/html/2303.11156v4#bib.bib23)). As target LLMs, we use OPT-1.3B and OPT-13B ([Zhang et al., 2022](https://arxiv.org/html/2303.11156v4#bib.bib57)) language models with 1.3B and 13B parameters, respectively. In Appendix [A](https://arxiv.org/html/2303.11156v4#A1 "Appendix A Experiments with More Datasets and Models ‣ Can AI-Generated Text be Reliably Detected?"), we also evaluate our attacks with GPT-2 Medium ([Radford et al., 2019](https://arxiv.org/html/2303.11156v4#bib.bib42)) as the target model. We use three different neural network-based paraphrasers – DIPPER with 11B parameters ([Krishna et al., 2023](https://arxiv.org/html/2303.11156v4#bib.bib27)), LLaMA-2-7B-Chat with 7B parameters ([Touvron et al., 2023](https://arxiv.org/html/2303.11156v4#bib.bib50)), and T5-based paraphraser ([Damodaran, 2021](https://arxiv.org/html/2303.11156v4#bib.bib11)) with 222M parameters.
