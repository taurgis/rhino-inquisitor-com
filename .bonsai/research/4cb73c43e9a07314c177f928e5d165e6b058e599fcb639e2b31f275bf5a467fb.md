## Summary

Building Your Commerce App > Connection Health Check > Registering the hook

## Compressed

### Registering the hook

Add a `checkConnectionHealth` entry to your cartridge's `hooks.json`:

```json
{
  "hooks": [
    {
      "name": "sfcc.app.<domain>.checkConnectionHealth",
      "script": "./hooks/checkConnectionHealth.js"
    }
  ]
}
```

Replace `<domain>` with your app's domain (for example, `tax`, `shipping`, `payment`, `ratings-and-reviews`). The hook name must follow the `sfcc.app.<domain>.checkConnectionHealth` convention — the platform uses it to associate the hook with your app's installation.

> **Function naming convention:** The exported function must be named `checkConnectionHealth`, matching the last segment of the extension point name.
