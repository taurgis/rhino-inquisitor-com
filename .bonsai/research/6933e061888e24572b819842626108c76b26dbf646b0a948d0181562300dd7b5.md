## Compressed

## Prerequisites

To integrate Page Designer with a PWA Kit site:

- Build your site with either of these implementations:
  - Composable Storefront (PWA Kit version 2.7.0 or later) for your whole site with usage of the [Retail React app template]
  - A [phased headless rollout] ([Storefront Reference Architecture - SFRA] and PWA Kit version 2.7.0 or later with usage of the Retail React app template)

- Create or update a SLAS public or private client. Follow the steps in [Create a SLAS Client] or use the [registerClient API endpoint].

  - In the **Scopes** field, include this scope: `sfcc.shopper-experience`.

    A SLAS private client offers several advantages over a public client. See [Use a SLAS Private Client].

- [Get a SLAS admin token].

- **MRT Admin Permission**: To use headless Page Designer features, merchants need one of the following permissions in Account Manager: `crm-org-admin`, `crm-org-user`, or `crm-service-admin`. If you have one of these permissions and an MRT environment pointing to your ecom site, no additional manual configuration is needed. Starting with version 26.6, no special permissions are required.

- **Single MRT Environment**: Each Business Manager site can only have one MRT environment configured. Multiple MRT environments pointing to the same Business Manager site (n:n assignment) isn't supported.

- Create your Page Designer pages in the Page Designer visual editor. See [Create a Page Using the Page Designer Visual Editor].

## Prerequisites

To integrate Page Designer with a PWA Kit site:

- Build your site with either of these implementations:
  - Composable Storefront (PWA Kit version 2.7.0 or later) for your whole site with usage of the [Retail React app template](https://github.com/SalesforceCommerceCloud/pwa-kit/blob/develop/packages/template-retail-react-app/README.md)
  - A [phased headless rollout](https://developer.salesforce.com/docs/commerce/pwa-kit-managed-runtime/guide/phased-headless-rollouts.html) ([Storefront Reference Architecture - SFRA](https://developer.salesforce.com/docs/commerce/sfra/guide/sfra-overview.html) and PWA Kit version 2.7.0 or later with usage of the Retail React app template)

- Create or update a SLAS public or private client. Follow the steps in [Create a SLAS Client](https://developer.salesforce.com/docs/commerce/commerce-api/guide/authorization-for-shopper-apis.html#create-a-slas-client) or use the [registerClient API endpoint](https://developer.salesforce.com/docs/commerce/commerce-api/references/auth-admin?meta=registerClient).

  - In the **Scopes** field, include this scope: `sfcc.shopper-experience`.

    A SLAS private client offers several advantages over a public client. See [Use a SLAS Private Client](https://developer.salesforce.com/docs/commerce/pwa-kit-managed-runtime/guide/use-a-slas-private-client.html).

- [Get a SLAS admin token](https://developer.salesforce.com/docs/commerce/commerce-api/guide/authorization-for-shopper-apis.html#get-a-slas-admin-token).

- **MRT Admin Permission**: To use headless Page Designer features, merchants need one of the following permissions in Account Manager: `crm-org-admin`, `crm-org-user`, or `crm-service-admin`. If you have one of these permissions and an MRT environment pointing to your ecom site, no additional manual configuration is needed. Starting with version 26.6, no special permissions are required.

- **Single MRT Environment**: Each Business Manager site can only have one MRT environment configured. Multiple MRT environments pointing to the same Business Manager site (n:n assignment) isn't supported.

- Create your Page Designer pages in the Page Designer visual editor. See [Create a Page Using the Page Designer Visual Editor](https://help.salesforce.com/s/articleView?id=cc.b2c_create_page.htm\&language=en_US\&type=5).
