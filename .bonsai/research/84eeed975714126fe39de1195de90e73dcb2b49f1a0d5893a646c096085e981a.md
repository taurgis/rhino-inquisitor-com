# Shopper Agent Setup for SFRA Storefronts

To set up the Shopper Agent for a B2C SFRA storefront, install the plugin\_shopper\_agent cartridge, and configure Shopper Agent features.

Before installing the plug-in cartridge:

*   Set up Enhanced Chat in your Salesforce org, and connect the channel to the Shopping Agent.
*   Set up Hybrid Authentication (Hybrid Auth). For instructions, see [Hybrid Authentication]. Under Site Settings, enable Hybrid Auth, Shopper Context, Do-Not-Track Synchronization, and HttpOnly True.
    
    Starting with B2C Commerce version 25.3, Hybrid Auth replaces the plug-in SLAS cartridge option to improve performance.

    If you use SFRA (Storefront Reference Architecture) to develop your storefront, install the required SFRA cartridge to run the agent.
*   **[Set Up Apple Pay and Google Pay for Shopper Agents on an SFRA Store]**  
    Let B2C Commerce shoppers complete purchases directly in their Shopper Agent. Adyen supports Apple Pay and Google Pay with Salesforce Payments.
*   **[Inputs and Outputs for Shopper Agent Actions on SFRA Stores]**  
    To configure Shopper Agent actions to work with a B2C Commerce SFRA storefront, set up inputs, outputs, and variables. The variables enable the Shopper Agent to authenticate and interact with SFRA storefronts. Coupon actions require an additional input token.
*   **[Import Custom Metadata for Salesforce Reference Architecture (SFRA) Storefronts]**

*   **[Select Where to Launch the Shopper Agent in Your SFRA Storefront]**  
    Tailor where visitors can access the Shopper Agent in your SFRA storefront. You can enable multiple launch locations to make it convenient for shoppers to access AI-powered assistance when they’re browsing, searching, or navigating your site.

    Commerce Reports and Dashboards give you a visual way to track your SFRA storefront revenue and orders directly attributed to your B2C Shopper Agent. # Shopper Agent Setup for SFRA Storefronts

To set up the Shopper Agent for a B2C SFRA storefront, install the plugin\_shopper\_agent cartridge, and configure Shopper Agent features. Complete these tasks in Git and in your B2C Commerce instance.

Before installing the plug-in cartridge:

*   Set up Enhanced Chat in your Salesforce org, and connect the channel to the Shopping Agent.
*   Set up Hybrid Authentication (Hybrid Auth). For instructions, see [Hybrid Authentication](https://developer.salesforce.com/docs/commerce/commerce-api/guide/hybrid-authentication.html#set-up-your-storefront-with-hybrid-auth). Under Site Settings, enable Hybrid Auth, Shopper Context, Do-Not-Track Synchronization, and HttpOnly True.
    
    Starting with B2C Commerce version 25.3, Hybrid Auth replaces the plug-in SLAS cartridge option to improve performance.
    

*   **[Install the Shopper Agent Cartridge for SFRA Storefronts](https://help.salesforce.com/s/articleView?id=cc.b2c_shopping_agent_install_sfra_cartridge.htm&language=en_US&type=5)**  
    If you use SFRA (Storefront Reference Architecture) to develop your storefront, install the required SFRA cartridge to run the agent.
*   **[Set Up Apple Pay and Google Pay for Shopper Agents on an SFRA Store](https://help.salesforce.com/s/articleView?id=cc.b2c_shopping_agent_sfra_payments.htm&language=en_US&type=5)**  
    Let B2C Commerce shoppers complete purchases directly in their Shopper Agent. Adyen supports Apple Pay and Google Pay with Salesforce Payments.
*   **[Inputs and Outputs for Shopper Agent Actions on SFRA Stores](https://help.salesforce.com/s/articleView?id=cc.b2c_shopping_agent_sfra_action_reference.htm&language=en_US&type=5)**  
    To configure Shopper Agent actions to work with a B2C Commerce SFRA storefront, set up inputs, outputs, and variables. The variables enable the Shopper Agent to authenticate and interact with SFRA storefronts. Coupon actions require an additional input token.
*   **[Import Custom Metadata for Salesforce Reference Architecture (SFRA) Storefronts](https://help.salesforce.com/s/articleView?id=cc.b2c_shopping_agent_import_custom_metadata_sfra.htm&language=en_US&type=5)**  
    For SFRA storefronts, site-specific product attributes require specific import and export handling. For best results, import this data manually.
*   **[Configure Enhanced Chat for the Salesforce Reference Architecture (SFRA) Storefront](https://help.salesforce.com/s/articleView?id=cc.b2c_shopping_agent_sfra_site_prefs.htm&language=en_US&type=5)**  
    To display the live chat button appears on your storefront product pages, put the Embedded Services Deployment code snippet into your site preferences. The code snippet is automatically generated when you set up your messaging channel.
*   **[Select Where to Launch the Shopper Agent in Your SFRA Storefront](https://help.salesforce.com/s/articleView?id=cc.b2c_shopping_agent_launch_locations_sfra.htm&language=en_US&type=5)**  
    Tailor where visitors can access the Shopper Agent in your SFRA storefront. You can enable multiple launch locations to make it convenient for shoppers to access AI-powered assistance when they’re browsing, searching, or navigating your site.
*   **[Collect Shopper Agent Analytics for SFRA Storefronts](https://help.salesforce.com/s/articleView?id=cc.b2c_shopping_agent_analytics.htm&language=en_US&type=5)**  
    Commerce Reports and Dashboards give you a visual way to track your SFRA storefront revenue and orders directly attributed to your B2C Shopper Agent. These metrics help you estimate the agent’s return on investment. With the agent filters on the dashboard, you can compare metrics with and without Shopper Agent involvement on the Homepage, Sales, Products, and Promotions views.
