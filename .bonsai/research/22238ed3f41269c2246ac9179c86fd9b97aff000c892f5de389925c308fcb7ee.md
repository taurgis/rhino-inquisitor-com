## Compressed

## URLs for Localization

In Salesforce B2C Commerce, URLs can be localized. When you create a site, the URL Rules module automatically formats your URLs according to the module configuration.

:::note
If site URLs are configured with the locale ID as the first element of the URL (for example, /en_US/mens), B2C Commerce doesn't resolve URLs if they don't contain the locale (for example, /mens).
:::
