## Compressed

### Configure B2C Commerce for Facebook and Instagram

1. Log in to Business Manager.
2. In Business Manager, click App Launcher  and then select **Merchant Tools** > **Social Channels** > **Facebook and Instagram**.
3. Select the **Accept Terms** button.
4. Fill out the form. If you need help, refer to the [Salesforce B2C Commerce Details] or select the small help icon for a field to learn about the required values.
   
5. Select **Save**.
6. If all required fields are defined and valid, the **Onboarding** tab is displayed.
   
7. Select **Get Started**.
   
8. Log in with your Facebook account (this should be part of a Meta Business Account).
   
9. Select **Continue as *\[Your Name]***.
   
10. Select the following options from your Meta Business account:
    - Check ***Shops*** to configure the integration related to your shop.
    - Check ***Facebook Ads*** to configure the integration related to your ad account.
      
11. Select the environment for this integration:
    - Choose ***Production*** to be connected to your live assets.
    - Choose ***Test*** to validate this integration with test assets.
      
12. Select a business ***Page*** from your Meta Business Account:
    - Connect to an *existing* Page by selecting any entry you want to use.
    - Create a *new* Page by selecting **Create New**.
      
13. Choose an ***ad account*** if you checked this option on the first step. Otherwise, skip this step.
    - Connect to an *existing* ad account by selecting any entry you want to use.
    - Create a *new* ad account by selecting **Create New**.
      
14. Fill in required ***Shop details***.
    
15. Confirm the commerce account being used and select **Next**.
16. Check all required permissions for the B2C Commerce application.
    
17. Select **Confirm** to perform the linking.
    
18. Set any additional desired information, or skip this step. **Wait for the onboarding to complete before closing or refreshing the page.**
    
19. After completing the onboarding process, B2C Commerce automatically attempts to share additional post onboarding data with Meta. If this fails, resend this information by selecting **Share Data**. If the automated process was executed successfully, **Share Data** not visible.
20. When everything completes, check the connected Meta application details on Business Manager. This information is used to process all features available in this integration.
    - `Business Manager ID`
    - `External Business ID`
21. The new ***Meta*** tab contains information you need to manage your connection.
    

#### Salesforce B2C Commerce Configuration Details

| **Field Name**                  | **Details**                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Salesforce AM Client ID**     | The Account Manager API Client ID, used for operations like accessing WebDAV folders to read feed files (categories, products, etc)                                                                                                                                                                                                         |
| **Salesforce AM Client Secret** | The Account Manager API Client Secret                                                                                                                                                                                                                                                                                                       |
| **Salesforce SLAS ID**          | The SLAS Credential ID, used for operations like syncing Orders from Meta to Salesforce B2C Commerce                                                                                                                                                                                                                                        |
| **Salesforce SLAS Secret**      | The SLAS Credential Secret                                                                                                                                                                                                                                                                                                                  |
| **Short Code**                  | The environment short code, available by selecting the help icon or accessing *Administration > Site Development > Salesforce Commerce API Settings*.                                                                                                                                                                                       |
| **Organization ID**             | The environment organization ID, available by selecting the help icon or accessing *Administration > Site Development > Salesforce Commerce API Settings*.                                                                                                                                                                                  |
| **Current Site Hostname**       | The hostname used by the current Site to access the environment APIs, for example: `dev.mysite.com`. This is important information, especially if this integration is running in a development or production instance. If you have a custom hostname registered, check the correct value in **Merchant Tools** > **SEO** > **Aliases**.     |
| **Product Feed Job ID**         | The job ID used by the current Site to export full product feeds, for example: `Instagram-ExportFullFeeds`). This is used to trigger this job immediately after onboarding. If you have more than one storefront site, check the correct job ID (according to the defined job step scope) in **Administration** > **Operations** > **Jobs** |

### Configure B2C Commerce for Facebook and Instagram

1. Log in to Business Manager.
2. In Business Manager, click App Launcher ![App Launcher](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/shared/appLauncher.png) and then select **Merchant Tools** > **Social Channels** > **Facebook and Instagram**.
3. Select the **Accept Terms** button.
4. Fill out the form. If you need help, refer to the [Salesforce B2C Commerce Details](#salesforce-b2c-commerce-configuration-details) or select the small help icon for a field to learn about the required values.
   ![Onboarding form](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_bus_mgr_onboarding_form.png)
5. Select **Save**.
6. If all required fields are defined and valid, the **Onboarding** tab is displayed.
   ![Onboarding tab](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_bus_mgr_onboarding_filled.png)
7. Select **Get Started**.
   ![Get Started](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_bus-mgr_facebook_onboarding_splash.png)
8. Log in with your Facebook account (this should be part of a Meta Business Account).
   ![Login with Facebook credentials](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_facebook_login.png)
9. Select **Continue as *\[Your Name]***.
   ![Continue with Facebook credentials](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_facebook_auth_business.png)
10. Select the following options from your Meta Business account:
    - Check ***Shops*** to configure the integration related to your shop.
    - Check ***Facebook Ads*** to configure the integration related to your ad account.
      ![Select Shops and Facebook Ads options](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_facebook_select_options.png)
11. Select the environment for this integration:
    - Choose ***Production*** to be connected to your live assets.
    - Choose ***Test*** to validate this integration with test assets.
      ![Select integration environment](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_facebook_environment.png)
12. Select a business ***Page*** from your Meta Business Account:
    - Connect to an *existing* Page by selecting any entry you want to use.
    - Create a *new* Page by selecting **Create New**.
      ![Select business page](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_facebook_assets.png)
13. Choose an ***ad account*** if you checked this option on the first step. Otherwise, skip this step.
    - Connect to an *existing* ad account by selecting any entry you want to use.
    - Create a *new* ad account by selecting **Create New**.
      ![Select ad account](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_facebook_ad_account.png)
14. Fill in required ***Shop details***.
    ![Enter contact email and return timeframe](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_facebook_shop_details.png)
15. Confirm the commerce account being used and select **Next**.
16. Check all required permissions for the B2C Commerce application.
    ![Verify permission information](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_facebook_permissions.png)
17. Select **Confirm** to perform the linking.
    ![Linking in progress](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_facebook_linking.png)
18. Set any additional desired information, or skip this step. **Wait for the onboarding to complete before closing or refreshing the page.**
    ![Optional business information, address, category, and bank account](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_facebook_additional_info.png)
19. After completing the onboarding process, B2C Commerce automatically attempts to share additional post onboarding data with Meta. If this fails, resend this information by selecting **Share Data**. If the automated process was executed successfully, **Share Data** not visible.
20. When everything completes, check the connected Meta application details on Business Manager. This information is used to process all features available in this integration.
    - `Business Manager ID`
    - `External Business ID`
21. The new ***Meta*** tab contains information you need to manage your connection.
    ![Meta tab with Overview and Settings](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_bus_mgr_facebook_meta.png)
