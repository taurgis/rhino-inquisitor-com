# Storefront Next Version 1.0.0 Release

Storefront Next is generally available for production use as of June 9, 2026.

Note For the initial v1.0.0 release of Storefront Next, the Storefront Next release notes are part of the B2C Commerce release notes to maximize visibility of this major launch. Going forward, find the release notes for Storefront Next features in the [Storefront Next Guide] on Salesforce Developers.

*   **[Deliver Personalized Shopping Experiences at Scale with Storefront Next (Generally Available)]**
    
    Storefront Next is a full-stack React framework that combines server-side rendering with client-side navigation to deliver performant and personalized shopping experiences. Save time and effort by using an automated workflow in Business Manager to set up your storefront. With the B2C Developer Toolkit and agent skills, get help with storefront development and convert your Figma design to code. Merchants can customize the storefront in Page Designer, which renders React components natively. Customers can converse with the Shopper Agent to find products.
    
*   **[Create Storefront Next Faster with Automated Setup in Business Manager] projects and environments, and make the initial storefront deployment—storefront setup does it all for you. The automated setup creates a storefront with an eCDN default domain and certificate. Choose to have your storefront code stored in a GitHub repository and authenticate to GitHub. After setup completes, you can view, clone, delete your MRT environment, and edit some settings. If you have PWA-Kit storefronts created earlier in MRT, you can display them in Business Manager and have all your storefronts available in one interface.")**
    
    No need to manually set up API clients, Managed Runtime (MRT) projects and environments, and make the initial storefront deployment—storefront setup does it all for you. The automated setup creates a storefront with an eCDN default domain and certificate. Choose to have your storefront code stored in a GitHub repository and authenticate to GitHub. After setup completes, you can view, clone, delete your MRT environment, and edit some settings. If you have PWA-Kit storefronts created earlier in MRT, you can display them in Business Manager and have all your storefronts available in one interface.
    
*   **[Manage Storefront Next Environments Preconfigured with eCDN] environments that storefront setup or you create in Business Manager are preconfigured with the embedded content delivery network (eCDN). Native eCDN support for Storefront Next provides better performance and security, a default domain for your storefront, and eCDN security features. The default domain, *.my.cc.salesforce.com, is automatically mapped to the *.exp-delivery.com MRT domain, and you don't need to set up a proxy.")**
    
    The Managed Runtime (MRT) environments that storefront setup or you create in Business Manager are preconfigured with the embedded content delivery network (eCDN). Native eCDN support for Storefront Next provides better performance and security, a default domain for your storefront, and eCDN security features. The default domain, \*.my.cc.salesforce.com, is automatically mapped to the \*.exp-delivery.com MRT domain, and you don't need to set up a proxy.
    
*   **[Manage Storefront Next Page Content in Page Designer], and Product Listing Page (PLP). These pages include layout and content components. After an administrator has set up the storefront in Business Manager, merchants can set component properties, and target campaigns and promotions in component settings.")**
    
    Merchants can now use Page Designer to add and customize these Storefront Next pages: Home Page, About Us, Product Detail Page (PDP), and Product Listing Page (PLP). These pages include layout and content components. After an administrator has set up the storefront in Business Manager, merchants can set component properties, and target campaigns and promotions in component settings.
    
*   **[Preview Your Storefront in Business Manager with Shopper Context]**
    
    Verify how your storefront looks based on shopper context, including customer groups, date and time, source code triggers, and qualifiers. Use the preview feature to test changes to products, pricing, and marketing strategies before deploying to production. This process helps you verify that your site displays correctly for scenarios like upcoming sales or seasonal campaigns.
    
*   **[Deliver Richer Shopping Experiences with the Storefront Next Market Street Template], and Product Detail Page (PDP). The template provides a proven blueprint, which saves implementers and merchants time and enables them to focus on brand differentiation and integration rather than page design. The product pages include components for a wishlist, store locator, in-store pickup, inventory status, enriched product tiles, and a popup to add a product to the cart. You can also include product reviews and ratings by connecting to a third-party service. The My Account page contains recent orders, the wishlist, payment methods, as well as other new features.")**
    
    The Market Street retail template offers an enriched My Account page, Product Listing Page (PLP), and Product Detail Page (PDP). The template provides a proven blueprint, which saves implementers and merchants time and enables them to focus on brand differentiation and integration rather than page design. The product pages include components for a wishlist, store locator, in-store pickup, inventory status, enriched product tiles, and a popup to add a product to the cart. You can also include product reviews and ratings by connecting to a third-party service. The My Account page contains recent orders, the wishlist, payment methods, as well as other new features.
    
*   **[Get Optimized Storefront Performance with a New Architecture]**
    
    Storefront Next uses React Router 7 framework mode, which renders pages on the server for initial page loads and reduces client-heavy processing in the browser. The Storefront Next server-side personalization delivers tailored content and data without sacrificing performance. Storefront Next uses Tailwind and shadcn/ui for CSS styling and components, which results in smaller storefront bundles and improved Core Web Vitals.
    
*   **[Build and Test UI Components in Storefront Next with Storybook]**
    
    Storefront Next includes Storybook, an open-source front-end tool for building, viewing, testing, and documenting React UI components. Use Storybook to explore the built-in Storefront Next components, build components in isolation, run automated tests, and create component documentation. Using Storybook for component development leads to easier component discoverability, faster development, higher component quality, and reduced regressions.
    
*   **[Build and Administer Storefront Next with AI Agents and the CLI]. With agent skills, AI agents can build storefronts, deploy cartridges, manage jobs, create sandboxes, and perform many other tasks from the terminal or directly inside your IDE. No need to write code from scratch, memorize CLI commands, or click through Business Manager. Use the CLI from the terminal to automate repeatable administration tasks.")**
    
    Use the Agentic B2C Developer Toolkit to build your storefront and manage administration tasks with AI agents, a CLI, and an MCP server. The toolkit includes agent skills and plug-ins that enable you to perform tasks by writing a prompt in your preferred AI coding agent. Examples of supported agents include Agentforce Vibes, Claude Code, Cursor, and GitHub Copilot (VS Code and CLI). With agent skills, AI agents can build storefronts, deploy cartridges, manage jobs, create sandboxes, and perform many other tasks from the terminal or directly inside your IDE. No need to write code from scratch, memorize CLI commands, or click through Business Manager. Use the CLI from the terminal to automate repeatable administration tasks.
    
*   **[Keep Your Figma Design Kit and Storefront Next Code in Sync]**
    
    Maintain a single source of truth for your brand tokens and components between the Figma design kit and your Storefront Next code. Use the Storefront Next Figma agent plugin to duplicate the official design kit for your brand, sync your brand colors and typography from code to Figma, and reflect component changes from code to Figma and vice versa. When you publish the Figma Code Connect mappings, your Figma components show your real React code in dev mode.
    
*   **[Protect Storefront Next Access via Business Manager]**
    
    Control access to your storefronts by using the Business Manager site configuration. Grant access to Managed Runtime environments associated with your storefronts only to users with a basic authentication password.
    
*   **[Streamline Checkout with Address Autocomplete in Storefront Next]**
    
    Reduce shoppers’ keystrokes and errors at the most abandonment-prone step of checkout with address autocomplete. During checkout, a shopper now needs to enter only three characters of their shipping or billing address to instantly receive Google-powered recommendations. When the shopper selects an address from the list of recommendations, Google completes the remaining address fields.
    
*   **[Boost Checkout Conversion in Storefront Next]**
    
    Offer shoppers a streamlined checkout experience and reduce cart abandonment. When a first-time shopper checks out, they can now save their shipping and payment information for future use and create an account with your store. When a registered shopper returns to make another purchase, the shopper only needs to enter their email and a verification code to check out. Their shipping and payment information is automatically filled in. Shoppers always have the option to check out as a guest.
    
*   **[Build and Deploy Storefront Extensions Faster with the Commerce Apps Framework]. Deploy the package through one automated command instead of handling cartridge uploads, path configuration, and data imports manually. Choose from three build approaches for varying levels of control, including UI-only, backend-only, or fullstack apps. The Commerce Apps Framework currently supports Tax, Ratings & Reviews, Loyalty, Digital Asset Management, Product Visualization, and Analytics domains with more domains coming soon.")**
    
    Bundle front-end UI components, back-end logic, or both into a Commerce App Package (CAP). Deploy the package through one automated command instead of handling cartridge uploads, path configuration, and data imports manually. Choose from three build approaches for varying levels of control, including UI-only, backend-only, or fullstack apps. The Commerce Apps Framework currently supports Tax, Ratings & Reviews, Loyalty, Digital Asset Management, Product Visualization, and Analytics domains with more domains coming soon.
