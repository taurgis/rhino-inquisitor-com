## Summary

B2C Commerce API Release Notes > 01/28/2026 > SCAPI Release

## Compressed

### SCAPI Release

- New APIs and endpoints:
  - New [Inventory Lists API] that provides comprehensive management capabilities for product inventory records within inventory lists:
    - `GET inventory-lists/{inventoryListId}/product-inventory-records/{productId}`
      - Retrieve a product inventory record.
    - `PUT inventory-lists/{inventoryListId}/product-inventory-records/{productId}`
      - Create a product inventory record using the information provided.
    - `PATCH inventory-lists/{inventoryListId}/product-inventory-records/{productId}`
      - Update a product inventory record with the specified information.
    - `DELETE inventory-lists/{inventoryListId}/product-inventory-records/{productId}`
      - Delete a product inventory record by ID.
  - New [Experiences API] for creating and updating Page Designer pages for headless and PWA storefront management outside of Business Manager:
    - `PUT /pages/{pageId}`
      - Create or update a Page Designer page.
    - `POST slot-configurations-search`
      - Search for slot configurations.
- Bug fix for [Custom APIs] timeouts for shopper use cases. Documented [timeouts] have been re-enforced.
- Updates for which no customer impact is anticipated:
  - Reliability enhancements for internal configuration handling.
  - Cleaned up obsolete feature switches and infrastructure updates.
  - Prepared for an upcoming feature to support User Authorization for SCAPI Admin APIs.
  - Security updates.
  - Prepared for routing OCI to Hyperforce.
  - Geolocation information will be set to rest session.
