## Summary

Required conditions for origin trials > Token is provided before feature is accessed

## Compressed

### Token is provided before feature is accessed

Make sure that an origin trial token is provided _before_ a trial feature is accessed. For example, if a page provides a token with JavaScript, make sure the code to provide the token is run before code that attempts to access the trial feature.
