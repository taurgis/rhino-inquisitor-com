## Summary

Composable Storefront Release Notes > 6/18/2026 > x86 Server Architecture Is Scheduled for Retirement

## Compressed

### x86 Server Architecture Is Scheduled for Retirement

The x86 server architecture in Managed Runtime is scheduled for retirement on **January 31, 2027**. After that date, environments running on x86 can't be deployed. Environments aren't deleted and continue to respond to requests, but deployments are blocked until the environment is switched to ARM.

The ARM architecture is already the default for all new projects. For existing projects, switch each environment's architecture in Runtime Admin under environment settings. Most projects can switch to ARM with no code changes.

**Where:** This change applies to Composable Storefronts using Managed Runtime.

## Detailed

### x86 Server Architecture Is Scheduled for Retirement

The x86 server architecture in Managed Runtime is scheduled for retirement on **January 31, 2027**. After that date, environments running on x86 can't be deployed. Environments aren't deleted and continue to respond to requests, but deployments are blocked until the environment is switched to ARM.

The ARM architecture is already the default for all new projects. For existing projects, switch each environment's architecture in Runtime Admin under environment settings. Most projects can switch to ARM with no code changes. If your project uses architecture-specific native modules, test in a non-production environment before switching production.

**Where:** This change applies to Composable Storefronts using Managed Runtime.
