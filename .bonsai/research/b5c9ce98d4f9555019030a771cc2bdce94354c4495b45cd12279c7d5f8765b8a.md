## Summary

Web Services > Creating Service Callbacks > Generic Callbacks

## Compressed

### Generic Callbacks

Doesn’t wrap any class. Used to define custom calls.

- `createRequest:` Required to create a `requestData` object. If you need additional processing, pass the `requestData` object to the execute callback. Otherwise, the `requestData` object is used to call the web service when the `Service` object is called.
- parseResponse: Use to parse the response contained in the `Service` object.

:::note
You must pass a plain Service object, rather than a subclass, for this callback method.
:::
