# Shopper Agent Setup for PWA Kit Storefronts

For the Shopper Agent to work with PWA Kit storefronts, set up Managed Runtime (MRT). MRT provides the infrastructure for your PWA Kit storefront, and it enables the Shopper Agent to communicate with the Enhanced Chat service in your Salesforce org.

*   **[Configure MRT and Trusted Domains for the Shopper Agent]**  
    For the Shopper Agent to work with PWA Kit storefronts, set up managed runtime (MRT). MRT provides the infrastructure for your PWA Kit storefront, and it enables the Shopper Agent to communicate with the Enhanced Chat service in your Salesforce org. Set the correct environment variables in Managed Runtime for your deployed bundle.
*   **[Select Where to Launch the Shopper Agent for PWA Kit Storefronts]**  
    Make it convenient for shoppers to access AI-powered assistance when they’re browsing, searching, and navigating your site. Launch the Shopper Agent from the header, the search suggestions dropdown list, or a floating icon each storefront page.
*   **[Set Up Apple Pay and Google Pay for PWA Kit Storefronts]**  
    To help shoppers complete purchases, add Apple Pay and Google Pay to the Shopper Agent messaging sessions. Payment method support is through Adyen. This feature is for B2C Commerce stores that use the Progressive Web App (PWA) Kit.
