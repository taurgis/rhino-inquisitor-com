## Compressed

### Sync a Product Catalog

To synchronize your product catalog with TikTok for Business, you enable a B2C Commerce job to send products to TikTok. Complete this process after you integrate B2C Commerce and TikTok.

1. In Business Manager, click App Launcher  and then select **Administration** > **Operations** > **Jobs**.

2. In the Search field, enter “TikTok-ExportCatalog job.”

   

3. Select and open the TikTok-ExportCatalog job.

4. Select the **Job Steps** tab.

5. Set ProductImageView Type to the view type that is set in the catalog.

   The value can be *large* or *hi-res*.

   

   Find the value in the main catalog image settings.

   

6. Click **Assign**.

7. Select the **Schedule and History** tab.

   

8. Start the job or set a schedule and frequency.

   - To immediately start the job, click **Run Now**.
   - To Schedule the job, complete the Active and Run Time settings and click **Run Now**.

### Sync a Product Catalog

To synchronize your product catalog with TikTok for Business, you enable a B2C Commerce job to send products to TikTok. Complete this process after you integrate B2C Commerce and TikTok.

1. In Business Manager, click App Launcher ![App Launcher](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/shared/appLauncher.png) and then select **Administration** > **Operations** > **Jobs**.

2. In the Search field, enter “TikTok-ExportCatalog job.”

   ![Jobs screen.](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_tiktok\_12.png)

3. Select and open the TikTok-ExportCatalog job.

4. Select the **Job Steps** tab.

5. Set ProductImageView Type to the view type that is set in the catalog.

   The value can be *large* or *hi-res*.

   ![Set ProductImageView Type.](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_tiktok\_13.png)

   Find the value in the main catalog image settings.

   ![Set the value.](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_tiktok\_14.png)

6. Click **Assign**.

7. Select the **Schedule and History** tab.

   ![Select Schedule and History tab.](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_tiktok\_15.png)

8. Start the job or set a schedule and frequency.

   - To immediately start the job, click **Run Now**.
   - To Schedule the job, complete the Active and Run Time settings and click **Run Now**.
