## Summary

Composable Storefront Release Notes > 6/18/2026 > HTTP Proxy Support Is Scheduled for Retirement

## Compressed

### HTTP Proxy Support Is Scheduled for Retirement

Managed Runtime will retire support for HTTP (non-secure) proxy configurations on **August 31, 2026**. After that date, only HTTPS proxy configurations are supported. Update any proxy configurations using HTTP to HTTPS before the retirement date to avoid disruptions.

**Where:** This change applies to Composable Storefronts using Managed Runtime proxies.

**See Also**

- [Proxy Requests]
- [Feature Retirement]
