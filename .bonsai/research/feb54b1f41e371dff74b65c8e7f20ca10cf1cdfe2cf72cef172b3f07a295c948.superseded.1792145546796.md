## Summary

B2C Commerce API Release Notes > 10/08/2026 > SLAS Release

## Compressed

### SLAS Release

- SLAS infrastructure updates for EU-Central. No customer impact is anticipated.
  - Schedule:
    - EU-Central: October 8, 2026 at 5:00 PM MT (11:00 PM UTC)
- mTLS Enforcement
  - To enhance the security of the SLAS authentication service, we’re enabling mutual TLS (mTLS) client-certificate enforcement at the SLAS gateway. Starting October 7, 2026, SLAS rejects any request that reaches the SLAS origin without a valid client certificate, including a request that bypasses the SCAPI zone.
  - Who is affected:
    - No action is required for integrations that use the standard, published Commerce Cloud SLAS endpoints through the SCAPI zone. This path is the supported integration path and continues to work without changes.
    - Action is required for integrations that connect directly to the SLAS origin and bypass the SCAPI zone, for example integrations that use a hardcoded origin hostname, IP address, or custom network path. SLAS rejects these requests after mTLS enforcement is enabled.
  - Schedule:
    - AP2: October 7, 2026
    - AP3: October 8, 2026
    - EU: October 12, 2026
    - US-East: October 15, 2026
