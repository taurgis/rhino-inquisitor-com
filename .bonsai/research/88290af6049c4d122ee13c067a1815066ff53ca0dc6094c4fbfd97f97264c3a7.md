# B2C Commerce Einstein Search Dictionaries

When enabled, Einstein Search Dictionaries consumes all site searches and search-related settings, and surfaces terms that shoppers search for but aren’t in a dictionary.

*   **[How B2C Commerce Einstein Search Dictionaries Works]**  
    Einstein Search Dictionaries automatically detects relationships between search terms and recommends which synonym list to assign them to, driving better search experiences for the shopper. This topic applies to B2C Commerce.
*   **[Share B2C Commerce Einstein Data]**  
    B2C Commerce Einstein Search Dictionaries is the only Einstein feature that enables you to share feature-specific data across the B2C Commerce merchant community.
*   **[Manage B2C Commerce Einstein Dictionary Entries]**  
    Accept, decline, or edit recommendations in Einstein Dictionaries synonym groups.
