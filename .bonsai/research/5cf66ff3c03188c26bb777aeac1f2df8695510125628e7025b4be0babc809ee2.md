Workflow syntax for GitHub Actions > jobs.<jobid>.steps[].wait > Example: Waiting for specific background steps

## Compressed

### Example: Waiting for specific background steps

```yaml
steps:
  - name: Build frontend
    id: build-frontend
    run: npm run build:frontend
    background: true

  - name: Build backend
    id: build-backend
    run: npm run build:backend
    background: true

  - name: Run linter while builds run
    run: npm run lint

  - name: Wait for both builds to finish
    wait: [build-frontend, build-backend]

  - name: Run tests
    run: npm test
```
