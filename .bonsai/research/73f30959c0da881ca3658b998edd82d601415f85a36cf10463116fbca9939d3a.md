## Summary

Configure Multisite URLs > Navigate with Site Context > useNavigate

## Compressed

### useNavigate

Import `useNavigate` from `@/hooks/use-navigate` instead of from React Router. The returned navigate function applies the site and locale prefix automatically.

```typescript
import { useNavigate } from "@/hooks/use-navigate";

function MyComponent() {
  const navigate = useNavigate();

  // Navigate to a prefixed path string
  navigate("/product/123");

  // Navigate to root (resolves to the site/locale homepage, e.g., /global/en-GB/)
  navigate("/");

  // Navigate with an object
  navigate({ pathname: "/product/123", search: "?color=red" });

  // History navigation (back/forward) passes through unchanged
  navigate(-1);
}
```
