### [CVE-2025-61624]

Fortinet Multiple Products Path Traversal Vulnerability: FortiOS, FortiPAM, FortiProxy, and FortiSwitchManager contain a path traversal vulnerability that may allow an authenticated attacker with admin profile and at least read-write permissions to write or delete arbitrary files via specific CLI commands.

*   Known To Be Used in Ransomware Campaigns? **Unknown**

*   Date Added:  2026-10-16
*   Due Date:  2026-10-19

Action: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes).
