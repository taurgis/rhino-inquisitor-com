# Give the Agent Access to the B2C Commerce Shopper API

The Shopper Agent communicates with B2C Commerce by way of the Shopper Login and API Access Service (SLAS). To obtain authorized access to SLAS, create a SLAS client and secret, and use those to obtain a SLAS token.

*   **[Create a SLAS Client]**  
    Create a SLAS client and secret so the agent can obtain an authorization token to access B2C Commerce APIs.
*   **[Create Named Credentials for SLAS Authentication]**  
    SLAS is Salesforce B2C Commerce’s identity and token service for access to headless B2C Commerce APIs. To access a securely stored SLAS client ID and password, set up a named credential for Salesforce to authenticate to the SLAS service. To access public APIs and test public endpoints, also configure a named credential that requires no authentication. Before you can configure a named credential, first configure an associated external credential.
*   **[Assign the B2C Shopper Agent Principal Access]**  
    Create a permission set for the agent that includes principal access. With this access, the Shopper Agent can authenticate with SCAPI and use the connections that you created.

# Give the Agent Access to the B2C Commerce Shopper API

The Shopper Agent communicates with B2C Commerce by way of the Shopper Login and API Access Service (SLAS). To obtain authorized access to SLAS, create a SLAS client and secret, and use those to obtain a SLAS token. The agent uses the token to make authorized calls to SCAPI or OCAPI.

*   **[Create a SLAS Client](https://help.salesforce.com/s/articleView?id=cc.b2c_shopping_agent_create_private_slas_client.htm&language=en_US&type=5#b2c_shopping_agent_create_private_slas_client)**  
    Create a SLAS client and secret so the agent can obtain an authorization token to access B2C Commerce APIs.
*   **[Create Named Credentials for SLAS Authentication](https://help.salesforce.com/s/articleView?id=cc.b2c_shopping_agent_create_named_credentials.htm&language=en_US&type=5)**  
    SLAS is Salesforce B2C Commerce’s identity and token service for access to headless B2C Commerce APIs. To access a securely stored SLAS client ID and password, set up a named credential for Salesforce to authenticate to the SLAS service. To access public APIs and test public endpoints, also configure a named credential that requires no authentication. Before you can configure a named credential, first configure an associated external credential.
*   **[Assign the B2C Shopper Agent Principal Access](https://help.salesforce.com/s/articleView?id=cc.b2c_shopping_agent_create_permission_set.htm&language=en_US&type=5)**  
    Create a permission set for the agent that includes principal access. With this access, the Shopper Agent can authenticate with SCAPI and use the connections that you created.
