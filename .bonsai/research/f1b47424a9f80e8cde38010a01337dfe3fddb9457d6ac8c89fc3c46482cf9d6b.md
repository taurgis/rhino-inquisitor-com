### 4.7 Notation Declarations

\[Definition: **Notations** identify by name the format of [unparsed entities], the format of elements which bear a notation attribute, or the application to which a [processing instruction] is addressed.\]

\[Definition: **Notation declarations** provide a name for the notation, for use in entity and attribute-list declarations and in attribute specifications, and an external identifier for the notation which may allow an XML processor or its client application to locate a helper application capable of processing data in the given notation.\]

XML processors _MUST_ provide applications with the name and external identifier(s) of any notation declared and referred to in an attribute value, attribute definition, or entity declaration. ### 4.7 Notation Declarations

\[Definition: **Notations** identify by name the format of [unparsed entities](https://www.w3.org/TR/xml/#dt-unparsed "Unparsed Entity"), the format of elements which bear a notation attribute, or the application to which a [processing instruction](https://www.w3.org/TR/xml/#dt-pi "Processing instruction") is addressed.\]

\[Definition: **Notation declarations** provide a name for the notation, for use in entity and attribute-list declarations and in attribute specifications, and an external identifier for the notation which may allow an XML processor or its client application to locate a helper application capable of processing data in the given notation.\]

XML processors _MUST_ provide applications with the name and external identifier(s) of any notation declared and referred to in an attribute value, attribute definition, or entity declaration. They _MAY_ additionally resolve the external identifier into the [system identifier](https://www.w3.org/TR/xml/#dt-sysid "System Identifier"), file name, or other information needed to allow the application to call a processor for data in the notation described. (It is not an error, however, for XML documents to declare and refer to notations for which notation-specific applications are not available on the system where the XML processor or application is running.)
