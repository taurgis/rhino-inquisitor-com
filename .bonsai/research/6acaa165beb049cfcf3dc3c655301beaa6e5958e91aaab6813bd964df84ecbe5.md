## Summary

B2C Commerce API Release Notes > 2023 > 05/30/2023

## Compressed

### 05/30/2023

#### Shopper Login (SLAS)

- Updated [TokenResponse], extending the maximum size of `idp_access_token` to 8k bytes.
- [getSessionBridgeAccessToken] supports a new optional parameter `dwsgst`. Its value is a guest session signature created from Script API's `Session.generateGuestSessionSignature()`. Passing this parameter improves the performance of this API.
- [Guest refresh tokens are now valid for 30 days]. *Previously, they were valid for 90 days.*

## Detailed

### 05/30/2023

#### Shopper Login (SLAS)

- Updated [TokenResponse](https://developer.salesforce.com/docs/commerce/commerce-api/references/auth?meta=type%3ATokenResponse), extending the maximum size of `idp_access_token` to 8k bytes.
- [getSessionBridgeAccessToken](https://developer.salesforce.com/docs/commerce/commerce-api/references/auth?meta=getSessionBridgeAccessToken) supports a new optional parameter `dwsgst`. Its value is a guest session signature created from Script API's `Session.generateGuestSessionSignature()`. Passing this parameter improves the performance of this API.
- [Guest refresh tokens are now valid for 30 days](https://developer.salesforce.com/docs/commerce/commerce-api/guide/slas.html#access-tokens-and-refresh-tokens). *Previously, they were valid for 90 days.*
