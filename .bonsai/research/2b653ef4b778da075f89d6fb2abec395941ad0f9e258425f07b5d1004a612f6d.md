## Update: 8 April 2023

I tested Safari 16.4 on macOS 12.6.4 today. No changes.

Meanwhile, Chromium has a change ready to go that will [allow elements with `display:contents` to be focused (3910374)], which is meant to honor CSSWG issue [#2632 stating Elements that have `display: contents` can still be focused…].

David Baron also filed a WebKit bug and requests for Mozilla and WebKit to take a position on `display: contents` focusability specifically:

*   WebKit [Bug 255149 – elements with CSS display:contents are not focusable]
*   [#772 Request for Mozilla Position: focusability of elements with display:contents]
*   WebKit [#164 focusability of elements with CSS display:contents]

## Update: 8 April 2023

I tested Safari 16.4 on macOS 12.6.4 today. No changes.

Meanwhile, Chromium has a change ready to go that will [allow elements with `display:contents` to be focused (3910374)](https://chromium-review.googlesource.com/c/chromium/src/+/3910374), which is meant to honor CSSWG issue [#2632 stating Elements that have `display: contents` can still be focused…](https://github.com/w3c/csswg-drafts/issues/2632#issuecomment-438851770).

David Baron also filed a WebKit bug and requests for Mozilla and WebKit to take a position on `display: contents` focusability specifically:

*   WebKit [Bug 255149 – elements with CSS display:contents are not focusable](https://bugs.webkit.org/show_bug.cgi?id=255149)
*   [#772 Request for Mozilla Position: focusability of elements with display:contents](https://github.com/mozilla/standards-positions/issues/772)
*   WebKit [#164 focusability of elements with CSS display:contents](https://github.com/WebKit/standards-positions/issues/164)
