# 400 Bad Request - Invalid refresh token errors when using plugin\_slas for B2C Commerce

Publish Date: Nov 26, 2024

Description

There are several reasons why **400 Bad Request - Invalid refresh token** are seen in Log Center when using [plugin\_slas] to extend the [Shopper Login and API Access Service (SLAS)].

1.  **Expired Tokens**: Once tokens are expired, they cannot be used for obtaining new access tokens.
    *   **Bot(s)**: A bot could be repeatedly trying to use a **stale, expired, or deleted refresh token**, causing a surge in "400 Bad Request - Invalid Refresh Token" errors. This behavior often results from the bot not properly handling token expiration or deletion, leading to continuous failed requests with invalid tokens.  
        *   If you need assistance identifying the bot, please open a case with Salesforce Support under the **'Commerce-B2C Developer Support'** category for further investigation and assistance.
        *    If you need assistance managing a bot, please review the following steps for further guidance:
            
             [Dealing with possible DDOS and Malicious Bot attacks on a Commerce Cloud B2C site]
            
2.  **Reusing a Refresh Token**: If you're using a public client ID, attempting to reuse a refresh token that has already been used will trigger this error. To avoid this, it's recommended to use a private client ID for the **plugin\_slas.scapi.auth.cred** service which is located under Administration > Operations > Services in Business Manager.
3.  **Change in Client ID**: Since refresh tokens are tied to a specific client ID, changing the client ID associated with **plugin\_slas.scapi.auth.cred** will result in spike in **400 Bad Request - Invalid refresh token** errors. This is expected behavior, and the errors will gradually decrease as shoppers log in again and receive new refresh tokens for the new client ID. To prevent login issues, ensure that the OCAPI settings are updated with the new client ID. If not, the POST /sessions endpoint will fail, preventing shoppers from logging in.
4.  **A Combination of all the above**.

Resolution

When a **400 Bad Request - Invalid refresh token** error occurs, the shopper just needs to log in again.

Additional Resources

There are other configuration related reasons why **400 Bad Request** errors occur.

*   Incorrect client ID being used for the instance. This can be checked via the SLAS Admin UI.
*   For private clients, remember to add the client secret to the **plugin\_slas.scapi.auth.cred** service credentials in the password field.
    *   Note: If you are using public client ID, clear the field.
