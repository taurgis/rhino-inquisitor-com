## Compressed

### React Router Form Actions

React Router's `<Form>` component does **not** go through `buildUrl`.

```typescript
import { Form } from "react-router";
import { buildUrl } from "@/lib/url";
import { useConfig } from "@salesforce/storefront-next-runtime/config";
import { useCurrentSiteAndLocaleRef } from "@salesforce/storefront-next-runtime/site-context";

function SearchForm() {
  const config = useConfig();
  const currentSiteAndLocaleRef = useCurrentSiteAndLocaleRef();

  const action = buildUrl("/action/search", config.app.url, currentSiteAndLocaleRef.current);

  return (
    <Form method="post" action={action}>
      ...
    </Form>
  );
}
```

:::warning Using `<Form action="/some-path">` without prefixing produces a URL without the site/locale prefix, which causes a 404 error. :::

## Detailed

### React Router Form Actions

React Router's `<Form>` component does **not** go through `buildUrl`. If you pass an `action` prop to `<Form>`, you must prefix it manually:

```typescript
import { Form } from "react-router";
import { buildUrl } from "@/lib/url";
import { useConfig } from "@salesforce/storefront-next-runtime/config";
import { useCurrentSiteAndLocaleRef } from "@salesforce/storefront-next-runtime/site-context";

function SearchForm() {
  const config = useConfig();
  const currentSiteAndLocaleRef = useCurrentSiteAndLocaleRef();

  const action = buildUrl("/action/search", config.app.url, currentSiteAndLocaleRef.current);

  return (
    <Form method="post" action={action}>
      ...
    </Form>
  );
}
```

:::warning
Using `<Form action="/some-path">` without prefixing produces a URL without the site/locale prefix, which causes a 404 error.
:::
