## Summary

Composable Storefront Release Notes > 6/24/2026 > Server-Side Cookie Access Is On by Default for New Projects

## Compressed

### Server-Side Cookie Access Is On by Default for New Projects

New projects now have Server-Side Cookie Access enabled by default, letting your storefront access and manage cookies from server-side code as required for personalization and integrations, such as Shopper Agent. Existing projects continue to have server-side cookies turned off by default.

**Where:** This change applies to Managed Runtime and Composable Storefronts.
