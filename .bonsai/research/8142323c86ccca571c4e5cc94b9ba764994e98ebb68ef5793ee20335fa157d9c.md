## Compressed

### Manage Basket Imports with the V2 Shopper Baskets API

Enhance your storefront’s reliability by transitioning to the Shopper Baskets V2 API for basket imports. Update your imports to V2 for all customized template files to prevent cache inconsistencies and keep your basket data synchronized for shoppers.

**Where:** This change applies to Composable Storefronts in B2C Commerce.

**How:** To use the Shopper Baskets V2 aliased hooks, make sure that your B2C Commerce instance supports the Shopper Baskets V2 API, and then update your imports from @salesforce/commerce-sdk-react.

```
// Before:
import {useShopperBasketsMutation} from '@salesforce/commerce-sdk-react'
// After:
import {useShopperBasketsV2Mutation as useShopperBasketsMutation} from '@salesforce/commerce-sdk-react'
```
