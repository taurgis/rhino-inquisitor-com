## Summary

Integrate Page Designer with PWA Kit > Building Leaf Components > Component Metadata

## Compressed

### Component Metadata

Store the metadata in your cartridge at:
`cartridge/experience/components/{group}/{componentId}.json`

```json
{
  "name": "Image Tile",
  "description": "Simple image display component with responsive sources",
  "group": "odyssey_base",
  "arch_type": "headless",
  "region_definitions": [],
  "attribute_definition_groups": [
    {
      "id": "imageTile",
      "name": "Image Tile",
      "attribute_definitions": [
        {
          "id": "image",
          "name": "Image",
          "type": "image",
          "required": true,
          "description": "The image to display"
        }
      ]
    }
  ]
}
```
