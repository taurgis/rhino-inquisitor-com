## Summary

B2C Commerce API Release Notes > 04/16/2025 > SCAPI Release

## Compressed

### SCAPI Release

SCAPI support for the custom [Client IP Header] and [Hybrid Authentication] is now enabled on Sandbox and Development instances. Enablement on Staging and Production instances is being planned.

## Detailed

### SCAPI Release

SCAPI support for the custom [Client IP Header](https://developer.salesforce.com/docs/commerce/commerce-api/guide/client-ip-forwarding.md) and [Hybrid Authentication](https://developer.salesforce.com/docs/commerce/commerce-api/guide/hybrid-auth.md?q=hybrid#hybrid-auth-overview) is now enabled on Sandbox and Development instances. Enablement on Staging and Production instances is being planned.
