# 26.7 Release

This B2C Commerce release occurs between June 23 and July 23, 2026.

*   **[Resolve Issues Faster with Centralized, Multi-channel Alert Management]**  
    Track issues across all Log Center data sources from a unified management page. Create alerts for various activities, such as events, log streaming, and anomaly detection. Expand your notification channels to Slack and PagerDuty to quickly inform technical teams. Reduce notification noise with state-aware alerts that fire when an issue is new, ongoing, or resolved.
*   **[Stream and Download eCDN Logs from Business Manager]**  
    Monitor and troubleshoot your eCDN traffic directly from the Logs tab on the Configure Zones page. Use Logpush to stream HTTP Requests, Firewall Events, or Page Shield Events continuously to Amazon S3, Google Cloud Storage, Azure Blob Storage, Datadog, or Splunk, with up to 2 active jobs per zone. Use Logpull to download request logs from the past 7 days on demand with no destination setup required.
*   **[Track PCI Compliance Alerts for Your eCDN Zone]**  
    Stay informed about PCI compliance status for your eCDN zone directly from the Configure Zones page. The new Notifications tab surfaces PCI alerts so you can monitor compliance without leaving Business Manager.
*   **[Curate Your Product Listings in ChatGPT with the OpenAI Product Feed]**  
    Reach shoppers in ChatGPT by sending a curated product feed to OpenAI. Map B2C Commerce product fields to the channel fields that OpenAI expects, filter which products are included, and preview the feed before turning on the daily sync. Maintain accurate product titles, prices, images, and availability in ChatGPT without writing custom code.
*   **[Manage Content for Site-Wide Regions in Storefront Next with Content Blocks (Beta)]**  
    Manage content for headers and announcement banners consistently across your entire storefront by creating content blocks in site-wide regions. Instead of recreating content that appears across your entire storefront for each individual page, create the content once and apply it everywhere. Maintain brand consistency and save time when updating promotional messages or navigation elements that appear site-wide. Preview your changes directly from Page Designer without switching user interfaces.
*   **[Protect Your Storefront with Hardened File Upload Security]**  
    To improve security, Business Manager now enforces multi-factor authentication (MFA) to import or upload JavaScript files and HTML files that contain scripts. JavaScript and HTML files viewed through WebDAV or the Folder Browser no longer execute within Business Manager, but you can still download them locally.
*   **[Evaluate Promotional Campaigns with Improved A/B Tests]**  
    Test the effectiveness of your promotions by using a streamlined A/B test interface. Set the rank, precedence and priority directly in the Promotions experience of the test segment. Use validated dates during test creation, and view date and time values in your local time zone.
*   **[Create Campaigns for B2C Commerce Storefronts with an Improved UI]**  
    The refreshed campaigns interface for B2C Commerce storefronts makes configuration clearer, and shows date and time values in the site's time zone.
*   **[Manage Category Slicing and Product Variations in Visual Merchandising]**  
    Visual Merchandising is now the central place to complete category-level slicing and see all product variants within a category. Access these common tasks right from the dropdown menu on a product card so you no longer leave the merchandising flow.
*   **[Manage Checkout Integrations with Commerce Apps]**  
    Install and configure Commerce apps for payments, tax, and shipping from the Commerce Apps page in Business Manager. Use one-time setup tasks instead of fragmented manual processes. Monitor integration health, control where Commerce app components appear in your storefront, and view real-time status updates for your checkout providers.
*   **[Deploy Commerce Apps Across Instances with Data Replication]**  
    Install and configure the Commerce App Package (CAP) on a staging instance and then publish the package to production using the new SITE\_COMMERCE\_FEATURE\_STATE replication group. Run code replication before data replication to deploy cartridge dependencies first and prevent run-time errors when configuration tasks reference custom code or hooks.
*   **[Track Granular Replication and Shopper Sign-Ups in Real Time (Pilot)]**  
    The B2C Commerce eventing framework, introduced as a pilot in the 26.6 release, adds four new event types with the 26.7 release. Three granular replication events, `sf.cc.replication.granular.completed`, `sf.cc.replication.granular.failed`, and `sf.cc.replication.granular.incomplete`, report per-object results for products, price tables, and content assets, indicating which individual object IDs succeeded and which failed. A fourth event, `sf.cc.shopper.registered`, fires when a customer profile is created and committed. This event is site-specific, so you can configure a different endpoint for each site.
*   **[Create Person Accounts During Shopper Registration]**  
    When Shopper Profile Sync is turned on, B2C Commerce now creates a person account in the connected Salesforce org in real time when a shopper registers using the B2C Commerce API (SCAPI) or a storefront built with PWA Kit or Storefront Next. This enhancement makes sure that person accounts are immediately available for use in your Salesforce org without waiting for asynchronous Shopper Profile Sync processing.
*   **[Deliver Smarter Search Results with Agentic Commerce Search]**  
    Agentic Commerce Search replaces native keyword search with an AI model trained on your catalog data, shopper behavior, and simulated queries. It ranks products by relevance and conversion, handling natural language, typos, and emerging trends without manual maintenance. With Agentic Commerce Search, you no longer need to maintain synonym lists, stop word lists, and search rules for every edge case.
