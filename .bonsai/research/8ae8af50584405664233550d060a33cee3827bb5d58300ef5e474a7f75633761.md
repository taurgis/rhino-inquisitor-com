## B2C Commerce

B2C Commerce is an enterprise product that resides on realms, separate from the Salesforce platform. You use Business Manager to configure B2C Commerce. The user documentation for B2C Commerce is at [Get Started with B2C Commerce].

## B2B Commerce

B2B Commerce are part of the Commerce application that resides on the Salesforce platform. B2B Commerce run on Salesforce orgs. The user documentation for B2B Commerce is at [Salesforce B2B Commerce].

## B2C Commerce

B2C Commerce is an enterprise product that resides on realms, separate from the Salesforce platform. The realms contain instances on which you develop, test, and deploy your online storefront. You use Business Manager to configure B2C Commerce. The user documentation for B2C Commerce is at [Get Started with B2C Commerce](https://help.salesforce.com/s/articleView?id=cc.b2c_getting_started.htm&language=en_US&type=5).

![Business Manager home page](https://sf-zdocs-cdn-prod.zoominsoftware.com/tdta-commerce-comm-262-0-0-production-enus/e007ecbe-93db-450d-b1cd-e584a22d7cb2/comm/images/comm_bm_ui.png)

## B2B Commerce

B2B Commerce are part of the Commerce application that resides on the Salesforce platform. B2B Commerce run on Salesforce orgs. You manage your B2B store from its home page. The user documentation for B2B Commerce is at [Salesforce B2B Commerce](https://help.salesforce.com/s/articleView?id=commerce.comm_intro.htm&language=en_US&type=5).
