## Customize Existing Business Manager Functionality

Customize certain Business Manager functionality by creating a custom cartridge and modifying specific ISML templates in it. These templates, which override standard Business Manager templates, exist in folders under `/cartridge/templates/default`. Only the Business Manager templates listed here can be customized.

| Folder                                   | Customizable Templates                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| /cartridge/templates/default/application | <ul><li>MenuFrame.isml</li></ul>                                                                                                                                                                                                                                                                                                                                                           |
| /cartridge/templates/default/custom      | <ul><li>modules.isml</li></ul>                                                                                                                                                                                                                                                                                                                                                             |
| /cartridge/templates/default/marketing   | <ul><li>giftcertificateemail.isml</li><li>powerreviewsemail.isml</li></ul>                                                                                                                                                                                                                                                                                                                 |
| /cartridge/templates/default/order       | <ul><li>orderdetails.isml</li><li>orderemailcancellation.isml</li><li>orderemailconfirmation.ismal</li><li>orderemailcss.isml</li><li>orderemailgeneral.isml</li><li>orderemailpaymentconfirmation.isml</li><li>orderemailshippingconfirmation.isml</li><li>paymentdetails.isml</li><li>printordergeneral.isml</li><li>printorderinvoice.isml</li><li>printorderpackingslip.isml</li></ul> |
| /cartridge/templates/default/user        | <ul><li>miniaddress.isml</li><li>minicreditcard.isml</li><li>minishippingaddress.isml</li><li>passwordemail.isml</li></ul>                                                                                                                                                                                                                                                                 |

For example, a merchant conducts business in a region that uses VAT (Value-Added Tax), and wants to print legally valid VAT invoices from the Order page. To implement this functionality, customize the `/cartridge/templates/default/order/printorderinvoice.isml` template to add the required information to the output of the **Print Invoice** button.

Find sample templates by creating a business manager extension cartridge using UX Studio. The `bm_extension.zip` file within this bundle contains the example business manager extension and sample templates.
