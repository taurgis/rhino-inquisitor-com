# How to find tenant information about your B2C Commerce realms

Publish Date: Jul 31, 2025

Description

How obtain tenant information about your B2C Commerce realm including the 4-letter Group ID, the alphanumeric Realm ID, Business Manager instance URLs, and POD number/s using Account Manager, Business Manager, or Support tickets.

Resolution

**Account Manager**

*   The Group ID can be found in [Account Manager] by going to the **Assigned Realms** section of the **Organization** tab which is only viewable to people with the **Account Administrator** role. More information about Account Manager roles can be seen [here].
*   Business Manager Instance URLs can be found for any user who has a scope-specific permission in Account Manager. For example, a user with the **Business Manager Administrator** role can only access an instance on Business Manager if it’s explicitly listed. The general format for Business Manager URLs is https://<instance type>-<region>-<realm name>.demandware.net/on/demandware.store/Sites-Site/.

**Support Ticket**

*   B2C Commerce Cloud Support provides realm information in realm provisioning tickets (when a realm is first created) and in [POD Move] cases (when a realm is migrated to a new POD server).
*   If necessary, you can contact us as outlined in [How to engage Commerce Cloud Support via the Salesforce Help portal].
