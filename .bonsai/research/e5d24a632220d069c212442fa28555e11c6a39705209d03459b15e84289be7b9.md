## Facebook and Instagram Catalog Ads Integration

Salesforce B2C Commerce's integration of Facebook Dynamic Ads allows merchants to quickly and easily get started using the Facebook Dynamic Ads product.

Use the B2C Commerce integration to Facebook Dynamic Ads to embed the Facebook Tracking Pixel into your site and generate a daily product catalog feed, which is exported to Facebook.

The Facebook Pixel integration to support Dynamic Ads now automatically tracks:

- PageView
- ViewContent
- AddToCart
- Purchase

To take advantage of tracking these events, Facebook must be enabled for your site and Facebook Pixel injection must also be enabled.

:::note To enable Facebook integration, contact your B2C Commerce Support representative. :::

To complete integration:

- Business Manager: (done by a user with Admin access to Facebook Business Manager)

  1. Enable Facebook integration – pixel injection for the specified environment (production)

     :::note
     Only one instance of the Facebook pixel is allowed per site. If you previously integrated the pixel, but want to use the Commerce Cloud integration, you must back out the current pixel code. Alternatively, if you want to continue with your existing pixel opt to export only the product catalog to Facebook. Disable Automatically inject Facebook Pixel code in site when you configure the feed in Business Manager.
     :::

  2. Complete the Facebook Business Account settings – You must have access to this information (Facebook Business Account ID, Page ID, Pixel ID. Get this information from the Facebook Business Manager setup.)

  3. Complete the setup of the Product Feed Configuration, including identifying which products are in the feed

     :::note
     You configure Facebook on each instance independently, or use site import or export to copy configuration data from instance to instance. Export and import configuration data of the Facebook integration through site import or export. Customize the feed by performing any necessary post processing using B2C Commerce hooks
     :::

- Facebook Business Manager Activity:

  1. Create a Facebook Business account and accept the Terms and Conditions.

     Create the Facebook Business Account, the Facebook Page, the Facebook Ad Account, and the Facebook Pixel.

  2. Create retargeting campaigns in Facebook Business Manager.

  3. Buy Ads for this campaign
