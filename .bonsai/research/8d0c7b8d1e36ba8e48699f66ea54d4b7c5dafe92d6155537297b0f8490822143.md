## Appendix C Response Demonstrations

In this part of the appendix, we present examples of LLM responses. Table [13](https://arxiv.org/html/2502.12150#A3.T13 "Table 13 ‣ Appendix C Response Demonstrations ‣ Idiosyncrasies in Large Language Models") and [14](https://arxiv.org/html/2502.12150#A3.T14 "Table 14 ‣ Appendix C Response Demonstrations ‣ Idiosyncrasies in Large Language Models") illustrate responses before and after our prompt-level interventions (Section [2.2](https://arxiv.org/html/2502.12150#S2.SS2 "2.2 Controlled Experiments ‣ 2 Evaluating Idiosyncrasies in LLMs ‣ Idiosyncrasies in Large Language Models")). Table [15](https://arxiv.org/html/2502.12150#A3.T15 "Table 15 ‣ Appendix C Response Demonstrations ‣ Idiosyncrasies in Large Language Models") shows the transformed responses when only markdown elements are retained (Section [3.2](https://arxiv.org/html/2502.12150#S3.SS2 "3.2 Markdown Formatting ‣ 3 Concrete Idiosyncrasies in LLMs ‣ Idiosyncrasies in Large Language Models")).

Table [16](https://arxiv.org/html/2502.12150#A3.T16 "Table 16 ‣ Appendix C Response Demonstrations ‣ Idiosyncrasies in Large Language Models") presents the LLM rewritten responses (Section [3.3](https://arxiv.org/html/2502.12150#S3.SS3 "3.3 Semantics ‣ 3 Concrete Idiosyncrasies in LLMs ‣ Idiosyncrasies in Large Language Models")). For paraphrasing, we find that formatting style remains largely unchanged, _e.g_., the number of enumerated lists are the same. Most of the differences lie in their word choices, paraphrased texts use different words with similar meanings but do not change the high-level semantic meaning of the original texts.
