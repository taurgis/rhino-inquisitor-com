# Site-Specific Content in B2C Commerce

_When you use shared library content across your organization, you can, when necessary, keep some of your content assets site-specific._

|  |
| --- |
| Available in: **B2C Commerce** |

For example, you can have certain brand-related data, such as sizing, only appear on sites related to that brand.

Set a content asset to `Offline`, `Not Searchable`, and `Not included in the sitemap` for the `default` site.

1. Click App Launcher _(image: App Launcher)_, and then select **Merchant Tools > *site* > Content > Content Assets**.
2. On the Content page, locate the content and lock it for editing (if necessary).
3. On the Content Asset page, select **Default** for the site.
4. Using the Default setting, set the attributes to Online = **No**, Searchable = **No**, and in the Sitemap Attributes section, Included = **NONE.**
5. Click **Apply**.
6. Click the **Edit Site Specific** button.

   If you don't see this button, you don't have access to multiple sites. Check with your Salesforce admin.
7. On the Site-Specific window, for each of these same attributes, deselect **Use Default**.
8. Select the site (at the top of the window) where you want this asset to appear.
9. Set the attributes to Online = **Yes**, Searchable = **Yes**, and in the Sitemap Attributes section, Included = **1 (YES)**.
10. Click **Apply**.
11. Repeat this process for other sites using this content.
12. On the Content Asset page, click **All Site Values** to see the settings for each site.

# Site-Specific Content in B2C Commerce

_When you use shared library content across your organization, you can, when necessary, keep some of your content assets site-specific._

|  |
| --- |
| Available in: **B2C Commerce** |

For example, you can have certain brand-related data, such as sizing, only appear on sites related to that brand.

Set a content asset to `Offline`, `Not Searchable`, and `Not included in the sitemap` for the `default` site. Then set the asset to `Online,` `Searchable,` and `Included in the sitemap`, for specific sites. See Site-Specific Product Attributes.

1. Click App Launcher _(image: App Launcher)_, and then select **Merchant Tools > *site* > Content > Content Assets**.
2. On the Content page, locate the content and lock it for editing (if necessary).
3. On the Content Asset page, select **Default** for the site.
4. Using the Default setting, set the attributes to Online = **No**, Searchable = **No**, and in the Sitemap Attributes section, Included = **NONE.**
5. Click **Apply**.
6. Click the **Edit Site Specific** button.

   If you don't see this button, you don't have access to multiple sites. Check with your Salesforce admin.
7. On the Site-Specific window, for each of these same attributes, deselect **Use Default**.
8. Select the site (at the top of the window) where you want this asset to appear.
9. Set the attributes to Online = **Yes**, Searchable = **Yes**, and in the Sitemap Attributes section, Included = **1 (YES)**.
10. Click **Apply**.
11. Repeat this process for other sites using this content.
12. On the Content Asset page, click **All Site Values** to see the settings for each site.
