Start by designing your platform to meet your organization's unique business requirements.

Use the Commerce Experience Builder template as the foundational tool for creating personalized commerce environments.

Here are some key topics covered to help you, as a developer, learn the Salesforce Commerce APIs and access the developer resources essential for successfully building a complex B2B sales platform or a direct-to-consumer online store:

1. Data Models:

- Understand the essential data models for commerce applications, which include cart, checkout, product and catalog, product attributes, pricing and promotions, inventory, store, and order processing. Better understanding of these models ensures efficient operations and a seamless user experience in your e-commerce solutions. See [B2B Commerce Data Model].

2. Commerce APIs:

- The B2B Commerce Developer Guide details how to use the Connect Commerce API for managing various e-commerce functions within Salesforce. This API helps integrate and manage web store operations like product catalogs, inventory, customer carts, and order processing. It enables developers to build seamless and robust e-commerce solutions for both B2B settings. See [B2B Commerce APIs].

1. Customization and Extension:

- Learn how to customize and extend your e-commerce solutions using Salesforce's tools and frameworks. This section focuses on enhancing functionality, integrating with services, and tailoring the shopping experience to meet specific business needs.
- B2B Commerce supports extensive customization and integration. Learn various approaches to extend the commerce capabilities of Salesforce, including using APIs to connect with external applications like ERP systems and payment gateways. See [B2B Commerce Extensions].

1. Integrations:

- Explore integration points for B2B Commerce, especially within the cart and checkout experience. Integration services work seamlessly across both B2B stores.
- Predefined flows simplify package integration for tax, shipping, and payment providers for B2B stores created with an LWR template. Understand how integration platforms and various components interact for a B2B store created with the Aura template. See [B2B Commerce Integrations].

1. Payment Processing Setup:

- Learn how to set up a payment gateway and connect it to your checkout process. The guide covers both server-side and client-side payment processing implementations. Last steps in implementing payment processing include connecting the payment gateway to checkout in your store. See [Set Up Payment processing].

6. Building Custom Components Using LWC and LWR:

- Lightning Web Components (LWC) and Lightning Web Runtime (LWR) are innovative technologies from Salesforce that allow for highly customizable and efficient front-end experiences. This guide will walk you through using these technologies to build customized storefronts that are both engaging and fast.
- Learn how to add custom components to your B2B store using an LWR template. Salesforce recommends using the Salesforce Developer Experience (SFDX) environment for building Lightning web components (LWC). See [Build Custom Components].
