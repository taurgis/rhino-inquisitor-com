# Provide Einstein Configurator Access for B2C Commerce

Publish Date: Oct 31, 2024

Description

It is necessary for users to be added to Einstein Configurator as Site Admins in order to add new users since the setup needs to be done in the actual Configurator tool.

Resolution

When a new site is deployed to Einstein, please contact [Commerce Cloud Support] to provide a list of email addresses of the people who require access as a Site Admin for the new site on Einstein Configurator.

**Note:** Current Site Admins can add new users to the Einstein Configurator tool without needing to contact Commerce Cloud Support.

Please follow the steps below to add a new user:

1.  Ensure that the user you wish to add has an active account on Account Manager.
2.  Open [Configurator].
3.  Select Admin Tab > User Management.
4.  In the search field, enter the email address of the user to add. If no search results are found, select "New."
5.  Enter the User name, Role, and Sites for which access is needed.
6.  Once you click "Confirm," another window will open that shows the new user's information & assigned role, sites assigned, actions available as a Site Admin, and the user that set up the access.

  
  
  
Please note that the Configurator Tool is not available until after your site is successfully deployed with the Commerce Cloud Einstein engine.
  
If you are not yet deployed with Einstein, you may contact your Site Administrator and request that they deploy Einstein using the following guide: **[Activate Einstein predictive intelligence]**

### **Additional Information:**

While adding a new user who already has access to another Orgs Einstein, you may encounter the following error message: The email address being added in the Configurator already exists.

A user in CQuotient must have a unique 'User Name' value.

# Provide Einstein Configurator Access for B2C Commerce

Publish Date: Oct 31, 2024

Description

It is necessary for users to be added to Einstein Configurator as Site Admins in order to add new users since the setup needs to be done in the actual Configurator tool.

Resolution

When a new site is deployed to Einstein, please contact [Commerce Cloud Support](https://help.salesforce.com/s/articleView?type=1&id=Updated-experience-when-engaging-Commerce-Cloud-Support-in-the-Salesforce-Help-portal&language=en_US) to provide a list of email addresses of the people who require access as a Site Admin for the new site on Einstein Configurator.

**Note:** Current Site Admins can add new users to the Einstein Configurator tool without needing to contact Commerce Cloud Support.

Please follow the steps below to add a new user:

1.  Ensure that the user you wish to add has an active account on Account Manager.
2.  Open [Configurator](https://configurator.cquotient.com/).
3.  Select Admin Tab > User Management.
4.  In the search field, enter the email address of the user to add. If no search results are found, select "New."
5.  Enter the User name, Role, and Sites for which access is needed.
6.  Once you click "Confirm," another window will open that shows the new user's information & assigned role, sites assigned, actions available as a Site Admin, and the user that set up the access.

  
  
  
Please note that the Configurator Tool is not available until after your site is successfully deployed with the Commerce Cloud Einstein engine.  
  
If you are not yet deployed with Einstein, you may contact your Site Administrator and request that they deploy Einstein using the following guide: **[Activate Einstein predictive intelligence](https://help.salesforce.com/s/articleView?type=1&id=How-to-Setup-Predictive-Intelligence-Data-Einstein-Feed-Process&language=en_US)**

### **Additional Information:**

While adding a new user who already has access to another Orgs Einstein, you may encounter the following error message: The email address being added in the Configurator already exists. Please search for the user in the search box. If you're unable to find the user when searching, please contact Support to have the user added to your specified site  

A user in CQuotient must have a unique 'User Name' value. If an attempt is made to add two users with the same 'User Name', the previous error message will be displayed. However, it is possible to assign multiple sites from different organizations to the same profile, using the **Sites** menu.
