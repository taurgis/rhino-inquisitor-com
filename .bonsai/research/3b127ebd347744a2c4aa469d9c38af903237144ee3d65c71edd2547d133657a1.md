เผยแพร่: 9 มิถุนายน 2026

สร้างเครื่องมือที่มีโครงสร้างเพื่อให้ตัวแทนทำงานได้อย่างมีประสิทธิภาพและแม่นยำ ในเว็บแอปพลิเคชันด้วย [WebMCP]

ใน Chrome 149 คุณสามารถ[ลงชื่อสมัครใช้ช่วงทดลองใช้จากต้นทางของ WebMCP] ได้ หากคุณยังไม่เคยใช้[ช่วงทดลองใช้จากต้นทาง] โปรแกรมเหล่านี้เป็นโปรแกรมที่มีระยะเวลาจำกัดซึ่งให้สิทธิ์ทดลองใช้ฟีเจอร์ทดลองของแพลตฟอร์มก่อนเปิดตัว แม้ว่าอาจมีการจำกัดการใช้งาน แต่นักพัฒนาแอปสามารถผสานรวมฟีเจอร์เหล่านี้เพื่อ การทดสอบแบบเรียลไทม์และรวบรวมความคิดเห็นของผู้ใช้ โดยมีเป้าหมายเพื่อแจ้งให้ทราบถึง การทำซ้ำ API ในอนาคต

## WebMCP คืออะไร

WebMCP ช่วยให้คุณกำหนดกฎสำหรับการโต้ตอบระหว่างเว็บแอปพลิเคชันและเอเจนต์ได้ คุณสามารถประกาศวัตถุประสงค์ขององค์ประกอบอินเทอร์เฟซและจัดการสถานะหน้าเว็บได้แทนที่ Agent จะต้องคาดเดาวัตถุประสงค์ขององค์ประกอบอินเทอร์เฟซ เช่น ปุ่มหรือช่องป้อนข้อมูล

### กรณีการใช้งาน

คุณเพิ่ม WebMCP ลงในเว็บไซต์ได้หลายวิธี เช่น

*   **กรอกแบบฟอร์มที่มีโครงสร้างซับซ้อนอย่างถูกต้อง**: สร้างเครื่องมือ WebMCP เพื่อช่วยให้ผู้ใช้แมปข้อมูลกับช่องได้อย่างถูกต้อง แทนที่จะพึ่งพาการป้อนอัตโนมัติเพียงอย่างเดียว เช่น คุณสามารถแยกความแตกต่างได้ว่าฟิลด์ต้องใช้ชื่อเต็ม หรือชื่อและนามสกุลแยกกัน
*   **การแก้ไขข้อบกพร่องของแอปพลิเคชันอย่างมีประสิทธิภาพ**: สร้างเครื่องมือวินิจฉัยในหน้าการตั้งค่าสำหรับนักพัฒนาแอป เพื่อให้ตัวแทนสามารถเรียกใช้การแก้ไขที่ซ่อนอยู่หลังเมนูที่ซ้อนกัน

นอกจากนี้ คุณยังช่วยให้ตัวแทนเข้าใจอินเทอร์เฟซที่ออกแบบมาสำหรับมนุษย์ได้ด้วย เช่น ข้อมูลปฏิทิน

หากไม่พบกรณีการใช้งานของคุณหรือมีไอเดียที่น่าสนใจสำหรับ WebMCP เข้าร่วม[โปรแกรมทดลองใช้เวอร์ชันแรก]และ แชร์ความคิดเห็น

เป้าหมายของเราคือการสร้าง API ที่เบราว์เซอร์ใดก็ตามที่มีความสามารถในการเป็นตัวแทนสามารถนำไปใช้และรับประโยชน์ได้ อ่าน[เอกสารประกอบของ WebMCP] ซึ่งรวมถึง [แนวทางปฏิบัติแนะนำ]และ [คำแนะนำด้านความปลอดภัยของเครื่องมือ]

*   [เข้าร่วมช่วงทดลองใช้จากต้นทาง]
