## Summary

Page Designer Integration with Storefront Next > Business Manager Setup > Live Preview

## Compressed

### Live Preview

When editing in Page Designer:

1. Business Manager reads the `route` from page metadata.
2. Loads your storefront in an iframe with the appropriate URL.
3. Shows live preview as you configure components.

For the storefront to load inside the Page Designer iframe, the `frame-ancestors` Content Security Policy directive must allow both `'self'` and your Business Manager hostname (for example, `https://your-instance.commercecloud.salesforce.com`). See [Security Response Headers].

:::note Previewing a local development environment in Page Designer isn't supported. For a local development workaround, see [Local Development]. :::

## Detailed

### Live Preview

When editing in Page Designer:

1. Business Manager reads the `route` from page metadata.
2. Loads your storefront in an iframe with the appropriate URL.
3. Shows live preview as you configure components.

For the storefront to load inside the Page Designer iframe, the `frame-ancestors` Content Security Policy directive must allow both `'self'` and your Business Manager hostname (for example, `https://your-instance.commercecloud.salesforce.com`). The default value of `'self'` isn't sufficient. Extend the directive in `config.server.ts`. See [Security Response Headers](/docs/commerce/b2c-commerce/guide/sfnext-security-headers.md).

:::note
Previewing a local development environment in Page Designer isn't supported. To use Page Designer's live preview, deploy your storefront to a Managed Runtime environment. For a local development workaround, see [Local Development](#local-development).
:::
