## Summary

Page Designer Integration with Storefront Next > Generate Cartridges > Automatic Generation on Build

## Compressed

### Automatic Generation on Build

```bash
pnpm build
```

This runs `pnpm cartridge:generate` as part of the build process and does these steps.

1. Scans `src/` for `@Component` and `@PageType` decorators.
2. Extracts metadata from decorators.
3. Generates JSON files in `cartridges/app_storefrontnext_base/cartridge/experience/`.
