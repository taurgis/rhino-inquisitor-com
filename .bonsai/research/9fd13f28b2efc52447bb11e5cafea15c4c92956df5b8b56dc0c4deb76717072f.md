## Steptypes.xml Definition File

Custom Step Types can be registered in the system with a `steptypes.xml` file. Within this file, you describe the step types of the cartridge, their parameters, and status codes.

The file must be named `steptypes.xml` and placed in a custom cartridge in the **root** folder. Each cartridge supports only **one** `steptypes.xml` file.

```
my_cartridge
├── cartridge
│   ├── controllers
│   ├── scripts
│   ├── (other cartridge folders)
│   └── my_cartridge.properties
└── steptypes.xml
```

The `steptypes.xml` file requires a specific XML syntax. A typical error message for an invalid `steptypes.xml` file is: `Invalid step [Step1]! Type with id [custom.MyCustomStep1] is unknown!`.

:::warning Each cartridge supports either a `steptypes.xml` or a `steptypes.json` file.

:::note The usage of `steptypes.xml` file should avoided.

## Steptypes.xml Definition File

Custom Step Types can be registered in the system with a `steptypes.xml` file. Within this file, you describe the step types of the cartridge, their parameters, and status codes.

The file must be named `steptypes.xml` and placed in a custom cartridge in the **root** folder. Each cartridge supports only **one** `steptypes.xml` file.

```
my_cartridge
├── cartridge
│   ├── controllers
│   ├── scripts
│   ├── (other cartridge folders)
│   └── my_cartridge.properties
└── steptypes.xml
```

The `steptypes.xml` file requires a specific XML syntax. If a `steptypes.xml` file contains errors, the errors are logged and the custom step types aren't registered. The system then loads step types from the `steptypes.xml` files of other cartridges.
A typical error message for an invalid `steptypes.xml` file is:
`Invalid step [Step1]! Type with id [custom.MyCustomStep1] is unknown!`.

:::warning
Each cartridge supports either a `steptypes.xml` or a `steptypes.json` file. Having both files in the same cartridge isn't supported.
:::

:::note
The usage of `steptypes.xml` file should avoided. Use the `steptypes.json` file instead and migrate the `steptypes.xml` to `steptypes.json`.
:::
