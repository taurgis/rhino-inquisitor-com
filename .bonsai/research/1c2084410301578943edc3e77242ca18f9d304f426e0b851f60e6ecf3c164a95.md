## Compressed

### Component Attribute Types and Resolved Value Objects

The content attributes from the `context` object (the content dictionary) are defined in a map. Attribute IDs are keys, and resolved values are values. A resolved value has been converted to B2C Commerce API objects when needed. Strings don't need conversion. The following table lists content attribute types and their B2C Commerce API objects.

| Content Attribute Type | B2C Commerce API Value    |
| ---------------------- | ------------------------- |
| category               | dw.catalog.Category       |
| cms_record             | dw.experience.CMSRecord   |
| custom                 | dw.util.Map               |
| file                   | dw.content.MediaFile      |
| image                  | dw.experience.image.Image |
| page                   | dw.experience.Page        |
| product                | dw.catalog.Product        |

## Detailed

### Component Attribute Types and Resolved Value Objects

The content attributes from the `context` object (the content dictionary) are defined in a map. Attribute IDs are keys, and resolved values are values. A resolved value has been converted to B2C Commerce API objects when needed. For example, a product attribute (product SKU) becomes a `dw.catalog.Product` instance. Strings don't need conversion. The following table lists content attribute types and their B2C Commerce API objects.

| Content Attribute Type | B2C Commerce API Value    |
| ---------------------- | ------------------------- |
| category               | dw.catalog.Category       |
| cms_record             | dw.experience.CMSRecord   |
| custom                 | dw.util.Map               |
| file                   | dw.content.MediaFile      |
| image                  | dw.experience.image.Image |
| page                   | dw.experience.Page        |
| product                | dw.catalog.Product        |
