# 25.3 Release

The B2C Commerce 25.3 release occurs February 25, 2025 through March 20, 2025.

Stay current with all the important B2C Commerce product updates by reviewing the release notes

To review past release notes, check out the [B2C Commerce Release Notes Archive].

Note Find Bug Fix Information in Salesforce Known Issues

Information about customer-reported issues and notifications about bug fixes is now published in [Salesforce Known Issues]. The B2C Commerce Release Notes continue to provide information about new features and major feature enhancements.

*   **[Configure PCI 4.0 Compliance with eCDN PCI Tools]**  
    The B2C Commerce eCDN PCI tools now include Page Shield. Page Shield helps you manage resources loaded by your website visitors. Your security team is notified with an alert when a script is changed or is flagged as malicious. You can also access policy violations via LogCenter and stream using logpush.
*   **[Set Authorization Methods for Password-Protected Storefronts]**  
    Business Manager administrators now have more options for managing access to a password-protected storefront. Administrators can select, the authentication method that’s best suited for their storefront.
*   **[Ingest Registered Shopper Profiles into Data Cloud]**  
    You can now export registered shopper profiles for specific sites as well as profiles modified after a certain date. The exported shopper profiles are then ingested into Data Cloud using the B2C Commerce Connector.
*   **[Augment the Customer Shopping Experience with an AI-Powered Assistant]**  
    Agentforce for Guided Shopping helps your store’s customers find the products they need to make informed purchase decisions. The generative AI-powered agent provides personalized, real-time guidance throughout the shopping journey, from product discovery to checkout and retrieving order details.
*   **[Stream Security Logs for Enhanced Monitoring]**  
    Log Center now supports streaming security logs to third-party aggregation tools like Splunk, Datadog, New Relic, Grafana Loki, or a generic HTTP connection. This integration enhances your monitoring and automation capabilities, ensuring better security and compliance.
*   **[Provide a Reason for Restarting Your Commerce Cloud Instance]**  
    B2C Commerce Control Center now requires you to enter a reason when you initiate the restart of a B2C Commerce instance. Reasons are recorded to help improve the reliability of our infrastructure.
