## Compressed

### Build B2C Storefronts Faster with the B2C DX MCP Server (Generally Available)

The B2C DX Model Context Protocol (MCP) is now generally available. Use the B2C DX MCP to enhance your development workflow by connecting an AI assistant, such as Claude, Cursor, or GitHub Copilot, to your B2C Commerce environment. The new B2C DX MCP server is a unified MCP that is the starting point for various development tools and storefronts. The B2C DX MCP server provides your AI assistant with real-time access to B2C Commerce APIs (SCAPI), storefront development, cartridge deployment, and Managed Runtime (MRT) deployments.
