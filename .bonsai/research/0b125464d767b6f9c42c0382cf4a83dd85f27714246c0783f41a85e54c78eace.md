## Compressed

### 6. How It Works

With this setup:

1. **Your existing routes work automatically** - No special page-viewer route needed
2. **Page Designer loads your actual routes** - When you edit a page with `"route": "/"`, Page Designer loads your homepage at `/`
3. **Live editing** - Changes in Page Designer's visual editor appear instantly in your PWA Kit storefront
4. **Hybrid support** - Mix headless and ISML pages during migration

**Example**: If you create a homepage with:

```json
{
    "name": "Home Page",
    "arch_type": "headless",
    "route": "/",
    "region_definitions": [...]
}
```

Page Designer:

- Loads your PWA Kit site's homepage (`/`).
- Renders it in an iframe for editing.
- Applies changes in real-time.
