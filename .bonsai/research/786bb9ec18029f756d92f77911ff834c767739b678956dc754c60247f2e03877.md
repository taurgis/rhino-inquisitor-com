### 3.1 Multi-dimensional analysis

We based our analysis on the Multidimensional Analysis (MDA) to English texts using the classic framework developed by [Biber, 1988a], which defines six functional dimensions of register variation (see [1]) based on co-occurrence patterns among 67 lexico-grammatical features.

Table 1: Biber’s (1988) six dimensions of register variation.

For Czech, we adopted the multidimensional analysis model developed by [Cvrček et al., 2020a]; [Cvrček et al., 2018a], which is based on factor analysis over 137 linguistic features extracted from the diversified Koditex corpus ([Zasina et al., 2018a]). This model identifies eight underlying dimensions of register variation specific to Czech (see [2]). Factor scores for each text were obtained using the MDA tagging pipeline [Cvrček et al., 2020a]; [Cvrček et al., 2018a], enabling the placement of Czech texts into this 8-dimensional space.

## Detailed

### 3.1 Multi-dimensional analysis

We based our analysis on the Multidimensional Analysis (MDA) to English texts using the classic framework developed by [Biber, 1988a](https://arxiv.org/html/2509.10179#biba.bibx5), which defines six functional dimensions of register variation (see [1](https://arxiv.org/html/2509.10179#S3.T1 "Table 1 ‣ 3.1 Multi-dimensional analysis ‣ 3 Analysis methods ‣ Benchmark of stylistic variation in LLM-generated texts")) based on co-occurrence patterns among 67 lexico-grammatical features. To operationalize the original framework on our corpora, we employed Andrea Nini’s Multidimensional Analysis Tagger (MAT), a tool that replicates Biber’s tagging scheme and outputs factor scores for each text ([Nini, 2019a](https://arxiv.org/html/2509.10179#biba.bibx25)).

Table 1: Biber’s (1988) six dimensions of register variation.

For Czech, we adopted the multidimensional analysis model developed by [Cvrček et al., 2020a](https://arxiv.org/html/2509.10179#biba.bibx11); [Cvrček et al., 2018a](https://arxiv.org/html/2509.10179#biba.bibx10), which is based on factor analysis over 137 linguistic features extracted from the diversified Koditex corpus ([Zasina et al., 2018a](https://arxiv.org/html/2509.10179#biba.bibx38)). This model identifies eight underlying dimensions of register variation specific to Czech (see [2](https://arxiv.org/html/2509.10179#S3.T2 "Table 2 ‣ 3.1 Multi-dimensional analysis ‣ 3 Analysis methods ‣ Benchmark of stylistic variation in LLM-generated texts")). Factor scores for each text were obtained using the MDA tagging pipeline [Cvrček et al., 2020a](https://arxiv.org/html/2509.10179#biba.bibx11); [Cvrček et al., 2018a](https://arxiv.org/html/2509.10179#biba.bibx10), enabling the placement of Czech texts into this 8-dimensional space.

Table 2: Dimensions of register variation in Czech (Cvrček et al., 2021).
