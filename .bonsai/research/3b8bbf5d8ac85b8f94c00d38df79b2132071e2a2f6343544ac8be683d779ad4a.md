### [CVE-2023-22894](https://www.cve.org/CVERecord?id=CVE-2023-22894)

Strapi Cleartext Storage of Sensitive Information Vulnerability: Strapi contains a cleartext storage of sensitive information vulnerability that could allow attackers with access to the admin panel to discover sensitive user details via the query filter. The impacted product(s) could be end-of-life (EoL) and/or end-of-service (EoS). Users are advised to discontinue use and/or transition to a supported version. This vulnerability can be chained with CVE-2023-22621 to achieve remote code execution.
