### [CVE-2026-105134]

Ahsay AhsayCBS Command Injection Vulnerability: Ahsay AhsayCBS contains a command injection vulnerability that could allow a remote attacker to execute operating system commands via manipulation of the random parameter in the Replication Receiver component’s /rps/api/json/UpdateReceivers.do endpoint.
