## Summary

Required conditions for origin trials > The token is still valid

## Compressed

### The token is still valid

Tokens are valid for six weeks after they're created.

You can check for active tokens on your Chrome Origin Trials [My Registrations page]:

![Chrome origin trials My Registrations page showing Valid Until date](/static/docs/web-platform/origin-trial-troubleshooting/image/chrome-origin-trials-re-c6d7c3d70c565.png)

Chrome DevTools displays Status `Success` if the token is still valid:

![Chrome DevTools origin trials information in the Application panel, highlighting Status: Success.](/static/docs/web-platform/origin-trial-troubleshooting/image/chrome-devtools-origin-t-b3655b356f3ff.png)

If your token has expired, DevTools displays the status `Expired` and your [My Registrations page] displays an **Expired Tokens** section.

![Chrome origin trials My Registrations page showing expired tokens.](/static/docs/web-platform/origin-trial-troubleshooting/image/chrome-origin-trials-re-b7635b714dfed.png)

## Detailed

### The token is still valid

Tokens are valid for six weeks after they're created. Beyond that, you must submit feedback in order to extend the **Valid Until** date. [Origin Trials Guide for Web Developers](https://github.com/GoogleChrome/OriginTrials/blob/gh-pages/developer-guide.md#22-how-do-i-keep-my-tokens-active-for-the-entire-trial) explains how to make sure your token is valid for an entire origin trial.

You can check for active tokens on your Chrome Origin Trials [My Registrations page](https://developer.chrome.com/origintrials#/trials/my):

![Chrome origin trials 
My Registrations page showing Valid Until date](/static/docs/web-platform/origin-trial-troubleshooting/image/chrome-origin-trials-re-c6d7c3d70c565.png)

Chrome DevTools displays Status `Success` if the token is still valid:

![Chrome DevTools 
origin trials information in the Application panel, highlighting Status: Success.](/static/docs/web-platform/origin-trial-troubleshooting/image/chrome-devtools-origin-t-b3655b356f3ff.png)

If your token has expired, DevTools displays the status `Expired` and your [My Registrations page](https://developer.chrome.com/origintrials#/trials/my) displays an **Expired Tokens** section.

![Chrome origin trials 
My Registrations page showing expired tokens.](/static/docs/web-platform/origin-trial-troubleshooting/image/chrome-origin-trials-re-b7635b714dfed.png)
