# Build Modern Shopping Experiences with PWA Kit

The Progressive Web App (PWA) Kit is a new storefront technology for headless commerce using Salesforce Commerce APIs and React. It provides front-end developers with a more flexible and agile approach to build and maintain modern shopping experiences. This release focuses on localization updates and improvements related to SEO, performance, and shopper experience.

**Where:** Available to all Salesforce B2C Commerce customers.

**When:** March 3rd, 2023

**Why:** Each change has a numbered link to the relevant pull request in the open-source repository.

**Featured Changes**

*   Initial release of Page Designer page rendering support in `template-retail-react-app`.
*   Support for product-set product types in `template-retail-react-app`.
*   Support for Node 16 across the board for PWA Kit

**Changes to commerce-sdk-react-preview**

*   Add Page/Region/Component components for shopper experience/page designer page rendering [#963](https://github.com/SalesforceCommerceCloud/pwa-kit/pull/963).
*   Namespace `Auth` storage keys with site identifier to allow multi-site support [#911](https://github.com/SalesforceCommerceCloud/pwa-kit/pull/911).
*   Add Shopper Experience `usePage` and `usePages` hooks[#958](https://github.com/SalesforceCommerceCloud/pwa-kit/pull/958).
*   Refactors and security package updates.

**Changes to pwa-kit-dev**

*   Add explicit `ws` dependency [#865](https://github.com/SalesforceCommerceCloud/pwa-kit/pull/865).
*   Security package updates.

**Changes to pwa-kit-runtime**

*   Support Node 16 [#965](https://github.com/SalesforceCommerceCloud/pwa-kit/pull/965).
*   Security package updates.

**Changes to template-retail-react-app**

*   Add Page Designer ImageTile component [#967](https://github.com/SalesforceCommerceCloud/pwa-kit/pull/967).
*   Add Page Designer ImageWithText component [#991](https://github.com/SalesforceCommerceCloud/pwa-kit/pull/991).
*   Add Page Designer carousel component [#977](https://github.com/SalesforceCommerceCloud/pwa-kit/pull/977).
*   Add Page Designer layout components [#993](https://github.com/SalesforceCommerceCloud/pwa-kit/pull/993).
*   Support the product-set type [#1019](https://github.com/SalesforceCommerceCloud/pwa-kit/pull/1019).

**New Contributors**

*   Thanks [@breadadams](https://github.com/breadadams) for your first contribution in [#950](https://github.com/SalesforceCommerceCloud/pwa-kit/pull/950).

**Full Changelog**

*   [v2.6.0...v2.7.0](https://github.com/SalesforceCommerceCloud/pwa-kit/compare/v2.6.0...v2.7.0)

**How:** The PWA Kit is available as an open-source project on GitHub. To get started, see the documentation on the [Salesforce Developers](https://developer.salesforce.com/docs/commerce/pwa-kit-managed-runtime/guide/getting-started.html) site.
