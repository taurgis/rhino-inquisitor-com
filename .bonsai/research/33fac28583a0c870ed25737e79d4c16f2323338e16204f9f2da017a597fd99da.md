## Compressed

### Managed Runtime - Log Center Logs for ODS and SIG Instances

Previously, you could view logs [in Log Center] for only production environments associated with primary instance group (PIG) instances. Now you can view logs for secondary instance group (SIG) and on-demand sandbox (ODS) instances. These new logs count towards [log volume limits].

## Detailed

### Managed Runtime - Log Center Logs for ODS and SIG Instances

Previously, you could view logs [in Log Center](/docs/commerce/b2c-commerce/guide/debugging.html#debug-using-log-center) for only production environments associated with primary instance group (PIG) instances. Now you can view logs for secondary instance group (SIG) and on-demand sandbox (ODS) instances. These new logs count towards [log volume limits](https://help.salesforce.com/s/articleView?id=cc.b2c_configuration_for_administrators.htm\&type=5).
