## Compressed

## Tells Appear and Disappear Between Model Versions

Consecutive versions within the same model family can have substantially different tells. Between the two latest versions of each model family, 55% to 72% of tells are unique to one version. A tell associated with one model version may disappear in the next, while new tells often appear.

The model versions shown below are ordered separately for each model family and were not necessarily released at the same time.
