## Detailed

### 4.2 Metrics

We evaluate judge reliability by measuring the agreement between model-produced judgments and reference judgments using accuracy, Spearman’s rank correlation, and Kendall’s τb\\tau\_{b}. Unless otherwise specified, each metric is computed within a query group and then averaged across groups. Accuracy is used as the main metric in our experiments.

Accuracy. We compute accuracy as the agreement between predicted judgments and reference judgments. Depending on the dataset, the judgment unit is either a preference decision or a correctness decision. For preference-based datasets, we convert both model judgments and reference judgments into pairwise preferences. For a query qq with candidate outputs {yq,1,…,yq,K}\\{y\_{q,1},\\ldots,y\_{q,K}\\}, let 𝒫q\\mathcal{P}\_{q} denote the set of all valid candidate pairs. For each pair (a,b)∈𝒫q(a,b)\\in\\mathcal{P}\_{q}, let zq,a,b∗z^{\*}\_{q,a,b} and z^q,a,b\\hat{z}\_{q,a,b} denote the reference and predicted preferences, respectively. The predicted preference is obtained directly in pairwise evaluation, by comparing candidate scores in pointwise evaluation, and by comparing candidate ranks in listwise evaluation. We compute preference accuracy as

|  | Accq=1\|𝒫q\|∑(a,b)∈𝒫q𝕀[z^q,a,b=zq,a,b∗],\mathrm{Acc}_{q}=\frac{1}{\|\mathcal{P}_{q}\|}\sum_{(a,b)\in\mathcal{P}_{q}}\mathbb{I}[\hat{z}_{q,a,b}=z^{*}_{q,a,b}], |  | (6) |
| --- | --- | --- | --- |

where a prediction is considered correct only when it exactly matches the reference preference, including cases where both the reference and prediction indicate a tie. To reduce position bias in pairwise evaluation, we evaluate each pair in both answer orders and average the two results.

For correctness-based datasets such as VerifyBench, the reference label indicates whether the final answer is correct. We therefore compute accuracy directly as label agreement over all instances.

Spearman’s rank correlation. Given reference scores 𝐬q∗\=(sq,1∗,…,sq,K∗)\\mathbf{s}^{\*}\_{q}=(s^{\*}\_{q,1},\\ldots,s^{\*}\_{q,K}) and judge scores 𝐬^q\=(s^q,1,…,s^q,K)\\hat{\\mathbf{s}}\_{q}=(\\hat{s}\_{q,1},\\ldots,\\hat{s}\_{q,K}) for query qq, we first convert them into ranks:

|  | rq,k∗=rank⁡(sq,k∗),r^q,k=rank⁡(s^q,k).r^{*}_{q,k}=\operatorname{rank}(s^{*}_{q,k}),\qquad\hat{r}_{q,k}=\operatorname{rank}(\hat{s}_{q,k}). |  | (7) |
| --- | --- | --- | --- |

Spearman’s rank correlation is computed as

|  | ρq=∑k=1K(r^q,k−r^¯q)​(rq,k∗−r¯q∗)∑k=1K(r^q,k−r^¯q)2​∑k=1K(rq,k∗−r¯q∗)2,\rho_{q}=\frac{\sum_{k=1}^{K}(\hat{r}_{q,k}-\bar{\hat{r}}_{q})(r^{*}_{q,k}-\bar{r}^{*}_{q})}{\sqrt{\sum_{k=1}^{K}(\hat{r}_{q,k}-\bar{\hat{r}}_{q})^{2}}\sqrt{\sum_{k=1}^{K}(r^{*}_{q,k}-\bar{r}^{*}_{q})^{2}}}, |  | (8) |
| --- | --- | --- | --- |

where r^¯q\\bar{\\hat{r}}\_{q} and r¯q∗\\bar{r}^{\*}\_{q} denote the mean ranks of the judge scores and reference scores, respectively.

Kendall’s rank correlation. We report Kendall’s τb\\tau\_{b} to account for tied rankings. For each query qq, we compare the pairwise ordering induced by the judge scores s^\\hat{s} with that induced by the reference scores s∗s^{\*}. Let CqC\_{q} and DqD\_{q} be the numbers of concordant and discordant candidate pairs, respectively, and let Ts^,qT\_{\\hat{s},q} and Ts∗,qT\_{s^{\*},q} be the numbers of tied pairs that occur only in the judge scores and only in the reference scores. |  | τb,q=Cq−Dq(Cq+Dq+Ts^,q)​(Cq+Dq+Ts∗,q).\tau_{b,q}=\frac{C_{q}-D_{q}}{\sqrt{(C_{q}+D_{q}+T_{\hat{s},q})(C_{q}+D_{q}+T_{s^{*},q})}}. |  | (9) |
