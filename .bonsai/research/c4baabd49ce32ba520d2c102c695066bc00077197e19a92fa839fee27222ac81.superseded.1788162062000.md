## Compressed

### Component Metadata

Store the metadata in your cartridge at:
`cartridge/experience/components/{group}/{componentId}.json`

```json
{
  "name": "Mobile Grid 2x1",
  "description": "2 row x 1 column grid on mobile, 1 row x 2 column on desktop",
  "group": "odyssey_base",
  "arch_type": "headless",
  "region_definitions": [
    {
      "id": "region1",
      "name": "First Region"
    },
    {
      "id": "region2",
      "name": "Second Region"
    }
```
