## Summary

B2C Commerce API Release Notes > 01/27/2026 > SCAPI Release

## Compressed

### SCAPI Release

- Starting with B2C Commerce version 26.2:
  - Enhanced SCAPI verbose logging in LogCenter when `sfdc_verbose` is enabled.
    - Logged information now includes request latency for Custom APIs along with existing details.
    - Added service runtimes with request latency for granular performance tracking.
  - Checkout API updates:
    - [Orders] - 1.4.13 documentation update
    - [Shopper Basket V1] - 1.9.2 documentation update
    - [Shopper Basket V2] - 2.3.3
      - Added the new query parameter `populateCustomerDetails` to the `createBasket` and `transferBasket` endpoints.
      - Added fields in the `/baskets/{}/paymentInstruments` POST request for SalesforcePayments.
      - Added fields in the Basket schema for Salesforce Payments ( Basket → PaymentInstrument).
    - [Shopper Payments] - 1.2.1 documentation update
    - [Shopper Orders] - 1.9.0
      - Added a fail order endpoint: `/orders/{}/actions/fail`
      - Added fields in the Order schema response for SalesforcePayments (Order → PaymentInstrument).
      - Added fields in the `/orders/{}/paymentInstruments` PATCH request for SalesforcePayments.
      - Added the `expand = oms` and `oms` fields.
- Starting with B2C Commerce version 26.1, Agent/OOBO is supported out of the box in Hybrid Auth with PWA Kit when using the Customer Service Center in Business Manager. See [Hybrid Authentication].
