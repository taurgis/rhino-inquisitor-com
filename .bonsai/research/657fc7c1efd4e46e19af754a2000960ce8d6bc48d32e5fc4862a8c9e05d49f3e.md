## Summary

Third-Party Applications > Facebook and Instagram Shop Ads Integration > Configure Facebook and Instagram Business Manager Permissions

## Compressed

### Configure Facebook and Instagram Business Manager Permissions

1. Log in to Business Manager.
2. Click App Launcher  and then select **Administration** > **Organization** > **Roles & Permissions**.
3. Select the role of your Business Manager user(s).
4. Select the **Business Manager Modules** tab.
5. Select the specified Sites under **Sites**, for example: RefArch and RefArchGlobal.
6. Select **Apply**.
   
7. For **Custom Objects**, select the *write* checkbox for `Custom Object Editor`.
   
8. For **Social Channels**, select the *write* checkbox for `Facebook and Instagram`.
   
9. Select **Update**.
10. In the **Business Manager Modules** tab, switch the context to **Organization**.
11. Select **Apply**.
    
12. For **Operations**, select the *write* checkbox for `Jobs`.
13. For **Operations**, select the *write* checkbox for `Job History`.
    
14. For **Social Product Feeds**, select the *write* checkbox for **Social Product Feeds Definition**.
    
15. Select **Update**.
16. Select the **WebDAV Permissions** tab.
17. Scroll to the **Impex** section.
18. Select the **Manage custom folders** link.
19. In the text box, enter: `src/feeds/export`.
    
20. Select **Apply**.
21. For **Impex**, select the *write* checkbox for `/impex/src/feeds/export/*`.
    
22. Select **Update**.

## Detailed

### Configure Facebook and Instagram Business Manager Permissions

1. Log in to Business Manager.
2. Click App Launcher ![App Launcher](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/shared/appLauncher.png) and then select **Administration** > **Organization** > **Roles & Permissions**.
3. Select the role of your Business Manager user(s).
4. Select the **Business Manager Modules** tab.
5. Select the specified Sites under **Sites**, for example: RefArch and RefArchGlobal.
6. Select **Apply**.
   ![Select Context Sites](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_bus_mgr_select_context_sites.png)
7. For **Custom Objects**, select the *write* checkbox for `Custom Object Editor`.
   ![Select Custom Objects](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_bus_mgr_role_custom_object_editor.png)
8. For **Social Channels**, select the *write* checkbox for `Facebook and Instagram`.
   ![Select Social Channels](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_bus_mgr_role.png)
9. Select **Update**.
10. In the **Business Manager Modules** tab, switch the context to **Organization**.
11. Select **Apply**.
    ![Select Organization](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_bus_mgr_select_context_org.png)
12. For **Operations**, select the *write* checkbox for `Jobs`.
13. For **Operations**, select the *write* checkbox for `Job History`.
    ![Select Operations](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_bus_mgr_role_jobs.png)
14. For **Social Product Feeds**, select the *write* checkbox for **Social Product Feeds Definition**.
    ![Select Social Product Feeds](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_bus_mgr_role_social_product_feeds_definition.png)
15. Select **Update**.
16. Select the **WebDAV Permissions** tab.
17. Scroll to the **Impex** section.
18. Select the **Manage custom folders** link.
19. In the text box, enter: `src/feeds/export`.
    ![Select WebDAV custom folders](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_bus_mgr_role_webdav_manage_custom_folders.png)
20. Select **Apply**.
21. For **Impex**, select the *write* checkbox for `/impex/src/feeds/export/*`.
    ![Select WebDAV path](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_bus_mgr_role_webdav_permissions.png)
22. Select **Update**.
