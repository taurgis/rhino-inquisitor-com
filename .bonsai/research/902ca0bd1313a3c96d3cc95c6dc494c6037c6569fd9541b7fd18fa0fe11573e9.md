## Detailed

### K.4 Stage 4: Environment Scaling

The domain creation stage produced one work environment per domain. In this stage, we scaled to six work environments per domain by finding five additional seed documents and creating edit tasks for each. The process follows three sub-steps.

Find Seed Documents. For each domain, we searched for diverse real-world documents using GitHub code search, public data portals, and open-source project repositories. Diversity was explicitly targeted along four axes: subject matter, structural complexity, size within the 2–5k token range, and authorship style. Each candidate was validated against the document desiderata ([Table A5](https://arxiv.org/html/2604.15597#A14.T5 "Table A5 ‣ Appendix N Document Desiderata ‣ LLMs Corrupt Your Documents When You Delegate")), tested for parser compatibility, and documented with full provenance.

Brainstorm Edits. Edit tasks for the new work environments were generated using persona-driven ideation, following the same approach as the initial domain creation.
