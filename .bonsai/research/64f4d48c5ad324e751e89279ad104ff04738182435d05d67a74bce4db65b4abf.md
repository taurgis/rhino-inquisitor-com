# Build Modern Shopping Experiences with PWA Kit (Generally Available)

The Progressive Web App (PWA) Kit is a new storefront technology for headless commerce using Salesforce Commerce APIs and React.

**Where:** Available to all Salesforce B2C Commerce customers.

**When:** September 8, 2021

**Why:** Features of PWA Kit 1.0.0 include:

*   Integration with Commerce APIs and Open Commerce API (OCAPI)
*   Cross-device shopper authentication with the Shopper Login and Access Service (SLAS)
*   Responsive design optimized for mobile, tablet, and desktop
*   Category-based navigation with breadcrumbs
*   Product search and product listing, including filtering
*   Cart and wishlist management
*   Account management, including saved payments, saved addresses, and order history
*   Handling of promotions and coupon codes
*   Streamlined, single-page checkout, including guest and registered shopper flows
*   Einstein product recommendations displayed throughout the shopper journey
*   Locale switching and display of localized content

**How:** The PWA Kit is available as an open-source project on GitHub.

The underlying Commerce APIs and Open Commerce APIs don’t allow public clients, like PWA Kit, to reset passwords and look up orders for guest shoppers. Projects must use a custom API to handle guest password reset verification logic and email sending and guest order lookup.

# Build Modern Shopping Experiences with PWA Kit (Generally Available)

The Progressive Web App (PWA) Kit is a new storefront technology for headless commerce using Salesforce Commerce APIs and React. It provides front-end developers with a more flexible and agile approach to build and maintain modern shopping experiences.

**Where:** Available to all Salesforce B2C Commerce customers.

**When:** September 8, 2021

**Why:** Features of PWA Kit 1.0.0 include:

*   Integration with Commerce APIs and Open Commerce API (OCAPI)
*   Cross-device shopper authentication with the Shopper Login and Access Service (SLAS)
*   Responsive design optimized for mobile, tablet, and desktop
*   Category-based navigation with breadcrumbs
*   Product search and product listing, including filtering
*   Cart and wishlist management
*   Account management, including saved payments, saved addresses, and order history
*   Handling of promotions and coupon codes
*   Streamlined, single-page checkout, including guest and registered shopper flows
*   Einstein product recommendations displayed throughout the shopper journey
*   Locale switching and display of localized content

**How:** The PWA Kit is available as an open-source project on GitHub. To get started, go to the [Commerce Cloud Developer Center](https://developer.commercecloud.com/s/article/PWA-Kit).

The underlying Commerce APIs and Open Commerce APIs don’t allow public clients, like PWA Kit, to reset passwords and look up orders for guest shoppers. Projects must use a custom API to handle guest password reset verification logic and email sending and guest order lookup.
