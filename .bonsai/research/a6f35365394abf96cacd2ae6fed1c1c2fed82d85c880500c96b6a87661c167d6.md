### PWA Kit - Support for Hybrid Auth

With B2C Commerce version 25.3, hybrid authentication (auth) replaces Plugin SLAS. Hybrid auth improves the performance and stability of hybrid storefronts by moving the feature directly into the B2C Commerce platform. See [Configure a Hybrid Storefront with Hybrid Auth].

### PWA Kit - Support for Hybrid Auth

With B2C Commerce version 25.3, hybrid authentication (auth) replaces Plugin SLAS. Hybrid auth improves the performance and stability of hybrid storefronts by moving the feature directly into the B2C Commerce platform. See [Configure a Hybrid Storefront with Hybrid Auth](/docs/commerce/b2c-commerce/guide/hybrid-auth.html).
