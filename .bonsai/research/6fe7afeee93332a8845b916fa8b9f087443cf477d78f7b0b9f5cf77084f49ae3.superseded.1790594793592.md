## Summary

Configure Multisite URLs > Switch Sites, Locales, and Currencies > Locale Switcher

## Compressed

### Locale Switcher

The locale switcher component is at `src/components/locale-switcher`. When a shopper selects a new locale:

1. The current URL path is stripped of its site/locale prefix using `stripPathPrefix`.
2. The new URL is rebuilt with the updated locale using `buildUrl`.
3. `i18n.changeLanguage` is called with the new locale string.
4. A `POST` is submitted to `/action/set-site-context` with the updated `localeId`.
5. The server action sets the `lng` cookie.
6. React Router triggers a full loader revalidation so all page data is reloaded with the new locale context.
