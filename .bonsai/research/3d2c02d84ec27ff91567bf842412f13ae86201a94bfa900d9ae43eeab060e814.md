## Summary

B2C Commerce API Release Notes > 2023 > 07/10/2023

## Compressed

### 07/10/2023

#### Shopper Search

- [productSearch] now correctly handles storefront search queries with the `&` character and considers all terms before and after the `&`. Previously, the search query was incorrectly truncated before the `&` character and subsequent terms were missing in the query.

## Detailed

### 07/10/2023

#### Shopper Search

- [productSearch](https://developer.salesforce.com/docs/commerce/commerce-api/references/shopper-search?meta=productSearch) now correctly handles storefront search queries with the `&` character and considers all terms before and after the `&`. Previously, the search query was incorrectly truncated before the `&` character and subsequent terms were missing in the query.
