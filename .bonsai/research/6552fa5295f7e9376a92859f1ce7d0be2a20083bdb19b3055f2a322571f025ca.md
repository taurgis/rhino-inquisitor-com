## Summary

Third-Party Applications > Facebook and Instagram Shop Ads Integration > Configure SCAPI Hooks

## Compressed

### Configure SCAPI Hooks

Enable SCAPI Hook execution in Salesforce Commerce Cloud Business Manager to create a basket or place an order through OCAPI endpoints when the access token is generated through SCAPI TSOB:

1. Click App Launcher  and then select **Administration** > **Global Preferences** > **Feature Switches**.
2. Check the `Enable Salesforce Commerce API Hook Execution` box.
   
3. Select **Apply**.

## Detailed

### Configure SCAPI Hooks

Enable SCAPI Hook execution in Salesforce Commerce Cloud Business Manager to create a basket or place an order through OCAPI endpoints when the access token is generated through SCAPI TSOB:

1. Click App Launcher ![App Launcher](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/shared/appLauncher.png) and then select **Administration** > **Global Preferences** > **Feature Switches**.
2. Check the `Enable Salesforce Commerce API Hook Execution` box.
   ![Select SCAPI hook enable setting](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_instagram_oci_scapi_hooks_enabled.png)
3. Select **Apply**.
