## Summary

Microsoft Edge Origin Trials

## Compressed

Get access to experimental web platform features to ensure utility and stability of a feature before its general availability.

## 

Get started

### 

Select your origin trial

There are several origin trials available to run on your domain. These trials are open to all developers and are limited in duration and usage.

### 

Register for an experiment

If you are already logged into GitHub, follow the prompts in the registration form to receive a valid token to use on your site.

### 

Enable the origin trial in your site's code

Add an origin trial token using either a <meta> tag or HTTP Header.
