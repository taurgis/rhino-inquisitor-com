# GoogleChromeLabs/webmcp-tools — README summary

Source: https://github.com/GoogleChromeLabs/webmcp-tools (README.md)

Overview: "This repository contains a suite of developer utilities and demos designed to support the adoption of the WebMCP API." Apache-2.0 licensed, topics: awesome-list, webmcp.

Developer utilities in the repo:
1. WebMCP Model Context Tool Inspector — Chrome Extension to verify WebMCP tools are exposed correctly, visualize input schema, debug connection issues in-browser.
2. WebMCP Evals — CLI tool to evaluate LLM tool-calling accuracy against defined test cases/schemas.
3. WebMCP Polyfill — JavaScript polyfill to make WebMCP tools/CSS pseudo-classes work in browsers without native support.

Demos: 14+ interactive demos (pizza-maker, react-flightsearch/travel, french-bistro reservations, maze game, and others covering e-commerce, hotels, real estate, smart home) showing both Imperative and Declarative API usage.

Classification: this is a reference collection of developer tools and working demos, NOT an installable library/package itself; individual tools (e.g. the polyfill) are separate npm packages referenced from here.
