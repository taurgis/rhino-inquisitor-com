## Summary

B2C Commerce API Release Notes > 12/4/2025 > SCAPI Release

## Compressed

### SCAPI Release

With B2C Commerce version 26.1:

- Added Custom APIs to the [Timeouts API]. This allows configuration of request timeouts for Custom API requests up to a maximum of 120 seconds.
- New SCAPI APIs and endpoints:
  - [Customers]
    - `PUT customer-groups/{customerGroupId}/members`
      - Adds multiple customers to a customer group by their customer numbers in a single batch operation.
    - `DELETE customer-groups/{customerGroupId}/members`
      - Removes multiple customers from a customer group by their customer numbers in a single batch operation.
    - `GET /customer-groups`
      - Retrieves customer groups with support for pagination (offset/limit) and field selection via the select parameter.
  - [Price Books]
    - `POST /price-book-search`
      - Searches for price books using query-based criteria, enabling discovery and filtering of price book configurations.
  - [Products]
    - `POST /unassigned-product-search`
      - Searches for products that aren't assigned to any catalog.
  - [SCAPI Schemas]
    - `GET /schemas`
      - Retrieves a list of available SCAPI OAS schemas.
    - `GET /schemas/{apiFamily}/{apiName}/{apiVersion}`
      - Retrieves the OAS schema identified by API family, name, and version.
  - [Shopper Experience]
    - `GET /contents/{id}`
      - Retrieves a single content asset by ID with optional locale parameter for localized content.
    - `GET /contents`
      - Retrieves multiple content assets by their IDs in a single batch request, supporting locale-based content retrieval.
    - `GET /folders/{id}`
      - Retrieves a content folder by ID with support for hierarchical navigation via the `levels` parameter and optional locale.
    - `GET /folders`
      - Retrieves multiple content folders by their IDs in batch, with support for hierarchical levels and localization.
    - `GET content-search`
      - Searches content assets using query parameters with support for sorting, pagination (offset/limit), refinements, and locale-specific results.
  - [Shopper Customers]
    - `GET /product-lists/{listId}/items`
      - Retrieves all items in a product list, for example: wish list and gift registry, with support for expansion parameters to include product details, availability, images, and prices.
  - [Shopper Payments]
  - [Shopper Products]
    - New expansion `shipping_methods` for `/products` and `/products/{id}`. Adds shipping method information to product responses, allowing clients to retrieve available shipping options for products.
    - New expansion `set_products` and `bundled_products` for `/products`. Enables retrieval of product set members and bundled product details within product responses.
  - [Sites]
    - `POST /site-search`
      - Searches for sites using a query-based search with configurable search criteria in the request body.
