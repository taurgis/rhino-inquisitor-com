## Compressed

### Locale Only in Query Params

```typescript
// config.server.ts
export default defineConfig({
  app: {
    url: {
      search: "?lng=:localeId",
      excludeRoutes: ["/resource/**", "/action/**"],
    },
    // No detection config override required.
    // Path detection doesn't find valid site/locale IDs in page path segments
    // and falls through. Site resolves from cookie or header; locale from ?lng=.
  },
});
```

No detection config override is required. The default detection falls through path segments to find the locale in the `?lng=` query parameter.

Best for: Single-site storefronts that want locale-aware URLs without path changes.

| Page     | URL                          |
| -------- | ---------------------------- |
| Homepage | `/?lng=en-GB`                |
| Product  | `/product/123?lng=en-GB`     |
| Category | `/category/womens?lng=it-IT` |
