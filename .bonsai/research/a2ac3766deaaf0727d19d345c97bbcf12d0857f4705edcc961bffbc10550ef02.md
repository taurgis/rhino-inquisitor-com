### [CVE-2026-96652]

Plex Media Server Server-Side Request Forgery (SSRF) Vulnerability: Plex Media Server contains a server-side request forgery (SSRF) vulnerability which could allow an attacker using any X-Plex-Token value to include a full URL in the 'protocol' parameter and force the Plex server to POST to the attacker's chosen destination.
