# OCAPI

Review the new B2C Commerce OCAPI updates in the B2C Commerce 20.4 release. The OCAPI version is now 20.4.

*   **[Support Ending for All OCAPI Versions Earlier Than 17.1]**  
    Support for all OCAPI versions 13.x, 14.x, 15.x, and 16.x will end on July 1, 2020. If you use any of these versions, you must take action before July 1.
*   **[Rebuild Search Indexes with the Data API]**  
    You can use the Data API to call new system jobs for rebuilding search indexes.
