### 2.2. Text Editing in NLP

NLP research has explored various text editing tasks ([Laban et al., 2023b]; [Pryzant et al., 2020]; [Choi et al., 2021]). [Faltings et al. (2021)] release the WikiDocEdits dataset and propose an interactive text generation setting in which a user interacts with the system by issuing commands to edit existing text. [Raheja et al. (2023)] proposed an instruction-based editing system using fine-tuned language models. [Kim et al. (2022)] presented a system that iteratively improves fluency, clarity, coherence, and style by detecting editable spans and their corresponding edit intents, then instructing a revision model to refine the text. [Yang et al. (2017)] developed a taxonomy and classifier for Wikipedia edit intentions. Following them [Du et al. (2022)] created a multi-domain corpus of revised text with annotated edit intentions. Unlike existing work, we create a resource for text editing that caters to challenging writing tasks (literary fiction and creative nonfiction). Our data consists of 8035 fine-grained edits that are annotated by creative writing experts and we further show how recent advances in few-shot learning can help models improve their own writing by learning from edits provided by the writers.

### 2.2. Text Editing in NLP

NLP research has explored various text editing tasks ([Laban et al., 2023b](https://arxiv.org/html/2409.14509v5#bib.bib63); [Pryzant et al., 2020](https://arxiv.org/html/2409.14509v5#bib.bib94); [Choi et al., 2021](https://arxiv.org/html/2409.14509v5#bib.bib19)). Adding to it the advent of Large Language Models has enabled AI-assisted writing tools ([Buschek et al., 2021](https://arxiv.org/html/2409.14509v5#bib.bib13); [Ippolito et al., 2022a](https://arxiv.org/html/2409.14509v5#bib.bib51)). [Faltings et al. (2021)](https://arxiv.org/html/2409.14509v5#bib.bib35) release the WikiDocEdits dataset and propose an interactive text generation setting in which a user interacts with the system by issuing commands to edit existing text. [Raheja et al. (2023)](https://arxiv.org/html/2409.14509v5#bib.bib96) proposed an instruction-based editing system using fine-tuned language models. [Shu et al. (2024)](https://arxiv.org/html/2409.14509v5#bib.bib105) developed strategies for cross-sentence rewriting and introduced the OpenRewriteEval benchmark. [Reid and Neubig (2022)](https://arxiv.org/html/2409.14509v5#bib.bib98) modeled multi-step editing processes to better mimic human content creation and improve performance on various tasks. [Kim et al. (2022)](https://arxiv.org/html/2409.14509v5#bib.bib56) presented a system that iteratively improves fluency, clarity, coherence, and style by detecting editable spans and their corresponding edit intents, then instructing a revision model to refine the text. [Yang et al. (2017)](https://arxiv.org/html/2409.14509v5#bib.bib116) developed a taxonomy and classifier for Wikipedia edit intentions. Following them [Du et al. (2022)](https://arxiv.org/html/2409.14509v5#bib.bib30) created a multi-domain corpus of revised text with annotated edit intentions. Unlike existing work, we create a resource for text editing that caters to challenging writing tasks (literary fiction and creative nonfiction). Our data consists of 8035 fine-grained edits that are annotated by creative writing experts and we further show how recent advances in few-shot learning can help models improve their own writing by learning from edits provided by the writers.
