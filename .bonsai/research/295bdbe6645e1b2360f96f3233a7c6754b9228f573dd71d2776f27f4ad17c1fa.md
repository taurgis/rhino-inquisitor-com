## Detailed

### 5.2 The FTPO Formulation

FTPO implements several mechanisms to constrain logits to reference, with a two-part regularization allowing larger shifts for chosen and rejected logits, relative to the remaining vocab. The loss function is formulated as such: At the final position in the inference trace, define token rr (rejected) and chosen alternatives CC. We optimize three loss objectives:

Preference loss with margin. We encourage chosen tokens to exceed the rejected token’s logit by margin mm:

|  | ℒp​r​e​f=∑c∈Cwc⋅softplus​(m−Δc)∑c∈Cwc\mathcal{L}_{pref}=\frac{\sum_{c\in C}w_{c}\cdot\text{softplus}(m-\Delta_{c})}{\sum_{c\in C}w_{c}} |  |
| --- | --- | --- |

where Δc\=y⁡\[c\]−y⁡\[r\]\\Delta\_{c}=y\[c\]-y\[r\] is the logit gap between chosen and rejected, and the weight wc\=clamp​((m−Δc)/m,0,1)w\_{c}=\\text{clamp}((m-\\Delta\_{c})/m,0,1) deactivates the loss when the margin is achieved (Figure [14](https://arxiv.org/html/2510.15061#A10.F14 "Figure 14 ‣ Appendix J FTPO Loss Function Definition ‣ Antislop: A Comprehensive Framework for Identifying and Eliminating Repetitive Patterns in Language Models")).

Target regularization. We tether chosen and rejected ("target") logits to reference values, calculating MSE loss directly on logit deltas (not logprobs). A zero-penalty window τt​a​r​g​e​t\\tau\_{target} allows these logits initial freedom to move:

|  | ℒt​a​r​g​e​t=1\|T\|​∑j∈Tmax⁡(\|y⁡[j]−yr​e​f​[j]\|−τt​a​r​g​e​t,0)2\mathcal{L}_{target}=\frac{1}{\|T\|}\sum_{j\in T}\max(\|y[j]-y_{ref}[j]\|-\tau_{target},0)^{2} |  |
| --- | --- | --- |

where T\=C∪{r}T=C\\cup\\{r\\} contains all target tokens.

Non-target regularization. We strongly anchor the remaining vocabulary to prevent distribution drift:

|  | ℒn​o​n​t​a​r​g​e​t=1\|N\|​∑j∈N(y⁡[j]−yr​e​f​[j])2\mathcal{L}_{nontarget}=\frac{1}{\|N\|}\sum_{j\in N}(y[j]-y_{ref}[j])^{2} |  |
| --- | --- | --- |

where NN represents all non-target tokens.

The total loss, incorporating weighting coefficients λtarget\\lambda\_{\\text{target}} and λnontarget\\lambda\_{\\text{nontarget}}:

|  | ℒF​T​P​O=ℒp​r​e​f+λt​a​r​g​e​t​ℒt​a​r​g​e​t+λn​o​n​t​a​r​g​e​t​ℒn​o​n​t​a​r​g​e​t\mathcal{L}_{FTPO}=\mathcal{L}_{pref}+\lambda_{target}\mathcal{L}_{target}+\lambda_{nontarget}\mathcal{L}_{nontarget} |  |
