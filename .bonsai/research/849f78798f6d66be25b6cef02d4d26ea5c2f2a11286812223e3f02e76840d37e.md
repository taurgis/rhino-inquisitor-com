## Update: 31 July 2025

My current advice on using `display: contents`:

*   Do not use `display: contents` on anything that is interactive.
*   Do not use `display: contents` on anything that can take focus.
*   Avoid `display: contents` in web components.
*   Probably avoid `display: contents` on things with richer semantics (such as tables and lists and headings and so on).
*   Browsers have fixed and regressed `display: contents` repeatedly over the years, so build regular testing into a project plan as well.

It is still not a CSS reset.
