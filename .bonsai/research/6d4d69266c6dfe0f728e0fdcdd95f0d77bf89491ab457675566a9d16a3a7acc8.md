## Appendix C Determining the Evaluation Metric

To assess what evaluation metric best aligns with human judgment, we use a small dataset of 20 peer-reviewed papers that are not included in our benchmark. For each paper, we generate modified text that introduces an error using GPT 5 and Gemini 2.5 Pro. We then employ five distinct LLMs — Claude Sonnet 3.7, DeepSeek Reasoner v3.1, Gemini 2.5 Pro, GPT 5, and Grok 4 — to identify the errors in these modified papers. In these examples, we consider the top ten (or less) error excerpts generated by the identification LLM and see whether an error has been identified by using (i) the word-level Levenshtein distance (see Section [4.2.1](https://arxiv.org/html/2511.21843v1#S4.SS2.SSS1 "4.2.1 Word-Level Levenshtein Distance-Based Similarity ‣ 4.2 Evaluation Metric ‣ 4 Automated Evaluation Framework ‣ FLAWS: A Benchmark for Error Identificationand Localization in Scientific Papers")) (ii) the outputs generated by prompting an instance of the insertion LLM (specific prompt in Appendix [B.8](https://arxiv.org/html/2511.21843v1#A2.SS8 "B.8 Identification Evaluation ‣ Appendix B LLM Prompts Used ‣ FLAWS: A Benchmark for Error Identificationand Localization in Scientific Papers"))(iii) manual inspection, to identify whether any of the top 10 identified error excerpts correspond to the inserted error. We use the manual inspection results as ground truth and compare how the automated methods perform with respect to them.

Out of the 20 papers, we first manually inspected the inserted errors and found that both insertion models generated valid errors for 19 of the papers, this left us with 190 identified error examples (19 papers ×\\times 2 insertion models ×\\times 5 identification models). The performance of the automated identification processes compared to manual identification are shown in Table [9](https://arxiv.org/html/2511.21843v1#A3.T9 "Table 9 ‣ Appendix C Determining the Evaluation Metric ‣ FLAWS: A Benchmark for Error Identificationand Localization in Scientific Papers") and Table [10](https://arxiv.org/html/2511.21843v1#A3.T10 "Table 10 ‣ Appendix C Determining the Evaluation Metric ‣ FLAWS: A Benchmark for Error Identificationand Localization in Scientific Papers"). In addition, we find that manual identification matches the best with combing both automated approaches as shown in Table [11](https://arxiv.org/html/2511.21843v1#A3.T11 "Table 11 ‣ Appendix C Determining the Evaluation Metric ‣ FLAWS: A Benchmark for Error Identificationand Localization in Scientific Papers"): an error is identified if either the LLM or the Levenshtein metric indicates an error is identified. Therefore, we will use this as our final evaluation metric.
