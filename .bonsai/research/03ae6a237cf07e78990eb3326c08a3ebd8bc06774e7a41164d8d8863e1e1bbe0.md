## Compressed

### 4.7 Data and code availability

Our analysis code in Python is available at [https://github.com/berenslab/llm-excess-vocab]. The 362 442×15362\\,442\\times 15 matrix of yearly word occurrences (for each word and year, the number of abstracts in that year containing that word; the additional last row contains the total number of abstracts in that year) is available in our Github repository as a csv.gz file. Our content/style annotations are also available there as a csv file. The original PubMed data are openly available for bulk download here: [https://pubmed.ncbi.nlm.nih.gov/download].
