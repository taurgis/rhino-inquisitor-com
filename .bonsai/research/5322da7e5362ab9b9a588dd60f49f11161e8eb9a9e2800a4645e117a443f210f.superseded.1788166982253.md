## Summary

Page Designer Integration with Storefront Next > Deploy Cartridges > Prerequisites

## Compressed

### Prerequisites

Create a `dw.json` file in the `storefront-next-dev` package directory.

```json
{
  "hostname": "your-instance.demandware.net",
  "username": "your-username",
  "password": "your-password",
  "code-version": "version1"
}
```

:::note
For more detailed steps for setting up the `dw.json` file and deploying the cartridge, see [Deploy the Storefront Next Cartridge for Page Designer].
:::
