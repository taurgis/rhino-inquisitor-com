## Compressed

### Set an Environment Base Path to Route Requests to an MRT Environment

If your composable storefront has multiple MRT environments under a single domain, set environment base paths to each MRT environment to route requests to specific environments. Also use an environment base path to host the storefront within a specific subpath.
