## Compressed

### Component Registry

The component registry dynamically loads Page Designer components on-demand using lazy imports.

- **Lazy loading**: Components are only loaded when needed, reducing initial bundle size.
- **Dynamic imports**: Each component is registered with an importer function.
- **Fallback support**: Optional loading states during component load.
- **Data loaders**: Optional server/client data fetching functions hoisted to the page.

**Registry Initialization Example**:

```jsx
import {registry} from '@salesforce/commerce-sdk-react'

export function initializeRegistry() {
  // Register components with lazy imports
  registry.registerImporter('pwa.contentCard', () => import('./components/content-card'))

  registry.registerImporter('pwa.grid', () => import('./components/grid'))

  // Register component with data loader and fallback
  registry.registerImporter('pwa.productCarousel', () => import('./components/product-carousel'), {
    loader: 'loader',
    fallback: 'fallback'
  })
}
```

**How It Works**:

1. Call `initializeRegistry()` once during app startup.
2. When a page renders, the registry checks if the component is loaded.
3. If not loaded, it calls the importer function (triggers React Suspense).
4. Subsequent uses of the same component are instant.

**Key Benefits**:

- Only components used on the page are downloaded.
- Initial page load is faster.
- Components are shared across pages (loaded one time and cached).
- Eliminates the manual management of imports in page files.
