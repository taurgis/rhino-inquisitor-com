# Optimizing PWA Performance with Region Selection in Managed Runtime for B2C Commerce

Publish Date: Oct 31, 2024

Description

**Enhance PWA Performance by Deploying Closer to Commerce Cloud B2C Platform PODs**

The PWA Kit Managed Runtime offers a global network for deploying your Progressive Web Apps (PWAs). To optimize performance and responsiveness, deploying your PWA closer to the Commerce Cloud B2C platform PODs where your customers' data is stored is crucial. This can be achieved by carefully selecting the appropriate region for your PWA in the Runtime Admin UI.

Resolution

**Choosing the Optimal Region for Peak Performance**

The location of your Commerce Cloud B2C platform PODs plays a significant role in determining the optimal region for your PWA.

**Elevating User Satisfaction with Optimal Region Deployment**

To identify the optimal region for your PWA, consider the geographic distribution of your target audience. If the majority of your customers reside in a specific region, deploying your PWA to a cluster in that region ensures that data requests travel shorter distances, minimizing latency and enhancing performance.

**Streamlined Deployment and Cache Purge for Effortless Performance Optimization**

Changing the region for your Managed Runtime involves a straightforward process in the Runtime Admin UI:

1.  Access the Runtime Admin UI by navigating to the following URL: [https://runtime.commercecloud.com/] 
2.  Select the Project and Environment you want to manage.
3.  In the left-hand navigation pane, click on ‘Environment Settings’ ([More Detail]).
4.  Under Advanced -> Region,  select the desired region from the dropdown list.
5.  Click on Save to apply the changes.

Initiating region changes triggers a redeployment of your PWA to the new environment.

The redeployment and cache purge typically take around 20 minutes to complete.

**Trust Status Updates**

Information about Managed Runtime is now provided via the [B2C Commerce Status] site.

# Optimizing PWA Performance with Region Selection in Managed Runtime for B2C Commerce

Publish Date: Oct 31, 2024

Description

**Enhance PWA Performance by Deploying Closer to Commerce Cloud B2C Platform PODs**

The PWA Kit Managed Runtime offers a global network for deploying your Progressive Web Apps (PWAs). To optimize performance and responsiveness, deploying your PWA closer to the Commerce Cloud B2C platform PODs where your customers' data is stored is crucial. This can be achieved by carefully selecting the appropriate region for your PWA in the Runtime Admin UI.

Resolution

**Choosing the Optimal Region for Peak Performance**

The location of your Commerce Cloud B2C platform PODs plays a significant role in determining the optimal region for your PWA. By deploying your PWA to a cluster near the PODs storing your customers' data, you minimize latency and significantly improve page load times. This translates to a more responsive and engaging user experience, leading to increased satisfaction and loyalty.

**Elevating User Satisfaction with Optimal Region Deployment**

To identify the optimal region for your PWA, consider the geographic distribution of your target audience. If the majority of your customers reside in a specific region, deploying your PWA to a cluster in that region ensures that data requests travel shorter distances, minimizing latency and enhancing performance. You can utilize the information in our POD location lists for [EMEA/APAC](https://help.salesforce.com/s/articleView?type=1&id=Locations-and-Outgoing-POD-IPs-for-each-Commerce-Cloud-POD-EMEA-APAC-PODs&language=en_US) and [AMER](https://help.salesforce.com/s/articleView?type=1&id=Locations-and-Outgoing-POD-IPs-for-each-Commerce-Cloud-POD-AMER-PODs&language=en_US) to accurately pinpoint the appropriate region for your POD and therefore the best region for Managed Runtime as well.

**Streamlined Deployment and Cache Purge for Effortless Performance Optimization**

Changing the region for your Managed Runtime  involves a straightforward process in the Runtime Admin UI:

1.  Access the Runtime Admin UI by navigating to the following URL: [https://runtime.commercecloud.com/](https://runtime.commercecloud.com/) 
2.  Select the Project and Environment you want to manage.
3.  In the left-hand navigation pane, click on ‘Environment Settings’ ([More Detail](https://developer.salesforce.com/docs/commerce/pwa-kit-managed-runtime/guide/managed-runtime-administration.html#edit-environment-settings)).
4.  Under Advanced -> Region,  select the desired region from the dropdown list.
5.  Click on Save to apply the changes.

Initiating region changes triggers a redeployment of your PWA to the new environment.

The redeployment and cache purge typically take around 20 minutes to complete. During this time, your PWA remains accessible, but there may be a slight delay in refreshing the content.

**Trust Status Updates**

Information about Managed Runtime is now provided via the [B2C Commerce Status](https://status.salesforce.com/products/B2C_Commerce_Cloud) site. This includes any active or historical incidents for the admin or storefront regions of Managed Runtime as well as upcoming maintenance windows.
