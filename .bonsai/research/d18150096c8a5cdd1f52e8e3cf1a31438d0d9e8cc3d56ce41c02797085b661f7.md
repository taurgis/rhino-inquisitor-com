## Summary

Third-Party Applications > Facebook and Instagram Shop Ads Integration > Configure Job Permissions

## Compressed

### Configure Job Permissions

Use the same client ID from the previous step to add the following configuration to your sandbox OCAPI settings. Meta uses this permission information to trigger the product feed jobs when needed.

1. Log in to Business Manager.
2. Click App Launcher  and then select **Administration** > **Site Development** > **Open Commerce API Settings**.
3. Select `Data` in the `Select Type` field, and let the context as `Global (organization-wide)`.
   
4. Paste and merge the following configuration information for your `clientID`:
   ```json
   ...
   {
     "client_id": "<YOUR_CLIENT_ID>",
     resources": [
       {
         "resource_id": "/jobs/*/executions",
         "methods": ["post"],
         "read_attributes": "(**)",
         "write_attributes": "(**)"
       }
     ]
   }
   ...
   ```
   For more information, refer to [Instagram Shopping with Commerce Cloud].
