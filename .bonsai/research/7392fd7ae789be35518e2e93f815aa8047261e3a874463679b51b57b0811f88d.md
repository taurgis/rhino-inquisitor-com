# Plugin SLAS Setup

Copy URL to Markdown

With B2C Commerce version 25.3, [hybrid auth](/docs/commerce/pwa-kit-managed-runtime/guide/hybrid-auth.html) replaces Plugin SLAS. Hybrid storefronts that use Plugin SLAS are still supported.

Note

We highly recommend migrating to Hybrid Auth so that you can take advantage of the improved performance and streamlined workflow.

Here are the guides that apply to only Plugin SLAS.

*   [Configure a Hybrid Storefront with Plugin SLAS](/docs/commerce/pwa-kit-managed-runtime/guide/phased-headless-rollouts.html)
*   [Hybrid Stability Upgrade for PWA Kit Version 3.8.0](/docs/commerce/pwa-kit-managed-runtime/guide/hybrid-upgrade-v3.x.html)
*   [Hybrid Stability Upgrade for PWA Kit Version 2.x](/docs/commerce/pwa-kit-managed-runtime/guide/hybrid-upgrade-v2.x.html)

### See Also 

*   [Use Composable Storefront in a Hybrid Implementation](/docs/commerce/pwa-kit-managed-runtime/guide/hybrid-implementation.html)
*   [Configure a Hybrid Storefront with Hybrid Auth](/docs/commerce/pwa-kit-managed-runtime/guide/hybrid-auth.html)
*   [Get Started with Composable Storefront](/docs/commerce/pwa-kit-managed-runtime/guide/pwa-developer-workflow.html)

Node 20 Deprecation

Node 20 has an end-of-life date of April 30, 2026. We strongly recommend that you update your production projects to Node 22 or Node 24 by upgrading to [the latest minor version of PWA Kit 3.x](https://github.com/SalesforceCommerceCloud/pwa-kit/releases). See full details on Node support dates and upgrade steps in [Upgrade Node Version](https://developer.salesforce.com/docs/commerce/pwa-kit-managed-runtime/guide/upgrade-node-version.html).
