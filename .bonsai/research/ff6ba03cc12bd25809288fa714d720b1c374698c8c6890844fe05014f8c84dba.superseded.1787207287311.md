## Summary

B2C Commerce API Release Notes > 04/21/2026 > SCAPI Release

## Compressed

### SCAPI Release

New APIs and endpoints:

- [Jobs API]
  - POST `/jobs/{jobId}/executions`
    - Create a job execution.
    - GET `/jobs/{jobId}/executions/{id}`
      - Retrieve job execution details.
    - DELETE `/jobs/{jobId}/executions/{id}`
      - Delete a job execution.
    - POST `/job-execution-search`
      - Search job executions.
- [Roles API]
  - GET `/roles`
    - Retrieve role information.
  - GET/PUT/DELETE `/roles/{roleId}`
    - Get, create, or delete a role by ID.
  - GET/PUT `/roles/{roleId}/permissions`
    - Get and create role permissions.
  - GET `/roles/{roleId}/users`
    - Retrieve users assigned to a specified role.
  - PUT/DELETE `/roles/{roleId}/users/{login}`
    - Assign and unassign users to roles.
  - POST `/roles/{roleId}/user-search`
    - Search user roles by login credentials.
- [Scripts API]
  - GET `/code-versions`
    - List code versions.
  - PUT/GET `/code-versions/{codeVersionId}`
    - Create/Get code version details.
  - PATCH `/code-versions/{codeVersionId}`
    - Activate a code version.
  - DELETE `/code-versions/{codeVersionId}`
    - Delete a code version.
- [Shopper Agents]
  - POST `/organizations/{organizationId}/session/init`
    - Initialize an Agentforce shopper session.
- [Sites API]
  - GET `/sites`
    - Retrieve details for all sites.
  - GET `/sites/{siteId}` - Retrieve site details by ID.
    - POST `/site-search`
      - Search sites.
- [Users API]
  - GET `/users`
    - Retrieve user information.
  - GET/PUT/PATCH/DELETE `/users/{login}`
    - Create, retrieve, update, delete (CRUD) users using login credentials.

Updated APIs and endpoints:

- [Replications API]
  - Added support for Page Designer (PD) pages: PD pages replicate as content assets, including all their components.
- [Shopper Customers API]
  - Added support for saving and deleting payment method references for Salesforce Payments
    - Payment Method Reference Setup (POST `/organizations/{organizationId}/customers/{customerId}/payment-method-references/actions/setup`) — Shoppers can now save a payment method for future use.
    - Delete Payment Method Reference (DELETE `/organizations/{organizationId}/customers/{customerId}/payment-method-references/{paymentMethodReferenceId}`) Shoppers can now delete a saved payment method reference.
- [Shopper Experience API]
  - POST `/qualifiers/resolve`
    - Checks user qualification for customer groups, campaigns/promotions, and data binding contexts.
