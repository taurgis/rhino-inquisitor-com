## Summary

Required conditions for origin trials > Third-party token origin matches script origin

## Compressed

### Third-party token origin matches script origin

You can register to participate in an origin trial for scripts that are injected on other origins.

For example, if you want scripts that are served from `javascript-library.example` to take part in an origin trial, you need to register a token with third-party matching for `javascript-library.example`.

![Chrome origin trials 
registration page showing third-party matching selected.](/static/docs/web-platform/origin-trial-troubleshooting/image/chrome-origin-trials-reg-80e9d57ed233.png)

The origin value for a third-party token must match the origin of the script that injects it.
