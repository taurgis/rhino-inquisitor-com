## Compressed

### Origin trial feature access is supported for the method used to provide a trial token

Some types of access to origin trial features require you to provide a trial token in a specific way. For example, the only way to enable [origin trial access for service workers and shared workers] is to provide a token in an `Origin-Trial` header.

## Detailed

### Origin trial feature access is supported for the method used to provide a trial token

Some types of access to origin trial features require you to provide a trial token in a specific way. For example, the only way to enable [origin trial access for service workers and shared workers](https://developer.chrome.com/docs/web-platform/origin-trial-troubleshooting#workers) is to provide a token in an `Origin-Trial` header.
