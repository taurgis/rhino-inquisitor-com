## Summary

Composable Storefront Release Notes > 6/8/2026 > Improved Header Forwarding for Proxy Requests

## Compressed

### Improved Header Forwarding for Proxy Requests

The Managed Runtime proxy now correctly forwards request headers that were previously dropped or overwritten.

- User-Agent is preserved. The original client `User-Agent` is now correctly forwarded to all origins on proxy requests.
- Access Control Headers (ACH) reach B2C Commerce API (SCAPI). ACH headers are no longer stripped before reaching SCAPI.

**Where:** This change applies to Composable Storefronts using the MRT proxy.
