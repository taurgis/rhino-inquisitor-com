# Configure a Hybrid Storefront with Hybrid Auth

Copy as Markdown

View as Markdown

Copy URL to Markdown

With B2C Commerce version 25.3, hybrid authentication (Hybrid Auth) replaces the Plugin SLAS cartridge option.

[Hybrid Auth](https://developer.salesforce.com/docs/commerce/commerce-api/guide/hybrid-authentication.html) is a standalone solution for site implementations that need both Storefront Reference Architecture (SFRA)/SiteGenesis (SG) authorization and Shopper Login and API Access Service (SLAS) authorization. This means you need both a `dwsid` (SFRA/Site Genesis) and a JSON Web Token (SLAS), and these tokens must be kept in sync. Hybrid Auth is an improvement over the Plugin SLAS approach, offering a more efficient and streamlined method.

Note

We highly recommend migrating to Hybrid Auth so that you can take advantage of the improved performance and streamlined workflow.

For complete implementation details, see [Hybrid Auth](https://developer.salesforce.com/docs/commerce/commerce-api/guide/hybrid-authentication.html).

Node 20 Deprecation

Node 20 has an end-of-life date of April 30, 2026. We strongly recommend that you update your production projects to Node 22 or Node 24 by upgrading to [the latest minor version of PWA Kit 3.x](https://github.com/SalesforceCommerceCloud/pwa-kit/releases). See full details on Node support dates and upgrade steps in [Upgrade Node Version](https://developer.salesforce.com/docs/commerce/pwa-kit-managed-runtime/guide/upgrade-node-version.html).
