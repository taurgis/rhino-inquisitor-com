## Compressed

### Build Composable Storefront Components in Page Designer Without ISML

You can now expose React-based composable storefront pages and components directly in Page Designer without building ISML storefront versions. The new Page Designer architecture removes the ISML rendering layer, so your React components render the page directly. No need to maintain duplicate storefront code. You just add metadata attributes to use the more integrated development workflow. By eliminating duplicate storefront code, you can significantly reduce development time.
