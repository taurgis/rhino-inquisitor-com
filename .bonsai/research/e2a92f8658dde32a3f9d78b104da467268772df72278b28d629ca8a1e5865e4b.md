## Summary

B2C Commerce API Release Notes > 2024 > 06/26/2024

## Compressed

### 06/26/2024

#### SCAPI Release

- Server-Side Web-Tier Caching is automatically turned on for all instances that don't use [Shopper Search API] `productSearch` and `getSearchSuggestions` endpoints on their PRD instances. For details, see [Server-Side Web-Tier Caching].

## Detailed

### 06/26/2024

#### SCAPI Release

- Server-Side Web-Tier Caching is automatically turned on for all instances that don't use [Shopper Search API](https://developer.salesforce.com/docs/commerce/commerce-api/references/shopper-search?meta=Summary) `productSearch` and `getSearchSuggestions` endpoints on their PRD instances. For details, see [Server-Side Web-Tier Caching](https://developer.salesforce.com/docs/commerce/commerce-api/guide/server-side-web-tier-caching.md).
