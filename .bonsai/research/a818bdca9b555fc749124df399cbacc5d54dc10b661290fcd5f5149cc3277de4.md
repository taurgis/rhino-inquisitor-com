## Summary

## Compressed

## 03/11/2026

SCAPI Release

- New [Timeouts API] :
  - Provides self-service timeout configuration with preference-based response timeout settings for Sandbox and Development instances types.
- Hybrid Auth flow:
  - Now returns the correct HTTP 401 response code in cases where the login failed. Previously a HTTP 500 was returned.
  - Now properly includes trusted-system authentication requests. Previously, this endpoint was not supported by Hybrid Auth.
- The ETag response header was removed, as it wasn't relevant to SCAPI.
