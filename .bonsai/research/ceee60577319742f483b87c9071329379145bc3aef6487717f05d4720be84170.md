## Summary

B2C Commerce API Release Notes > 02/03/2025 > OCAPI Release

## Compressed

### OCAPI Release

- With B2C Commerce version 25.2:
  - Fixed an issue with the [createScapiRemoteInclude()] script functionality when used in combination with a Shopper API. As an example, this led to a 500 exception during the use of the Shopper Baskets API.

## Detailed

### OCAPI Release

- With B2C Commerce version 25.2:
  - Fixed an issue with the [createScapiRemoteInclude()](https://salesforcecommercecloud.github.io/b2c-dev-doc/docs/current/scriptapi/html/index.html?target=class_dw_system_RemoteInclude.html) script functionality when used in combination with a Shopper API. As an example, this led to a 500 exception during the use of the Shopper Baskets API.
