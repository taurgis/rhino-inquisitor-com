## Einstein Trust Layer Service Support

The Shopper Agent for B2C Commerce supports these trust layer services.

| Service | Description |
| --- | --- |
| Zero Data Retention Policy | Einstein Trust Layer uses a zero-data retention policy, so third-party LLMs, like Open AI and Azure Open AI, don’t store or use data for model training. Customers’ use of other features including agents can result in data storage. For more information, contact your Salesforce account executive. |
| Dynamic Grounding with Secure Data Retrieval | Relevant information from a Salesforce record is merged with the prompt to provide context. |
| Prompt Defense (System policies and prompt injection detection) | System policies help limit hallucinations and decrease the likelihood of unintended or harmful outputs by the LLM. |
| Toxicity Detection | The service detects and flags potentially harmful LLM responses. |
| Audit and Feedback | The service logs and stores prompts, responses, and trust signals in Data 360. Feedback can be used for improving prompt templates. |

Data masking through the Einstein Trust Layer is disabled to improve the performance and accuracy of agents.

## Shopper Agent for B2C Commerce Limits

*   You can have up to 100 active agents and, within that 100, have one version of the default Agentforce agent. Active Einstein bots count towards the limit of active agents. See [Activate or Deactivate your Agent].
*   When an incoming customer message exceeds the character limits of the messaging channel, the message isn’t delivered, and no response generates. Different messaging channels have different character limits.
*   Agent responses are optimized for Enhanced Chat, additional channels are not supported.

The Shopper Agent for B2C Commerce uses the Agentforce Service agent type.

## Shopper Agent for B2C Commerce Builder Considerations

Metadata API doesn't yet constrain which subagents and actions you add to a B2C Shopper Agent, but that doesn't mean that Shopper Agents support all subagents and actions it's technically possible to add.

Currently, the B2C Shopper Agent doesn't support these subagents:

*   General CRM
*   Single Record Summary

Currently, the B2C Shopper Agent doesn't support these actions:

*   Identify Object by Name
*   Identify Record by Name
*   Query Records
*   Query Records With Aggregate
*   Summarize Record
*   Draft or Revise Email
*   Update Record Fields
*   Extract Fields And Values From User Input

## Other Considerations

*   For PWA Kit storefronts, PWA Kit v3.13.0 or later supports the B2C Shopper Agent.
*   For SFRA storefronts, plugin\_shopper\_agent v1.0.0-GA supports the B2C Shopper Agent.
*   Create up to 20 versions of an agent. Only one version of an agent can be active at a time. If you’ve reached the limit, delete older versions before cloning new ones. For more information, see [Manage Agent Versions].
*   You can't yet edit active agents.
*   The APIs required to connect Data 360 to the B2C Shopper Agent are compatible only with the default dataspace.
*   Agentforce is included as a Covered Service in the Einstein Platform and Agentforce SOC 2 and SOC 3 reports. Agentforce is HIPAA eligible and covered under the Salesforce [Business Associate Addendum Restrictions], and has also achieved ISO 27001, 27017, and 27018 certifications.
