## Compressed

### ARM Architecture Support for Server-Side Rendering

Managed Runtime now supports ARM architecture for Server-Side Rendering (SSR), providing more efficient processing capabilities for your storefronts.

**How:** ARM architecture is automatically enabled for new projects created in Managed Runtime.

**Benefits:**

- Enhanced performance for server-side rendering operations
- More efficient resource utilization

:::note Migration to the ARM architecture is required before January 31, 2027. After that date, environments running on x86 can't be deployed. :::

## Detailed

### ARM Architecture Support for Server-Side Rendering

Managed Runtime now supports ARM architecture for Server-Side Rendering (SSR), providing more efficient processing capabilities for your storefronts. ARM architecture is the default for all new projects, offering improved performance and efficiency.

**How:** ARM architecture is automatically enabled for new projects created in Managed Runtime. For existing customer projects, environments can be switched over to ARM from x86.

**Benefits:**

- Enhanced performance for server-side rendering operations
- More efficient resource utilization

:::note
Migration to the ARM architecture is required before January 31, 2027. After that date, environments running on x86 can't be deployed.
:::
