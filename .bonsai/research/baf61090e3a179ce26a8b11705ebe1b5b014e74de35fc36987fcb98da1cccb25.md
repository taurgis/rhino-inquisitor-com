## Summary

Page Designer Integration with Storefront Next > Deploy Cartridges > Deploy the Cartridge with the push Command

## Compressed

### Deploy the Cartridge with the `push` Command

To deploy the cartridge, run this command.

```bash
pnpm push
```

The command:

1. Generates cartridge metadata if `GENERATE_AND_DEPLOY_CARTRIDGE_ON_MRT_PUSH` is enabled.
2. Deploys the cartridge to B2C Commerce via WebDAV.
3. Pushes the storefront bundle to Managed Runtime.
