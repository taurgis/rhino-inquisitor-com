# Design Your Own Merchandising Workspace

Create a unified view and customized navigation tailored to your merchandising tasks by using the Merchandising template or build a custom workspace from scratch using Manual Setup.

**Where:** This change applies to B2C Commerce.

**How:** From Setup, in the Quick Find box, enter and then select **New Custom App**. To use a template, select **Merchandising**. To create a workspace from scratch, select **Manual Setup**.
