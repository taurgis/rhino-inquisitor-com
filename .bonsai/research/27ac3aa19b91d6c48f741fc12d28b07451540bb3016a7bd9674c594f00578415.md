## Appendix J FTPO Loss Function Definition

Preference Loss Component:

For each chosen token index cc against a rejected token index rr, define the logit gap

|  | Δ=y⁡[c]−y⁡[r].\Delta=y[c]-y[r]. |  |
| --- | --- | --- |

The margin requirement is mm. A smooth penalty is applied if the gap is smaller than mm:

|  | ℓpref=log⁡(1+e(m−Δ)),\ell^{\text{pref}}=\log\!\bigl(1+e^{(m-\Delta)}\bigr), |  |
| --- | --- | --- |

A taper weight

|  | w=clamp⁡(m−Δm, 0, 1)w=\operatorname{clamp}\!\Big(\tfrac{m-\Delta}{m},\,0,\,1\Big) |  |
| --- | --- | --- |

shrinks the contribution as Δ\\Delta approaches the margin. The preference loss is the weighted mean over chosen tokens:

|  | ℒpref=∑w​ℓpref∑w.\mathcal{L}_{\text{pref}}\;=\;\frac{\sum w\,\ell^{\text{pref}}}{\sum w}. |  |
| --- | --- | --- |

As Δ\\Delta increases toward the margin mm, the penalty smoothly tapers. Once Δ≥m\\Delta\\geq m, the weight goes to zero and the preference loss no longer contributes.
