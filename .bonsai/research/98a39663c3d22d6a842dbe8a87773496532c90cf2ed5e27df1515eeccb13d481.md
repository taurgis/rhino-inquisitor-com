Hybrid Auth                                                                                                               | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

| SiteGenesis                            | N                                   | Y                                                                                                                                                 |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Third Party IDPs and Social Login      | N                                   | Y                                                                                                                                                 | <ul><li>Third-party IDP: Starting with B2C Commerce version 25.8, hybrid auth supports third-party IDP and Social Login, but you must perform all interactions with a third-party IDP using SLAS. Configure OAuth2 providers in [SLAS Admin] instead of Business Manager and add a redirect URI in Hybrid Auth Settings.</li><li>Social Login: Starting with B2C Commerce version 25.8, you must perform all logins using SLAS.</li></ul>                                                                                             |
| Passwordless Login                     | N                                   | N                                                                                                                                                 | Hybrid storefronts don't support passwordless login. See [Implement Passwordless Login].                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| SLAS Private Clients                   | Y                                   | Y                                                                                                                                                 |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| SLAS Public Clients                    | Y                                   | Y                                                                                                                                                 |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| SLAS Trusted System (TSOB)             | N                                   | Y                                                                                                                                                 |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Script API "Remember Me" functionality | N                                   | N/A <ul><li>The traditional remember me functionality enhanced with SLAS extended expiry times and is redundant when you migrate to HA.</li></ul> |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| PWA Kit Version 2.x                    | Y                                   | Y                                                                                                                                                 | <ul><li>To use hybrid auth, you need `salesforce/commerce-sdk-react` *v4.0.0* or later.</li><li>`salesforce/commerce-sdk-react` *v3.4.0* comes packaged with PWA Kit v2.10.</li><li>`salesforce/commerce-sdk-react` *v5.1.1* comes packaged with PWA Kit v2.11.</li></ul>                                                                                                                                                                                                                                                                                                                                                           |
| PWA Kit Version 3.x                    | Y                                   | Y                                                                                                                                                 | <ul><li>To use hybrid auth, you need `salesforce/commerce-sdk-react` *v4.0.0* or later.</li><li>`salesforce/commerce-sdk-react` *v3.3.0* comes packaged with PWA Kit 3.10.0.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Do Not Track (DNT)                     | N                                   | Y                                                                                                                                                 | You must perform specific steps to enable and synchronize DNT. See [Step 8: Enable or Disable Do-Not-Track Synchronization].                                                                                                                                                                                                                                                                                                                                                                          |
| Shopper Context                        | N                                   | Y                                                                                                                                                 | <ul><li>Salesforce recommends that you enable Shopper Context for Hybrid Authentication as it is the only way personalization data is made available for APIs. See the [Shopper Context documentation].</li><li>Geolocation-based personalization must be synchronized between Shopper Context and SFRA/SiteGenesis. See [Step 7: Set Shopper Context].</li><li>Note: The Script API for Shopper Context is available for geolocation-based personalization.</li></ul> |
| Controller exclusion                   | Y                                   | N                                                                                                                                                 | In Hybrid Auth, there is no need to exclude any controllers.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Cookie setting customization           | Y, via customization                | N/A                                                                                                                                               | In Hybrid Auth, unlike Plugin SLAS, you no longer have access to the cookie object and can no longer override cookie settings.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Agent/Order On Behalf Of (OOBO)        | N                                   | Y                                                                                                                                                 | Starting with B2C Commerce version 26.1, Agent/OOBO is supported out of the box in Hybrid Auth with PWA Kit when using the Customer Service Center in Business Manager. If your site uses a third-party cartridge for Agent/OOBO, make sure that you perform testing in a local environment before deploying to your live site.                                                                                                                                                                                                                                                                                                     |
