## Summary

B2C Commerce API Release Notes > 05/20/2026 > SCAPI Release

## Compressed

### SCAPI Release

- New SCAPI APIs and endpoints:
  - [Shopper Availability]
    - `GET /product/shopper-availability/v1/organizations/{organizationId}/availability`
      - Retrieve availability data for one or more products with improved caching performance.
      - This new API deprecates the `expand=availability` parameter on the [Shopper Products API] `getProduct` and `getProducts` endpoints.
  - [Shopper Product Images]
    - `GET /product/shopper-products/v1/organizations/{organizationId}/products/{productId}/images`
      - Retrieve image data for a given product ID.
      - This new API adds a `viewTypeLimit` parameter and uses a dedicated images endpoint instead of the `expand=images` parameter on the [Shopper Products API] `getProduct` endpoint.
  - [Preferences API]
    - `GET`/`PATCH` `/global-preference-groups/{groupId}/{instanceType}`
      - Get and update global preference groups.
    - `GET`/`PATCH` `/site-preference-groups/{groupId}/{instanceType}`
      - Get and update site preference groups.
    - `POST` `/site-preference-groups/{groupId}/{instanceType}/preference-search`
      - Search preferences.
    - `GET` `/site-preference-groups/{groupId}/{instanceType}/preferences/{preferenceId}`
      - Get and update preferences.
  - [Inventory Lists API]
    - `GET`/`PUT`/`PATCH`/`DELETE` `/inventory-lists/{inventoryListId}`
      - CRUD operations for inventory lists.
  - [Experiences API]
    - `GET` `/slots/{slotId}/{contextType}`
      - Get a slot.
    - `POST` `/slot-search`
      - Search for slots.
    - `GET`/`PUT`/`PATCH`/`DELETE` `/slots/{slotId}/slot-configurations/{configurationId}`
      - CRUD operations for slots.
  - [Custom Objects API]
    - `GET`/`PUT`/`PATCH`/`DELETE` `/custom-objects/{objectType}/{key}`
      - Object type key operations.
    - `POST` `/custom-objects-search/{objectType}`
      - Search custom objects by object type.
    - `GET`/`PUT`/`PATCH`/`DELETE` `/sites/{siteId}/custom-objects/{objectType}/{key}`
      - Site-specific object type key operations.
  - [Stores API]
    - `DELETE`/`PATCH`/`PUT` `/stores/{id}`
      - Additional CRUD operations for stores.
- [Shopper Search]
  - New query parameter `imgTypes` on `productSearch`:
    - Filters product images by type with optional per-type count limits, for example, `imgTypes=large:2,small:1`.
    - Requires `expand=images` and `allImages=true`.
  - `q` parameter: The `maxLength` increases from **50** to **500**. Lexical search queries remain limited to 50 characters.
  - `limit` parameter: Adds an explicit `minimum: 1` constraint in addition to the existing `maximum: 200` and the default of 25.
  - `allImages`: Updated the parameter description to clarify that it can be combined with `imgTypes` for filtered image responses.
  - The `OrganizationId` schema and `organizationId` path parameter now use a regex pattern (`^f_ecom_[a-z]{4}_(prd|stg|dev|s[0-9]{2}|[0-9]{3})$`) instead of `minLength`/`maxLength`, with a more descriptive description referencing realm and instance identifiers.
- Prepare for OCI migration to Hyperforce in AMER and EMEA. No customer impact is anticipated.
