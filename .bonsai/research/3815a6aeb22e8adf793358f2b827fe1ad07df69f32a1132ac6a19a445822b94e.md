## Requirements

Before you begin, make sure that you have performed the following steps:

1. [Create a test account with Adyen]. With this, you will be able to access the [test Customer Area], and apply for a live account. While you wait for your live account credentials, you can start integrating by using your test account.

2. Finish the [metadata import].

3. In Salesforce Commerce Cloud, [enforce HTTPS].

   To be compatible with the Chrome v80 Cookie policy, you need to enforce the use of HTTPS for all sites.

## Detailed

## Requirements

Before you begin, make sure that you have performed the following steps:

1. [Create a test account with Adyen](/get-started-with-adyen). With this, you will be able to access the [test Customer Area](https://ca-test.adyen.com/), and apply for a live account. While you wait for your live account credentials, you can start integrating by using your test account.

2. Finish the [metadata import](/plugins/salesforce-commerce-cloud/sfra/install-the-cartridge-and-import-the-metadata).

3. In Salesforce Commerce Cloud, [enforce HTTPS](https://documentation.b2c.commercecloud.salesforce.com/DOC1/index.jsp?topic=%2Fcom.demandware.dochelp%2Fcontent%2Fb2c_commerce%2Ftopics%2Fadmin%2Fb2c_configure_enforce_https_global_preference.html).

   To be compatible with the Chrome v80 Cookie policy, you need to enforce the use of HTTPS for all sites.
