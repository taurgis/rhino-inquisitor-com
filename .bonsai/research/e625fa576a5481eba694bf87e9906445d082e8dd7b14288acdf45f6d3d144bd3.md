# LINK Marketplace Retirement

The LINK Marketplace is now retired. To help you extend B2C Commerce, we’ve migrated all apps from the LINK (B2C Commerce) marketplace to AppExchange – made up of cartridges and headless integrations. The AppExchange is now the sole Salesforce marketplace for B2C Commerce Integrations. B2C Commerce independent software vendor (ISV) partner cartridge code has been removed from Salesforce GitHub repositories, and the LINK Program has officially concluded.

How: All B2C Commerce cartridges and headless integrations are now discoverable on [AppExchange.com] by searching for B2C Commerce or the ISV partner name in the search box.
