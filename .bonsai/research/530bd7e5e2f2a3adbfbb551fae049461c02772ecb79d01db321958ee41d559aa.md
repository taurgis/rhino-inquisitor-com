## Summary

Page Designer Integration with Storefront Next > Business Manager Setup > Using Page Designer

## Compressed

### Using Page Designer

1. Go to **Merchant Tools > Content > Page Designer**.
2. Create a page or edit an existing one.
3. Select a page type that matches your Storefront Next page types.
4. Add components to regions using the visual editor.
5. Configure component attributes in the properties panel.
6. Publish the page.
