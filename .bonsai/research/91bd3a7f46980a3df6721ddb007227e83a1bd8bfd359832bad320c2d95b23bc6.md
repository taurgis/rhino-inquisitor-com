# Set Component Visibility by Customer Group, Schedule, or Locale

_You can use Page Designer to control which components appear on a B2C Commerce storefront.

[Which Salesforce Commerce Product Do I Have?]

If you’ve targeted a component to be part of a campaign or promotion, this functionality isn’t available. In that case, the campaign or promotion you assign determines the customer group and schedule, if any.

1. In Business Manager, click App Launcher, and then select **Merchant Tools > Site > Content > Page Designer**.
2. Open a page in your storefront.
3. Click a component.
4. In the right pane, click the **Settimgs** tab and select **Custom Targeting**.
5. Select the customer groups for which you want the component to be visible.

   See [Create a Customer Group in B2C Commerce] for information about customer groups.
6. Select the locales in which you want the component to be visible.

   Be sure to select locales that your site supports.
7. Enter the dates and times during which you want the component to be visible.

   The times correspond to the time zone of your site.
8. Click **Apply**.
9. Click **Save**.
10. Add as many components to the region as you want.
11. Click the Page Structure icon._(image: Icon for Page Structure.)_
12. Expand the region that holds the components._(image: Image showing regions of the page with designations indicating components present and maximum visible.)_

   All components that you've added to the region appear in the list. Whether a component appears depends on how you've set the targeting rules. It also depends on whether the region has a maximum number of components allowed, as indicated in the Page Structure view. For example, 0/1 on the Header Banner Region indicates that the region currently contains no components, and a maximum of one component can be visible (1). The Main Region has no maximum specified (2). Column 1 currently contains three components, and only one component can be visible (3).
   
   Regions with a visibility maximum: When the page loads, the system evaluates the list of components in the region from top to bottom and checks the visibility rules for each component. The number of components that appear in the storefront depends on the maximum visible components allowed for the region. For example, if the maximum is two, the first two components whose customer group, date, and locale all match the rules appear on the page. If fewer components match than the region's maximum allows, only the matching ones appear. If no components match, nothing appears in that region. A good practice is to place a component with no visibility rules at the bottom of the list to act as a fallback in case no other component matches.
   
   > **Note:** You can drag the components to change the order in which they appear in the Page Structure panel.
   
   Regions with no visibility maximum: All components whose visibility rules match appear on the page at the same time.
