## Summary

Composable Storefront Release Notes > 3/12/2026 > Node.js 24 Support

## Compressed

### Node.js 24 Support

Managed Runtime now supports Node.js 24, bringing the latest features and security improvements to your storefronts. Node.js 24 provides enhanced performance, updated dependencies, and long-term support.

**How:** See the details at [Upgrade Node Version]. Ensure your local development environment, CI servers, and build systems are also updated to Node.js 24. Node.js 24 is available starting in [PWA Kit 3.17.0] and [PWA Kit 2.11.0].

- [Upgrade Node Version]
- [Supported Node Versions]
