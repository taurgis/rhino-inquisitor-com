## Summary

Page Designer Integration with Storefront Next > Implement Page Designer Pages > Region Usage in Pages

## Compressed

### Region Usage in Pages

Use **page mode** for top-level regions.

```tsx
<Region
  page={loaderData.page} // Page data from loader
  regionId="main" // Region ID matching @RegionDefinition
  fallbackElement={<Skeleton />} // Optional: Loading state
  errorElement={<ErrorMessage />} // Optional: Error state
/>
```

Use **component mode** for nested regions inside container components.

```tsx
<Region
  component={component} // Component object (synchronous)
  regionId="content" // Region ID
/>
```

:::important
Don't mix `page` and `component` props. Use one or the other.
:::
