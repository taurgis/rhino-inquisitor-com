## Summary

B2C Commerce API Release Notes > 05/20/2025 > OCAPI Release

## Compressed

### OCAPI Release

- With B2C Commerce version 25.6:
  - Enhanced the [Get customers list Data API] to allow developers to retrieve customer configuration preferences. Developers can use this API to retrieve information that was previously only part of the header data in [Customer Lists export].

## Detailed

### OCAPI Release

- With B2C Commerce version 25.6:
  - Enhanced the [Get customers list Data API](https://developer.salesforce.com/docs/commerce/b2c-commerce/references/ocapi-data-customer-lists?meta=Get%2Bcustomer%2Blist) to allow developers to retrieve customer configuration preferences. Developers can use this API to retrieve information that was previously only part of the header data in [Customer Lists export](https://help.salesforce.com/s/articleView?id=cc.b2c_customer_list_object_import_export.htm\&type=5).
