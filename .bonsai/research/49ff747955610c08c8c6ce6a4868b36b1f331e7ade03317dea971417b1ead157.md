# Get Started with the B2C Commerce API

The B2C Commerce API (SCAPI) is a set of RESTful APIs for building storefronts, merchant tools, and integrations on the B2C Commerce platform.

:::tip To browse the endpoints, see the [API Reference].

## Make Your First Request

The following two curl commands are all you need to get started.

### Step 1: Get a Guest Token

Replace `{client_id}` and `{client_secret}` with your SLAS private client credentials.

```sh
curl "https://kv7kzm78.api.commercecloud.salesforce.com/shopper/auth/v1/organizations/f_ecom_zzte_053/oauth2/token" \
  -u "{client_id}:{client_secret}" \
  -d "grant_type=client_credentials" \
  -d "channel_id=RefArch"
```

The response includes an `access_token`:

```json
{
  "access_token": "eyJ0eXAiOiJKV1Q...",
  "expires_in": 1800,
  "token_type": "Bearer"
}
```

### Step 2: Call a Shopper API

Use the `access_token` from Step 1 to fetch a product:

```sh
curl "https://kv7kzm78.api.commercecloud.salesforce.com/product/shopper-products/v1/organizations/f_ecom_zzte_053/products/25695327M?siteId=RefArch" \
  -H "Authorization: Bearer {access_token}"
```

A successful response returns product details as JSON:

```json
{
  "id": "25695327M",
  "name": "Striped Silk Tie",
  "currency": "USD",
  "price": 19.19,
  ...
}
```

In addition to securing access to the Shopper API, SLAS can also turn on third-party identity providers, single sign-on, and personalization in your application.

:::note **Other ways to get started:**

- Run a complete example (including token acquisition) with the Commerce SDK: [Quick Start]
- Explore APIs interactively: [SCAPI Postman Collection]

:::

## Understand SCAPI

### Shopper APIs vs. Admin APIs

SCAPI consists of two API types, plus open-source SDKs and a developer tooling ecosystem.

|                    | Shopper APIs                                                    | Admin APIs                                                                             |
| ------------------ | --------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **Purpose**        | Customer-facing (browsing, cart, checkout)                      | Merchant-facing (product, order, inventory management)                                 |
| **Authentication** | [SLAS] (OAuth 2.1) | [Account Manager] |
| **Scale**          | High-scale, supports anonymous users                            | Moderate usage                                                                         |
| **Access**         | Read-only (exceptions: Baskets, Orders)                         | Read and write                                                                         |
| **Naming**         | API names start with "Shopper"                                  | No naming convention                                                                   |

### JavaScript SDKs

| Package                                                                                          | Description                   | Docs                                                                       |
| ------------------------------------------------------------------------------------------------ | ----------------------------- | -------------------------------------------------------------------------- |
| [`commerce-sdk`]                                     | Node.js (server-side or CLI)  | [Docs]            |
| [`commerce-sdk-isomorphic`]               | Isomorphic (server + browser) | [Docs] |
| [`@salesforce/commerce-sdk-react`] | React hooks for SCAPI         | [Docs]                 |

For other languages, use the [SCAPI Postman Collection] or the API specs in [`commerce-sdk`].

To explore SCAPI from your IDE using AI assistants, use the [B2C DX MCP Server] (Developer Preview).

## Operational Reference

The following information is important when preparing for production use.

### Constraints

- SCAPI requests are [rate limited] to ensure availability.
- Shopper APIs must respond within 10 seconds; Admin APIs within 60 seconds. See [Timeouts and Limits].
- Request and response bodies have size limits. See [Timeouts and Limits].
- Shopper API requests are routed by USID. Don't reuse the same USID for many guest shoppers.
- For staging with vanity domains, set up [eCDN for Staging].
- For cross-origin browser access, configure [CORS].

### Troubleshooting

- Use correlation IDs to match requests to responses. Include a `correlation-id` header in your request and the response returns it as `x-correlation-id`. See [View SCAPI Logs and Track Requests].

### Change Policy

:::important Some new features are available only with specific B2C Commerce versions.

Make sure that your code can handle nonbreaking changes to the API, such as new fields, new optional parameters, or changes to error messages. :::

SCAPI is updated regularly with new features, bug fixes, and improvements.

For the full list of nonbreaking change types and the deployment schedule, see the [B2C Commerce Deployment Schedule].

### Availability

Subscribe to availability updates on [Salesforce Status].

The B2C Commerce API (SCAPI) is a set of RESTful APIs for building storefronts, merchant tools, and integrations on the B2C Commerce platform. It also goes by "Salesforce Commerce API" or just "Commerce API." For B2C Commerce customers, the API is available at no extra cost.

To learn how SCAPI fits into the B2C Commerce stack, see [Composable Storefront and SCAPI](https://developer.salesforce.com/docs/commerce/pwa-kit-managed-runtime/guide/pwa-scapi.html).

## Operational Reference

The following information is important when preparing for production use.

### Constraints

- SCAPI requests are [rate limited](/docs/commerce/b2c-commerce/guide/throttle-rates.html) to ensure availability.
- Shopper APIs must respond within 10 seconds; Admin APIs within 60 seconds. See [Timeouts and Limits](/docs/commerce/b2c-commerce/guide/timeouts-limits.html).
- Request and response bodies have size limits. See [Timeouts and Limits](/docs/commerce/b2c-commerce/guide/timeouts-limits.html).
- Shopper API requests are routed by USID. Don't reuse the same USID for many guest shoppers.
- For staging with vanity domains, set up [eCDN for Staging](https://help.salesforce.com/s/articleView?id=cc.b2c_configure_ecdn_for_staging.htm\&type=5).
- For cross-origin browser access, configure [CORS](/docs/commerce/b2c-commerce/guide/scapi-cors.html).

### Troubleshooting

- Use correlation IDs to match requests to responses. Include a `correlation-id` header in your request and the response returns it as `x-correlation-id`. See [View SCAPI Logs and Track Requests](/docs/commerce/b2c-commerce/guide/scapi-logs-request-tracking.html).

### Change Policy

:::important
Some new features are available only with specific B2C Commerce versions. This information is included in the [B2C Commerce Release Notes](https://help.salesforce.com/s/articleView?id=commerce.b2c_rn_release_notes.htm\&type=5) and the API specification where applicable.

Make sure that your code can handle nonbreaking changes to the API, such as new fields, new optional parameters, or changes to error messages.
:::

SCAPI is updated regularly with new features, bug fixes, and improvements. Updates are announced in [Salesforce Status](https://status.salesforce.com/products/B2C_Commerce_Cloud) and the [SCAPI Release Notes](/docs/commerce/commerce-api/references/about-commerce-api/about.html). Some features require specific [B2C Commerce versions](https://help.salesforce.com/s/articleView?id=commerce.b2c_rn_release_notes.htm\&type=5).

For the full list of nonbreaking change types and the deployment schedule, see the [B2C Commerce Deployment Schedule](https://help.salesforce.com/s/articleView?id=commerce.b2c_deploy_schedule\_24.htm\&type=5).

### Availability

Subscribe to availability updates on [Salesforce Status](https://status.salesforce.com/products/B2C_Commerce_Cloud). During maintenance, SCAPI returns [maintenance responses](/docs/commerce/b2c-commerce/guide/response-handling.html). For load management details, see [Load Shedding and Rate Limiting](/docs/commerce/b2c-commerce/guide/throttle-rates.html).
