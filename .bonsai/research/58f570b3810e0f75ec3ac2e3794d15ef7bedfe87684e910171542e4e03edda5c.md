## Compressed

### PWA Kit - Update SLAS Calls to Prevent Unauthorized Access Across Sites

Retail React App version 4.0 consumes the new versions of [Commerce SDK React] and [Commerce SDK Isomorphic]. These SDKs now satisfy Shopper Login and API Access (SLAS) guidance to pass `channel_id` as an argument when retrieving guest access tokens. See [Guest Tokens].

## Detailed

### PWA Kit - Update SLAS Calls to Prevent Unauthorized Access Across Sites

Retail React App version 4.0 consumes the new versions of [Commerce SDK React](https://salesforcecommercecloud.github.io/pwa-kit/) and [Commerce SDK Isomorphic](https://github.com/SalesforceCommerceCloud/commerce-sdk-isomorphic). These SDKs now satisfy Shopper Login and API Access (SLAS) guidance to pass `channel_id` as an argument when retrieving guest access tokens. See [Guest Tokens](https://developer.salesforce.com/docs/commerce/commerce-api/guide/slas.html#guest-tokens).
