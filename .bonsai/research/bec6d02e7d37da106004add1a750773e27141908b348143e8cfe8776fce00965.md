### 4.3 Implementation and Limitations

We provide two implementations of the sampler: a single-threaded HuggingFace Transformers version with streaming support, and a multithreaded OpenAI-compatible version for production platforms like vLLM ([Kwon et al., 2023]).

The sampler suppresses patterns without fine-tuning but reduces throughput. In practice, frequent backtracking decreases performance by 69%-96%, depending on banlist size (detailed performance analysis in Appendix [B] ‣ Antislop: A Comprehensive Framework for Identifying and Eliminating Repetitive Patterns in Language Models")). For applications requiring maximum inference speed, this overhead motivates our complementary approach: using the sampler’s outputs to train a slop-suppressed model via FTPO.

## Detailed

### 4.3 Implementation and Limitations

We provide two implementations of the sampler: a single-threaded HuggingFace Transformers version with streaming support, and a multithreaded OpenAI-compatible version for production platforms like vLLM ([Kwon et al., 2023](https://arxiv.org/html/2510.15061#bib.bib10)).

The sampler suppresses patterns without fine-tuning but reduces throughput. Each backtracking event restarts inference at a prior position, and this may occur hundreds of times per generation with large banlists. In practice, frequent backtracking decreases performance by 69%-96%, depending on banlist size (detailed performance analysis in Appendix [B](https://arxiv.org/html/2510.15061#A2 "Appendix B Inference Performance (tok/s) ‣ Antislop: A Comprehensive Framework for Identifying and Eliminating Repetitive Patterns in Language Models")). For applications requiring maximum inference speed, this overhead motivates our complementary approach: using the sampler’s outputs to train a slop-suppressed model via FTPO.
