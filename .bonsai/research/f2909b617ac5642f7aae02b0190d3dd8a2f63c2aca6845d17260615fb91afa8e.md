## Summary

B2C Commerce API Release Notes > 2024 > 07/10/2024

## Compressed

### 07/10/2024

#### SCAPI Release

- Server-Side Web-Tier Caching is automatically turned on for:
  - SBX and ODS instances
  - PRD instances that don't use use hooks in [Shopper Search API] `productSearch` and `getSearchSuggestions` endpoints. For details, see: [Server-Side Web-Tier Caching].
- Internal infrastructure upgrades. No customer impact is anticipated.

## Detailed

### 07/10/2024

#### SCAPI Release

- Server-Side Web-Tier Caching is automatically turned on for:
  - SBX and ODS instances

For details, see: [Server-Side Web-Tier Caching](https://developer.salesforce.com/docs/commerce/commerce-api/guide/server-side-web-tier-caching.md).
