## Compressed

### A.3 Prompts for Open-ended Language Analysis

We detail the procedures of our open-ended language analysis in Section [3.3]. Given the same input, we sample a pair of responses from two LLMs and present them, along with an analysis prompt (see Figure [11(a)]), to an LLM judge for comparison. To avoid the LLM judge exploiting any prior knowledge of the models, we anonymize model identities using an index distribution. This process is repeated for 35 response pairs, yielding a set of detailed analyses. Finally, we use the summarization prompt (see Figure [11(b)]) to distill these analyses into 5 bullet points that characterize the idiosyncrasies of each model.
