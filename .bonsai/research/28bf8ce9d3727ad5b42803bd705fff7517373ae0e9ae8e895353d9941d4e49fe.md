## Summary

B2C Commerce API Release Notes > 2024 > 06/04/2024

## Compressed

### 06/04/2024

#### SCAPI Release

- The Shopper Context API now requires a `siteId` for new customers. For details, see the [Shopper Context Guide].
- The following Script API methods are available to support SCAPI external taxation APIs with hooks:
  - [dw.order.LineItemCtnr#isExternallyTaxed]: Returns true if the basket was created with taxMode = external.
  - [dw.order.TaxMgr#applyExternalTax]: Applies externally set tax rates to the given basket. Use when `dw.order.LineItemCtnr#isExternallyTaxed` returns true.
    For details, see [Extensibility via Hooks] and [updateItemsinBasket].

#### SCAPI Fixes

- With B2C Commerce version 24.6, the [mergeBasket] endpoint now merges the guest shopper’s `shippingAddress` and `shippingMethod` into the registered basket when the registered basket does not contain `shippingAddress` or `shippingMethod`.

## Detailed

### 06/04/2024

#### SCAPI Release

- The Shopper Context API now requires a `siteId` for new customers. For details, see the [Shopper Context Guide](https://developer.salesforce.com/docs/commerce/commerce-api/guide/shopper-context-api.html#constraints).
- The following Script API methods are available to support SCAPI external taxation APIs with hooks:
  - [dw.order.LineItemCtnr#isExternallyTaxed](https://salesforcecommercecloud.github.io/b2c-dev-doc/docs/current/scriptapi/html/api/class_dw_order_LineItemCtnr.html#dw_order_LineItemCtnr_isExternallyTaxed_DetailAnchor): Returns true if the basket was created with taxMode = external.
  - [dw.order.TaxMgr#applyExternalTax](https://salesforcecommercecloud.github.io/b2c-dev-doc/docs/current/scriptapi/html/api/class_dw_order_TaxMgr.html#dw_order_TaxMgr_applyExternalTax_Basket_DetailAnchor): Applies externally set tax rates to the given basket. Use when `dw.order.LineItemCtnr#isExternallyTaxed` returns true.
    For details, see [Extensibility via Hooks](https://developer.salesforce.com/docs/commerce/commerce-api/guide/extensibility_via_hooks.html#taxes-apis-and-hooks) and [updateItemsinBasket](https://developer.salesforce.com/docs/commerce/commerce-api/references/shopper-baskets?meta=updateItemsInBasket).

#### SCAPI Fixes

- With B2C Commerce version 24.6, the [mergeBasket](https://developer.salesforce.com/docs/commerce/commerce-api/references/shopper-baskets-v2?meta=mergeBasket) endpoint now merges the guest shopper’s `shippingAddress` and `shippingMethod` into the registered basket when the registered basket does not contain `shippingAddress` or `shippingMethod`.
