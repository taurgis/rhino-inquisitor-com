## Summary

Page Designer > Use Salesforce CMS Content with Page Designer > Use Salesforce CMS Content to Configure a Component Attribute

## Compressed

### Use Salesforce CMS Content to Configure a Component Attribute

Configure the component attribute by selecting the Salesforce CMS content and then configuring the attributes for that content.

When you select CMS content for a component attribute, it's copied into the page. CMS updates don't automatically appear in the component.

The default locale for the Page Designer page isn't necessarily the same as the default locale for the CMS content.

1. Add the component that uses Salesforce CMS content to the page.

   In this example, the CMS Headline Banner component type uses CMS content to configure the Headline Content attribute. 

2. In the attribute editor window, click **Select CMS Content**.

   

   A list of the CMS content available to configure the attribute is displayed.

3. Choose the CMS content you want to use and click Select.

   

   The CMS content is copied to the page. Any attributes for the CMS content that require configuration are presented in the editing pane. The CMS content for the Headline Banner in the example requires that you enter a Title, Body, and Banner Image.

4. Configure at least the required attributes for the component click **Save** or **Save & Close**.

## Detailed

### Use Salesforce CMS Content to Configure a Component Attribute

Configure the component attribute by selecting the Salesforce CMS content and then configuring the attributes for that content.

When you select CMS content for a component attribute, it's copied into the page. CMS updates don't automatically appear in the component. To get updated content, reconfigure the attribute and select the content again.

The default locale for the Page Designer page isn't necessarily the same as the default locale for the CMS content.

1. Add the component that uses Salesforce CMS content to the page.

   In this example, the CMS Headline Banner component type uses CMS content to configure the Headline Content attribute. ![CMS headline banner component](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_page_designer_cms_component_screen.jpg)

2. In the attribute editor window, click **Select CMS Content**.

   ![Select CMS content](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_page_designer_new\_2\_cms_modal_select_screen.jpg)

   A list of the CMS content available to configure the attribute is displayed.

3. Choose the CMS content you want to use and click Select.

   ![Set properties for CMS Headline Banner component](https://a.sfdcstatic.com/developer-website/sfdocs/commerce-cloud/media/b2c-commerce/b2c_page_designer_cms_attrs_screen.jpg)

   The CMS content is copied to the page. Any attributes for the CMS content that require configuration are presented in the editing pane. The CMS content for the Headline Banner in the example requires that you enter a Title, Body, and Banner Image.

4. Configure at least the required attributes for the component click **Save** or **Save & Close**.
