## Summary

B2C Commerce API Release Notes > 06/23/2026 > SCAPI Release

## Compressed

### SCAPI Release

- [Custom Objects] 1.1.0
  - Added a search request example that demonstrates a `termQuery` on the `siteId` attribute to filter custom objects by site.
- [Orders] and [Shopper Orders]
  - When Salesforce Order Management (SOM) integration is enabled and the `expand=oms` parameter is requested, order detail and order lookup endpoints additionally return payment instrument data sourced from SOM.
  - Order Lookup: `GET /orders/{order_no}/lookup`
  - Shopper Orders: `GET /orders/{order_no}`
- [Shopper Auth] 1.50.0
  - The passwordless-token endpoint now documents Issuer Subject (`isb`) construction and its 256-character limit. Requests whose assembled `isb` exceeds 256 characters return `400 BAD_REQUEST` ("Issuer Subject length must be less than 256 characters"). For details, see [Shopper Login and API Access Service (SLAS) Overview].
- [Shopper Experience] 1.5.2
  - New endpoint:
    - `GET /experience/shopper-experience/v1/organizations/{organizationId}/components/{componentId}`
      - Retrieve a single Page Designer component by ID.
- [Shopper Orders] 1.15.0
  - New endpoints for order cancellation and returns:
    - `GET /orders/oms-meta-data`
      - Provides the cancel and return reason codes synchronized from Salesforce Order Management.
    - `POST /orders/{orderNo}/actions/oms-cancel-order`
      - Cancel an order.
    - `POST /orders/{orderNo}/actions/oms-return-order`
      - Specify items to return.
- [Shopper Products] 1.10.0
  - New endpoints:
    - `GET /product/shopper-products/v1/organizations/{organizationId}/products/{productId}/images`
      - Retrieve image data for a single product.
    - `GET /product/shopper-products/v1/organizations/{organizationId}/products/{productId}/prices`
      - Retrieve price details for a single product.
    - `GET /product/shopper-products/v1/organizations/{organizationId}/products/{productId}/promotions`
      - Retrieve active promotion details for a single product.
- [Shopper Search] 1.10.0
  - Page meta tags in search results now include a type field indicating how the storefront should render the tag: name, property, title, or jsonld. The field might not appear when the kind can't be determined.
