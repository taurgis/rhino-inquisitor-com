## Summary

Integrate Page Designer with PWA Kit > New Features > Design Metadata

## Compressed

### Design Metadata

Components now receive `designMetadata` with information for visual editing:

```typescript
interface ComponentDesignMetadata {
  id: string // Component instance ID
  name?: string // Display name
  isFragment: boolean // Is this a fragment?
  isVisible: boolean // Is component visible?
  isLocalized: boolean // Is component localized?
}
```

Components also receive additional props:

- `component` - The full component data object
- `regionId` - The parent region's ID

You don't need to use these props, but they're available if needed for custom behavior.
