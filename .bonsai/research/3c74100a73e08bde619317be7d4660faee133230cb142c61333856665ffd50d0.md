## Summary

Configure Multisite URLs > Navigate with Site Context > useCurrentSiteAndLocaleRef

## Compressed

### useCurrentSiteAndLocaleRef

Use the `useCurrentSiteAndLocaleRef` hook when you need to build URLs manually outside of Link or useNavigate:

```typescript
import { useCurrentSiteAndLocaleRef } from "@salesforce/storefront-next-runtime/site-context";
import { buildUrl } from "@/lib/url";
import { useConfig } from "@salesforce/storefront-next-runtime/config";

function MyComponent() {
  const config = useConfig();
  const currentSiteAndLocaleRef = useCurrentSiteAndLocaleRef();

  const url = buildUrl("/product/123", config.app.url, currentSiteAndLocaleRef.current);
  // url: /global/en-GB/product/123
}
```
