## Summary

Hostname Alias File

## Compressed

### Hostname Alias File

The hostname alias file defines what hostnames or domains that B2C Commerce supports. The hostname alias file also defines what pipelines or controllers are triggered for a specific URL. This file is required for a Production instance launch.

For more information on mappings, see [URL Redirects].

You can create a set of rules that controls how B2C Commerce processes different URLs.

Include the proper https-host in the alias file.

For example, www.mysite.com maps as:

```
{ "__version": "1", "settings": { "http-host": "www.mysite.com", "https-host": "www.mysite.com" } }
```

See [Configuring a Hostname Alias].

You can also configure your hostname alias file to [avoid multiple entry points] and duplicate URLs, thus increasing the SEO value of your storefront site.

For additional information on how B2C Commerce constructs URLs, see [URL Rules URL Syntax].

## Detailed

### Hostname Alias File

The hostname alias file defines what hostnames or domains that B2C Commerce supports. The hostname alias file also defines what pipelines or controllers are triggered for a specific URL. This file enables a Production instance with multiple IP addresses to provide different storefront content for multiple domains per site or multiple sites per realm. This file is required for a Production instance launch.

For more information on mappings, see [URL Redirects](https://help.salesforce.com/s/articleView?id=cc.b2c_url_redirects.htm&type=5).

You can create a set of rules that controls how B2C Commerce processes different URLs. These rules use the JSON (Java Script Object Notation) format (see [Json.Org](http://json.org/)).

Include the proper https-host in the alias file. The https-host must reflect the host name.

For example, www.mysite.com maps as:

```
{ "__version": "1", "settings": { "http-host": "www.mysite.com", "https-host": "www.mysite.com" } }
```

See [Configuring a Hostname Alias](https://help.salesforce.com/s/articleView?id=cc.b2c_configuring_hostname_alias.htm&type=5).

You can also configure your hostname alias file to [avoid multiple entry points](https://help.salesforce.com/s/articleView?id=cc.b2c_avoiding_duplicate_home_page_urls.htm&type=5) and duplicate URLs, thus increasing the SEO value of your storefront site. See the Mapping Rule Syntax section.

For additional information on how B2C Commerce constructs URLs, see [URL Rules URL Syntax](https://help.salesforce.com/s/articleView?id=cc.b2c_url_rules_url_syntax.htm&type=5).
