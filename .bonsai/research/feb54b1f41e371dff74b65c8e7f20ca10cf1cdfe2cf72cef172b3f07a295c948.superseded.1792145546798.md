## Summary

B2C Commerce API Release Notes > 09/29/2026 > SLAS Release

## Compressed

### SLAS Release

- [Auth Admin]
  - The [Delete Shopper endpoint] (`DELETE /tenants/{tenantId}/customers/{customerId}`) now accepts tenant-scoped Account Manager automation tokens, in addition to service-admin and organization-admin credentials.
    - To use it, call the endpoint with a `client_credentials` Account Manager token that has the CCDX_SBX_USER role and is scoped to the target tenant. Tokens without a matching tenant scope are rejected. Deletion behavior, including the rate limit of 100 requests per minute, is otherwise unchanged.
- mTLS Enforcement
  - To enhance the security of the SLAS authentication service, we’re enabling mutual TLS (mTLS) client-certificate enforcement at the SLAS gateway. Starting October 6, 2026, according to the new per-region schedule listed below, any request reaching the SLAS origin without a valid client certificate—including requests that bypass the SCAPI zone—will be rejected.
  - Who is affected:
    - No action required: for integrations using the standard, published Commerce Cloud SLAS endpoints through the SCAPI zone. This is the supported integration path and will continue to work without changes.
    - Action required: for integrations that connect directly to the SLAS origin and bypass the SCAPI zone—for example, by using hardcoded origin hostnames/IP addresses or a custom network path. These requests will be rejected once mTLS enforcement is enabled.
  - Schedule:
    - AP2: October 6, 2026
    - AP3: October 8, 2026
    - EU: October 12, 2026
    - US-East: October 15, 2026
