## Summary

B2C Commerce API Release Notes > 03/24/2026

## Compressed

## 03/24/2026

New SCAPI APIs:

- [Object Definitions]:
  - System Object Types
    - `GET /system/object-types`
      - Get system object types.
    - `POST /system/object-types-search`
      - Search system object types.
    - `GET /system/object-types/{objectType}`
      - Get system object type.
  - Attribute Definitions
    - `POST /system/object-types/{objectType}/attribute-definition-search`
      - Search attribute definitions.
    - `GET /system/object-types/{objectType}/attribute-definitions`
      - Get attribute definitions.
    - `GET/PUT/PATCH/DELETE /system/object-types/{objectType}/attribute-definitions/{id}`
      - Create, Read, Update, and Delete (CRUD) attribute definition.
  - Attribute Groups
    - `POST /system/object-types/{objectType}/attribute-group-search`
      - Search attribute groups.
    - `GET /system/object-types/{objectType}/attribute-groups`
      - Get attribute groups
    - `GET/PUT/PATCH/DELETE /system/object-types/{objectType}/attribute-groups/{id}`
      - CRUD an attribute group.
  - Attribute Group Assignments
    - `PUT/DELETE /system/object-types/{objectType}/attribute-groups/{groupId}/attribute-definitions/{defId}`
      - Assign/unassign attribute definition to a group.
- New [Experiences API] endpoints:
  - Library Folders
    - `GET/PUT/PATCH/DELETE /libraries/{libraryId}/folders/{folderId}`
      - CRUD a content folder.
    - `GET /libraries/{libraryId}/folders/{folderId}/sub-folders`
      - Get sub-folders.
    - `GET /libraries/{libraryId}/folders/{folderId}/content`
      - Get content assets in a folder.
  - Library Content Assets
    - `GET/PUT/PATCH/DELETE /libraries/{libraryId}/content/{contentId}`
      - CRUD a content asset.
    - `GET /libraries/{libraryId}/content/{contentId}/folders`
      - Get folder information for a content asset.
  - Library Folder Assignments
    - `GET/PUT/PATCH/DELETE /libraries/{libraryId}/folder-assignments/{contentId}/{folderId}`
      - CRUD a folder assignment.
    - `DELETE /libraries/{libraryId}/folder-assignments/{contentId}/{folderId}`
      - Delete a folder assignment.
- [Inventory Impex (OCI)] Updates:

  - Added the `fileFormat` field to the `submitEventsActivityExport` endpoint. Use this field to change the output format to CSV or JSON.
