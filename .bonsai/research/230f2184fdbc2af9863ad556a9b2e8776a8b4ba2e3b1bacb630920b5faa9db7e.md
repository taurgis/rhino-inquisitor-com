# Skills for Success

This guide covers the key technical skills for successful development with PWA Kit.

Generally speaking, PWA Kit developers should be comfortable with:

- Building universal React.js applications.
- Coding in [ES6](https://developer.mozilla.org/en-US/docs/Web/JavaScript) JavaScript.
- Styling UI components with [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS).
- Working with RESTful APIs like the [Salesforce Commerce API](https://developer.salesforce.com/docs/commerce/commerce-api/guide).
- Developing web applications with [Node.js](https://nodejs.org/) and [Express.js](https://expressjs.com/).
- Using [npm](https://docs.npmjs.com/) to manage packages and run scripts.

If that describes you, then you're ready to dive right in! What follows is a more comprehensive inventory of skills used in building a storefront application with PWA Kit. Don't worry if you're not an expert on every single thing. Working with PWA Kit presents plenty of opportunities to have fun learning new skills that are in high demand!

## JavaScript

A PWA Kit app is coded in modern JavaScript. Even your CSS is written in JavaScript!

A headless commerce app makes frequent network requests, so knowledge of [fetch()](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API) is crucial. We recommend using a universal fetch library ([cross-fetch](https://www.npmjs.com/package/cross-fetch), for example) that works both in a browser and in a Node.js environment. For maximum performance, you must be able write asynchronous code with [Promises](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) and [async and await](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/async_function).

### Recommended JavaScript Resources

- Online course: [Modern JavaScript From The Beginning](https://www.udemy.com/course/modern-javascript-from-the-beginning/)
- Online course: [JavaScript Concurrency](https://www.executeprogram.com/courses/javascript-concurrency)
- MDN: [Fetch API - Web APIs](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API)
- [`fetch()` cheatsheet](https://devhints.io/js-fetch)
- The [Express.js](https://expressjs.com/) web server
- How to [debug](https://nodejs.org/en/docs/guides/debugging-getting-started/) a Node.js application
- Managing [npm packages](https://docs.npmjs.com/cli-commands/install.html)
- Using [npm-run-scripts](https://docs.npmjs.com/cli-commands/run-script.html)

## React.js

React is the foundation for all PWA Kit apps. The [official React documentation](https://react.dev/learn) is an excellent place to start. It's so helpful that we recommend reading all of it! For a more targeted approach to learning React, try focusing on the components, props, the rendering lifecycle, and state management, including new concepts like hooks that were introduced in React 16.8.

### Recommended React.js Resources

- Online course: [Modern React](https://www.udemy.com/course/react-redux/)
- [Components](https://react.dev/learn/your-first-component) and [Props](https://react.dev/learn/passing-props-to-a-component) – React
- [State Management](https://kentcdodds.com/blog/application-state-management-with-react)
- [State](https://react.dev/learn/state-a-components-memory) and [Synchronizing with Effects](https://react.dev/learn/synchronizing-with-effects)
- [Context](https://kentcdodds.com/blog/how-to-use-react-context-effectively)
- [Error Boundaries](https://kentcdodds.com/blog/use-react-error-boundary-to-handle-errors-in-react)
- Hooks: [Quick Start](https://react.dev/learn), [Tutorial](https://react.dev/learn/tutorial-tic-tac-toe), and [Reference Overview](https://react.dev/reference/react)
- [Server Side Rendering](https://react.dev/reference/react-dom/server)
- [Hydration](https://react.dev/reference/react-dom/client/hydrateRoot)
- Debugging with [React DevTools](https://chrome.google.com/webstore/detail/react-developer-tools/fmkadmapgofadopljbjfkapdkoienihi?hl=en)
- React extensions like [react-router](https://v5.reactrouter.com/core/guides/quick-start) and [react-helmet](https://github.com/nfl/react-helmet)
