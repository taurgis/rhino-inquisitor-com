# 22.5 Release

The B2C Commerce 22.5 release occurs April 7, 2022 through May 17, 2022.

Stay current with all the important B2C Commerce product updates by reviewing the release notes! For a closer look at the features and enhancements in this release, watch the [22.5 Product Release Preview] video or [download] a PDF of the Preview.

Note Find Bug Fix Information in Salesforce Known Issues

Information about customer-reported issues and notifications about bug fixes is now published in [Salesforce Known Issues]. The B2C Commerce Release Notes continue to provide information about new features and major feature enhancements.

*   **[Add Klarna as a Payment Option]**  
    Commerce Payments now supports Klarna as a Multi-step payment option. You can offer shoppers the option to buy now and pay later. The Klarna payment option makes it convenient for shoppers to purchase items in all price ranges.
*   **[Set Commerce Payment Credential Storage]**  
    Commerce Payments now supports payment card credential storage. The Payment card credential storage. There are two settings.
*   **[Manage On-Demand Sandboxes with the Operations Scheduler]**  
    Use the Control Center Operations Scheduler to start and stop on-demand sandbox (ODS) instances within a realm. By scheduling ODS starts and stops, you can control the usage of ODS credits. The Operations Scheduler is a convenient UI-based tool. Developers can still use the swagger UI or the Sandbox API to schedule operations.
*   **[Use Primitive Data Types Only with Job Context]**  
    Jobs that store non-primitive data types of values, for example, arrays and objects, in `dw.job.JobExecution.getContext()` now fail. Previously, the job logged a warning, ignored the invalid value, and continued.
