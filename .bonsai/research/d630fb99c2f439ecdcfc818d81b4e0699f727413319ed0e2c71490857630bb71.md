# B2C Commerce Einstein and Data

B2C Commerce Einstein needs input data that it gathers from shopper activity.

Using gathered data, Einstein can:

*   Personalize recommendations.
*   Personalize search results and category grid sorting.
*   Identify new search synonyms.
*   Analyze shopper baskets to identify products commonly purchased together.
*   Provide shoppers with type-ahead search guidance, recent personal searches, and popular storefront searches.

To provide this level of shopper personalization, Einstein gathers and uses data from three sources:

| Data source | Description |
| --- | --- |
| Catalog | To collect product information from your catalog, run a catalog feed against your production instance. |
| Orders | To collect order information from your storefront, run an order feed against your production instance. |
| Clickstream | Clickstream data is automatically collected from your site in real-time using pixel tracking; you don't perform any action to collect this data.The following activities are automatically tracked:Product ViewAdd To CartFinish CheckoutView Recommendation |

B2C Commerce Einstein uses machine-learning models to analyze the collected data.

B2C Commerce Einstein needs input data that it gathers from shopper activity. Einstein uses this data for benchmarking and analysis to make intelligent data-driven personalization possible. This topic applies to B2C Commerce.

Using gathered data, Einstein can:

*   Personalize recommendations.
*   Personalize search results and category grid sorting.
*   Identify new search synonyms.
*   Analyze shopper baskets to identify products commonly purchased together.
*   Provide shoppers with type-ahead search guidance, recent personal searches, and popular storefront searches.

To provide this level of shopper personalization, Einstein gathers and uses data from three sources:

| Data source | Description |
| --- | --- |
| Catalog | To collect product information from your catalog, run a catalog feed against your production instance. |
| Orders | To collect order information from your storefront, run an order feed against your production instance. |
| Clickstream | Clickstream data is automatically collected from your site in real-time using pixel tracking; you don't perform any action to collect this data.The following activities are automatically tracked:Product ViewAdd To CartFinish CheckoutView Recommendation |
