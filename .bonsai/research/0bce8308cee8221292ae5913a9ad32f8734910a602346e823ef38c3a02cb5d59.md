## Compressed

### The useFetchers() Hook

[`useFetchers()`] returns an array of all in-flight fetchers across the application. While `useFetcher()` is scoped to a single component, `useFetchers()` provides a global view of all active fetcher operations. For example, showing a single "saving" badge when any background mutation is in progress.

```jsx
import { useFetchers } from "react-router";

function GlobalSavingIndicator() {
  const fetchers = useFetchers();
  const isSaving = fetchers.some((f) => f.state !== "idle");

  if (!isSaving) {
    return null;
  }
  return <div className="saving-indicator">Saving…</div>;
}
```

Each entry in the array mirrors the shape of a single `useFetcher()` instance, exposing `state`, `formData`, `data`, and other properties.
