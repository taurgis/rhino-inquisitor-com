## Developing for Page Designer

Developers play an important role in implementing Page Designer. Developers work with the ecommerce marketing director to determine the pages, components, layouts, and assets required for the storefront. The developer then creates and uploads custom cartridges. These cartridges contain reusable page types, component types, and visual editor artifacts that help merchants quickly create custom pages.
