# B2C Commerce Einstein Status Dashboard

Use the Einstein Status Dashboard to schedule and run storefront catalog and order feeds, enabling the activation of B2C Commerce Einstein features on the site.

*   **[B2C Commerce Einstein and Data]**  
    B2C Commerce Einstein needs input data that it gathers from shopper activity. Einstein uses this data for benchmarking and analysis to make intelligent data-driven personalization possible. This topic applies to B2C Commerce.
*   **[Configure Catalog and Order Feeds for B2C Commerce Einstein Deployment]**  
    Configure, schedule, and deploy catalog and order data feeds to Einstein.
*   **[Monitor the B2C Commerce Einstein Status Dashboard]**  
    Check the status of your catalog and order deployments and verify the quality of your data.
*   **[B2C Commerce Einstein Self-Service Support]**  
    The B2C Commerce Einstein Status Dashboard provides catalog and order deployment status and the ability to verify the quality of your data. The dashboard also displays any errors and warnings encountered by B2C Commerce Einstein about catalogs, orders, recommendations, or deployment. This topic applies to B2C Commerce.
